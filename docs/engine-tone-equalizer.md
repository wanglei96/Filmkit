# 局部影调（tone equalizer）设计

> 2026-10-20 立项。前因：全局曲线 + 全局 AE 下，「主体亮」与「天空保住蓝色 / 高光有层次」
> 反复互斥（真机 170249 阳台、170748 窗、163434 台灯）。业界做法是**局部影调**，
> 本文件记录我们按 darktable `tone equalizer` 落地的口径、参数与判据。

## 1. 为什么要局部

单条全局曲线只有一个"曝光点"：把中灰锚到 18.45%，天空（比中灰亮 4~6 EV）必然落到
曲线肩部，三通道一起逼近 1.0 ⇒ 色度被压缩 ⇒ 灰白。反过来保天空，主体就暗。
这不是参数问题，是**全局自由度只有 1 个**。

局部影调把自由度从 1 个（全局 EV）扩到 9 个（按亮度分区各给一个 EV），代价是必须
构造一张"引导 mask"来分区，且分区边界不能破坏局部对比。

## 2. 算法（darktable tone equalizer 口径）

```
scene 线性（Rec.2020）
  ① I = log2(luma)                     ← 对数域 ⇒ 曝光无关（eigf 的动机）
  ② box(I), box(I²)                     ← 可分离 H/V，半径 ≈ 短边 4%
  ③ a = var/(var+ε), b = (1−a)·mean     ← 自引导 guided filter（He 2010）
  ④ box(a), box(b)                      ← 系数平滑（同上半径）
  ⑤ q = a·I + b                         ← 平滑后的曝光图（仍在 EV 域）
  ⑥ gain = curve(q)                     ← 9 分区曲线，−8…0 EV
  ⑦ rgb × 2^gain                        ← 全分辨率应用（手写双线性上采样）
```

对应 darktable：②③④ 是它的 `guided mask`（默认 `eigf` 曝光无关引导滤波），
⑥ 是 `simple tab` 的 9 个 EV 滑杆，⑦ 是"每像素按 mask 亮度查曲线"。

**对数域是必需项**：在线性域做 guided filter，暗部被平滑得比高光多
（darktable 文档明确写了 original guided filter 的这个缺陷，eigf 就是为修它而生）。

## 3. 参数

| 参数 | 值 | 来源 |
|---|---|---|
| mask 分辨率 | 1/4 | 性能 |
| box 半径 | 短边 4%（下限 3） | darktable 建议 1–10%（eigf） |
| ε（guided filter） | 0.05（EV² 域） | 经验：太小 mask 跟噪声，太大退化成全局曲线 |
| 分区曲线 | −8…0 EV 九点 | darktable "compress shadows/highlights" 预设口径 |

曲线（EV 补偿，索引 0 = −8 EV 最暗，8 = 0 EV 白点）：

```
+0.30  +0.28  +0.24  +0.18  +0.12  +0.06  +0.02  −0.35  −0.60
 −8     −7     −6     −5     −4     −3     −2     −1      0
```

中灰（−2.44 EV）落在 +0.02/+0.06 之间 ⇒ **约 +0.03 EV**（锁定）。

## 4. 判据

1. **天空色度恢复**：同场景同机位，天空 ROI 的平均饱和度（Oklab C）上升
2. **中灰漂移 ≤ 0.1 EV**：`aeP50` 处的成片亮度变化 ≤ 0.1 EV
3. **局部对比不下降**：天空/主体交界的梯度能量不高于关闭时（无光晕）
4. **关开关逐位不变**：`toneEq()==false` 时 `applyToneEq` 直接返回原纹理，管线不插 pass

## 5. 边界与风险

- **不做语义分割**：分区只按亮度，不识别"天空"。玻璃反光、白墙也会被当高光压暗 ——
  这是 darktable 同类模块的固有行为，靠曲线幅度（0.6 EV）控制可接受度。
- **光晕**：guided filter 保边不完全时，天空与栏杆交界可能出现亮/暗边。半径与 ε 是旋钮。
- **性能**：1/4 分辨率 6 个 pass + 全分辨率 1 个 pass（预览也走），实测待补。
- **不做逐场景自适应**：曲线是固定预设，不做直方图驱动（那是下一步，需要单独验证）。
