# R-3 报告：内置预设白点 2.5~2.7 → **4.0**（消除高光死白）+ 重跑 R-1 拟合

> 用户 2026-10-12 真机：「白点默认才 2.7？那杯子高光变白的 bug 不就又出来了！」
> 工具：`recipe-fit.py`（新增 `--white-ev`/`--lat-split`/`--hi-floor`/`--hi-tol`）、`r3-white-point-refit.py`（新增；复用 R-1 的 `Evaluator` + R-2 的 `analyse`，**口径逐字沿用**）｜产物：`builtin.json`（**未 commit**）、`fit/r3*.json`

## 0. 结论（5 条）

1. **三条白点 → 4.0**（R-2 推荐值）。死白起点（R-2 判据：此后整段 8bit 极差 ≤1LSB 的起点）从 **2.60/2.45/2.40 → 三条齐平 3.55 EV**；高光层次预算 6.6/3.0/1.1 → **24.4/21.0/15.8 LSB**。
2. **"死白起点"不是白点的函数，而是"曲线何时到顶"的函数** —— 本卡最重要的实测发现。只提白点、重拟合但不加约束：死白起点只有 **3.45/2.65/3.55 EV**（理光更差：它为匹配高光目标 251.9 把曲线推到顶）⇒ 必须把"死白起点 ≥3.5EV"做成**拟合约束**（新增 `--hi-floor`）。
3. **代价**（minimax 两条链路，引擎实测 max|Δ|）：编辑器 10.46/8.40/8.98 → **14.78/17.42/12.74**；拍照 8.33/11.85/12.01 → **14.05/19.55/13.10**。理光代价最大（+9.0/+7.7），原因见 §4。
4. **亮部整体变暗**（真机口径含 LUT）：白纸 2.30EV **−17.7/−18.0/−15.9 LSB**；中灰 0EV **不变**（±1.3）。"胶片味"未变淡：高光段斜率 2.6EV 处 0.4/0.1/0.1 → **2.6/2.2/1.7 LSB/0.1EV**。
5. ★ **两套方案在 §5，请架构师/用户拍板**；本卡按任务卡默认交付方案 A（白点 4.0）。

## 4. 排除法（R-2 已证无效的两条不重复）与代价的真实来源

| 旋钮 | R-2 实测 | 本卡结论 |
|---|---|---|
| 提 `contrast` [4] | 白纸 239.2→244.0，但死白起点 2.55→**2.35**（更早） | **无效**：曲线更陡 ⇒ 更早到顶；本卡不靠它救白纸 |
| 降 rolloff knee | 白纸与上限同步降，**预算 7.5→6.7 不变**，死白起点恒 2.55 | **无效**：`kFsOut` 在 `srgbEncode` 之前，白纸与上限被同一 knee 平移 |
| **本卡真正依赖的三个旋钮** | — | ① **白点 [38]**（死白起点的上界）；② **黑点 [37] 更负**（DR 变大 ⇒ 目标曲线被挤进更窄的 e 区间，`e(2.3EV)` 0.94→0.89）；③ **shoulder/toe 解耦**（高光"晚弯"与暗部"早压"方向相反，绑定值必然二选一） |

**理光为什么代价最大（+9.0/+7.7）**：它的目标高光端要 **251.9/255**，而拍照链路 `highlightRolloff` 把上限封在 **246.53**（R-1c 已证"必然超差 ≥5.4"）。白点提到 4.0 后，"3.5EV 以上要留可见层次"与"高光要够亮"变成**同一自由度的正反两面** ⇒ 17.42/19.55 是该约束下的最优折中，不是搜索不够（2970 组宽网格扫描最优也只有 16.27，且不满足死白判据）。

## 8. 未验证项（诚实标注）

1. **未做真机验证**：全部结论来自离线工具（真编译 `computeFilmicSpline` + 真跑 `kFsFilm`/`kFsOut`/`kFsStyle`）；§6 的"观感"是 8bit 数值外推，**不是真机成片**。建议真机复拍白瓷/白墙/白纸三件套。
2. **`--hi-floor` 探针与验收口径有系统差**：探针 = 纯 filmic→rolloff→OETF→luma（无 sat/split/gamut），验收 = R-2 的完整 `kFsFilm`。标定：探针 1.00 LSB ⇔ 验收死白起点 **3.55EV**（理光）。三条探针值都恰在 1.00 边界 ⇒ 真机若更早到顶，可能只有 3.4~3.5EV。
3. **未验证**：RAW 解码/WB/CCM/LSC/HR（白点作用点在 CCM 之后，这些段只改"反射率→EV"标定）；颗粒/暗角/清晰度（工具全关）；auto 白点路径（预设 `auto_tone=0` 不走）。
4. **理光的 17.42/19.55 是"满足死白约束下的最优"，不是"可达 ±4"** —— 拍照链路 246.53 硬上限仍在（引擎级决策，R-1c 已记入 `preset-DESIGN.md` §8.5），本卡未改引擎。
5. **未跑** `--grid`：`--lat-split` 下 `R1_LEVELS` 未扩展，网格路径只在原布局下维护。
