# 高光链路验收清单

> 口径：**成片观感以用户为准**；下面每条都给出可核对的日志字段，避免"改了但没生效"。

## 待验

- [ ] **天空 / 窗外大面积高光**（2026-10-22 记，**连续阴天无法验**，等晴天）
  - 背景：0.12.14 把 `allSat` 分支的亮度锚从"满阱 luma（常数 1.237）"改成"实测 luma"，
    并把 `hl_grecon` 默认改回 1。三通道全饱和的像素现在输出"中性白 + 真实亮度"。
    镜面反光因此彻底修好，但**天空也属于"大面积饱和"**，需要确认没有被这条改动带偏。
  - 判据（三条同时成立）：
    1. 天空是**蓝/淡蓝**，不是灰白（对照 0.11.97 的"蓝天回来了"）
    2. 日志 `hlGRecon: 1`、`teqHl: -2.2`（大面积高光档）
    3. `hi240 ≤ 0.5%`（高光没有顶死）
  - 若天空变灰白：把 `allSat` 的判据从"三通道 ≥ 满阱×0.99"收紧到
    "三通道都 ≥ 满阱×0.99 **且** 该像素短帧也饱和（标记 0）"——即只对"信息真的没了"
    的像素中立化，把"有短帧真值的大面积"让回 opposed。

- [ ] **HDR 开关前后内容一致性**（承接 0.11.90 的 gainmap 改动）
  - 判据：同一张图 SDR / HDR 两版的**构图与亮度分布一致**，只有高光 headroom 不同。
