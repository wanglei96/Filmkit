# 理光正片（Ricoh GR Positive Film）标定报告 · 2026-11-01

> 目标：新建「理光正片」预设，贴近 GR 原厂观感。产出包 `filmkit-0.12.215-RICOH4.apk`。
> 与负片同一方法论：色彩归 LUT、影调归 filmic、开关归设置页；所有数字可复现。

## 1. 世代判定（先回答"一代/二代/三代"）

| 依据 | 结论 |
|---|---|
| grblog 官方样片 153 篇，含 Positive Film 的 18 篇**全部**来自 GR III / GR IIIx（2019–2025） | 可核实参数的正片样片只有**三代** |
| GR III 默认参数（3564，2019）：`Sat 0 / Hue 0 / Key −1 / Contrast +2 / Hi −1 / Shadow −2`；GR IIIx（7831）：同，但 `Contrast` 默认 `+3` | 三代内部 GR III 与 IIIx 的默认对比度差 1 档 |
| GR II 时代（2015–2018）在 grblog 无可核实样片；dpreview / Imaging Resource / Wikipedia 在本机网络 403 或不可达 | 一/二代只能靠参数与文字，无法定量 |
| 现有 `ricoh_negative_v2` 的 19 张样片来自 GR III/IIIx | **上一轮负片是三代观感，不是一代**（用户原猜测已纠正） |

⇒ **本轮以 GR III/IIIx（三代）为基准**（用户 2026-11-01 拍板）。

## 2. 样片与证据

| 来源 | 数量 | 用途 |
|---|---|---|
| grblog 18 篇含 Positive Film 的文章，逐图读图注 | 25 张正片样片 | 其中 **12 张默认参数**（无 custom / 无 WB 偏移 / 无 EV 偏移）做色彩统计 |
| 同站 7151 的 **3 组同场景 Positive↔Negative 配对**（参数相同） | 3 组，逐像素对齐相关 0.97–0.99 | 正片相对负片的色相/饱和 delta（唯一实测硬数据） |

排除：`custom`（7831 六张、2153、7284 的 M3B12）、WB 非默认（3277 Shade/Daylight）、EV ±2（7829、8102）。

## 3. 实测结论

### 3.1 正片相对负片的 delta（亮度匹配 |ΔL|<4，按色相桶中位）

| 色相桶 | Δh | C 比 |
|---|---|---|
| 红 0–30° | **−7.9°** | ×1.07 |
| 橙 30–60° | −4.5° | ×1.04 |
| 黄绿 90–120° | −10.0° | ×1.20 |
| 绿 120–150° | **−14.1°** | ×1.11 |
| 青绿 150–180° | −14.3° | ×1.07 |
| 蓝 240–270° | −0.9° | ×1.43 |
| 蓝 270–300° | +2.4° | ×1.45 |

与文章定性完全同向（7151）：正片红 = bright red（负片 = 褪色朱红）；正片绿 = 微黄绿（负片 = 强蓝绿）；正片蓝比负片浓。
**与上一轮负片实测自洽**：上轮测得"负片相对正片"蓝 ×0.67、绿 Δh +13° ⇒ 反向 1.49 / −13°，本轮独立测得 1.43~1.45 / −14.1°。

### 3.2 正片灰轴（12 张默认参数样片，低饱和像素 C*<8，按 L 桶加权）

| L* 桶 | a* | b* |
|---|---|---|
| 0–10 | +1.03 | **+1.36**（暗部暖）|
| 20–30 | +0.44 | −1.20 |
| 50–60 | −0.04 | **−1.06**（中调微冷）|
| 90–100 | −0.26 | **+0.64**（高光回暖）|

对比负片（暗 +1.1 / 中 −1.3 / 亮 −1.9）：**正片高光偏暖、负片高光偏冷**（b* +0.6 vs −1.9）。

### 3.3 影调（官方默认参数，非样片反推）

GR 正片原厂默认：`Key −1`（整体压暗）+ `Contrast +2/+3`（高对比）+ `Hi −1`（高光对比弱）+ `Shadow −2`（阴影对比弱）
⇒ 中段陡、两端柔的反转片 S 曲线。**没有同场景对照样片可定量**（见 §6 未决项），按参数语义映射到 filmic。

## 4. 引擎决定：filmic（`[98] = 0`）

| 判据 | filmic | sigmoid |
|---|---|---|
| 高光/阴影**分别**柔化（Hi −1 / Shadow −2） | ✅ `[5..7]` shoe / `[8..10]` toe 各自 latitude | ❌ 单一 sigmoid 斜率 |
| 黑白点（Key −1 + 对比） | ✅ `[37][38]` black/white EV | ❌ 无端点参数 |
| 已有正片标定参照 | ✅ 负片/徕卡都在 filmic 下标定 | — |

⇒ 正片预设**锁 `engine_slot = 0`**（与徕卡一瞬同口径；设置页「强制引擎」仍可覆盖）。

## 5. LUT：现有不可用，重烘 `ricoh_positive_v1`

现有 44 个内置 LUT 中理光系 7 个：`ricoh_cinema_green/yellow`（电影模式）、`ricoh_hdf`（高光扩散）、
`ricoh_high_contrast_b_w`（黑白）、`ricoh_vivid`（鲜活）、`ricoh_negative` / `ricoh_negative_v2`（负片）。
**没有任何"正片"LUT**；负片 LUT 的方向与正片相反（红褪色、绿偏蓝、蓝 ×0.67）⇒ 直接不可用。

新资产 `app/src/main/assets/luts/ricoh_positive_v1.lut`（64³ uint8，786464 B，TITLE「理光 正片 · 标定」），
由 `tools/bake-ricoh-lut.py --preset positive` 烘焙（与负片同一脚本、同一判据）：

- 色相表 = 负片表 + §3.1 配对 delta（红回到 29°、绿回到 134°、蓝 303°）；
- 灰轴 = §3.2 实测（暗暖 → 中冷 → 高光回暖）；
- 只做色彩，不动亮度（中灰 50% → 50%）；端点保护（纯黑不染色）。
- 判据：灰轴单调 PASS；格点最大跳变 18.0 LSB（负片 29.3，同量级；64³ + 三线性插值可接受）。

## 6. 预设配方

| 槽 | 值 | 依据 |
|---|---|---|
| `[98] engine_slot` | 0（filmic） | §4 |
| `[4] contrast` | 1.15 | GR `Contrast +2`（III）/`+3`（IIIx）取中，filmic log 域斜率 |
| `[0] exposure_ev` | −0.25 | GR `Key −1`（压暗 1/3 EV，取保守 0.25 避免过量） |
| `[5..7] shoulder` | 0.06 | GR `Hi −1`（高光对比减弱 = 过渡区加宽） |
| `[8..10] toe` | 0.10 | GR `Shadow −2`（阴影对比减弱 = 过渡区更宽） |
| `[37][38]` | −8 / +4 EV | 与负片同（实测黑位实、白点到顶） |
| `[20..22] sat` | 1.0（不写） | 降饱和/偏色全由 LUT 承担，不叠第二层 |
| LUT 强度 | 1.0 | 色彩全由 LUT 承担 |

离线曲线核对（`tools/tuning/filmic_offline.compute_spline`，black −8 / white +4）：

| EV | 负片配方（1.0 / 0.01） | 正片配方（1.15 / 0.05） |
|---|---|---|
| −1 | 0.089 | 0.078（更暗） |
| 0 | 0.185 | 0.185（中灰锚定不动） |
| +2 | 0.585 | 0.634（更亮） |
| +3→+4 段 | +0.143 | +0.112（高光更柔） |

## 7. 未决项（下轮怎么定）

| 项 | 为什么没定 | 怎么定 |
|---|---|---|
| 正片**目标曲线** | 没有"我们引擎 vs GR 正片"的同场景对照；7151 配对只能证明 Positive≈Negative 的曲线形状 | 拍 6 题材 RAW（同场景 GR 正片 JPEG 对照）后重跑 `recipe-fit.py` |
| `contrast` / `toe` / `shoulder` 定值 | 只能按 GR 参数语义映射，无实测 | 同上；或用 §7 实拍清单逐步收敛 |
| 红/黄 delta 的独立验证 | 配对只有 3 组场景（蓝天空、绿植、街景），黄色样本少 | 找 Positive 的黄色主体样片补统计 |
| GR III 与 IIIx 的 `Contrast` 默认差（+2 vs +3） | 只能选一档 | 实拍对照后二选一 |
| 一/二代正片 | 无可核实参数样片 | 若要做"老理光味"，需另找一手样片（当前网络不可达） |

## 8. 实拍验证清单（给用户）

1. 强光街景（红招牌 + 蓝天）：红应是**正红**（非负片的褪色朱红），蓝清透但不过饱和；
2. 绿植 / 阴天：绿应**微黄绿**（负片是蓝绿），两张同场景切换对比最直观；
3. 人像：肤色应比负片略暖、对比略高，不应发灰；
4. 高光（天空/白墙）：不应死白，但整体比负片暗约 1/3 EV；
5. 与 0.12.214 的负片并排：两者差异应**一眼可辨**（红/绿方向相反）。
