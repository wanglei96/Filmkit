# 徕卡一瞬 0.12.90：真机"艳俗 / 不油润"诊断与重标记录

日期：2026-10-26。触发：用户 4 张成片（`test_temp/FILMKIT_20261026-*_徕卡M9CCD.jpg`）反馈——
"观感很艳俗，没有油润厚重感，彩噪有变好"。

## 1. 先说一个会让验收失真的硬问题（已修）

日志 `filmkit-engine-20261026.log`：4 张里只有第 1 张（095908）跑在 0.12.89 的影调上。

| 张 | 名字 | raw.render blackEv/whiteEv | 结论 |
|---|---|---|---|
| 1 | 095908 | **−4.879 / 4.0** | 预设生效 |
| 2 | 100003 | −7.801684 / 4.564171 | **掉回代码默认** |
| 3 | 100030 | −7.801684 / 4.564171 | 同上 |
| 4 | 101130 | −7.801684 / 4.564171 | 同上 |

根因：`setFilmParams` 写入预设 `[37]/[38]` 后，同一调用链里的 `applyZebraPref()` →
`applyFilmicRangePrefs()` 首次从设置页 prefs 读值并把预设值**无条件冲掉**。只在冷启动
（相机/Activity 重建）后第一次 `setFilmParams` 触发——用户拍完第 1 张看相册再回相机，后
3 张就都用了默认黑白点。修复：`setFilmParams(..., presetFilmicEv)` 显式携带预设黑白点，
`applyFilmicRangePrefs` 让预设优先（用户改设置页滑杆时再让 prefs 赢）。

## 2. 样张 vs 成片的差异（同口径 CIELAB，长边 1000px）

样张 = `docs/research/leica-m9-samples/`（Xiaomi 17 Ultra by Leica 水印；**是否全部
「徕卡一瞬」模式未能在图内证实**，ifanr 8 张与 ithome 12 张的来源文章待补链接）。

| 指标（链） | 我们的 4 张 | ifanr 样张（典型） | 读法 |
|---|---|---|---|
| 高光局部对比 hp（L>70） | **0.3~0.9** | 1.7~7+ | 我们的高光被压成平色块（云/白墙） |
| 暗部局部对比 hp（L<20） | 1.8~4.2 | 0.3~3.3 | 我们的暗部过渡更硬 |
| 中间调占比（L 60–80） | 101130 占 68% | 多数 < 15% | 我们的中高段整体偏亮 |
| 全图 C*P90 | 16~26 | 10~31 | 总量不高，但**纯色物体**（红/蓝/绿）C* 达 47~84 |
| 中性 cast（a*, b*） | ≈0 | 暖 +2~+7 / 冷 −7 | 我们太中性，缺"一点点偏色" |

结论：**"艳"不是全图饱和超标，是高纯度色块 + 中高段偏亮 + 高光死平**；"不厚重"是
高光没有层次、暗部过渡硬、缺暖调和低对比的胶片底子。ifanr-18（暖光室内）是"油润"的
好参照：白墙是暖灰（L 60~70）而不是近白，暗部有暖色细节，红是砖红不是纯红。

## 3. 0.12.90 参数（单链拍照拟合 + 观感约束）

`recipe-fit --mode camera --white-ev 4.2 --lut-min 0.85 --lat-split --hi-floor 3.0 --hi-tol 1.5`：

- 白点 4.0 → **4.2**、高光层次判据 1.0 → **1.5 LSB** ⇒ 实测 **8.80 LSB**（原 1.56），修高光平；
- 黑点 −4.879 → **−5.1725**（暗部更透气）；
- contrast 1.188 → **1.1974**；shoulder 0.0056/0.0013/0.1064（更柔的肩）；
- LUT 1.0 → **0.9466**（高光层次约束下拟合器自己收的，保 M9 色相）；
- 分区饱和 **暗 0.7 / 中 0.6 / 高 0.7**（拟合器实测 LUT 色度增益 1.53× ⇒ 压回 ~1.0）；
- 新增 `temp_mired 1.2`（暖偏色）、`fade 0.04`（提黑位的褪色感）；
- 分离色调暖 0.12 / 冷 0.04；暗角 −0.18 → **−0.21**；颗粒 20 / ISO160 不变。

残差：拍照链 3.06 LSB（0.12.89 为 3.13）；编辑器链 35.43（已知记账，未恶化）。

## 4. 验收方法（这次请这样拍）

1. 同一场景、**固定机位**，先「标准」再「徕卡一瞬」，各一张（避免像昨天 21:04 那样
   两张都在切标准之后）。
2. 日志里核对 `camera.preset.apply` 的 `filmic=-5.1725/4.2` 与每张 `raw.render` 的
   `blackEv/whiteEv` —— 这次新增了 `filmic` 字段，冷启动丢参数会当场露馅。
3. 重点看：白墙是不是暖灰而不是纯白、云/灯管有没有层次、暗部是不是"深但有东西"。

## 5. 下一步（若这一版仍有偏差）

- 若仍嫌艳：LUT 强度 0.85 → 0.80 + 局部色相（红/蓝单独收）——不要全局再压饱和。
- 若嫌不够暖/厚重：`temp_mired` 1.2 → 2.5、`fade` 0.04 → 0.08（一次只动一个）。
- 样张甄别：补齐 ifanr/ithome 原文链接，剔除不是「徕卡一瞬」的图后再重算指纹。
