# Vulkan 分块递归的同 RAW 验证

2026-11-26，vivo V2509A / Mali-G1-Ultra MC12。Android Vulkan 扩展未报告 `VK_KHR_performance_query`，Perfetto 的 GPU 数据源提供内存用量，缺少外部内存读写计数。用 Vulkan 时间戳比较完整命令区间。该区间也包含 GPU 调度等待，无法量化实际 DRAM 读写或把差值归给单一因素。

## 候选

沿用上轮 CPU 计算 G/B、Vulkan 处理 R 的完整曝光和 DIR 支路。分块方案使用 Nehab 等人论文 Algorithm 3 的边界状态传递。每轴先并行计算 64 像素块的正向和反向摘要，再沿行或列传递两端状态，最后以真实状态并行重建每一块。正扫中间像素在 workgroup 内存中供同块的逆扫使用。行列之间仍保留整图中间平面，各半径独立执行。原 Young–van Vliet 递推、初末边缘条件、全部半径、权重和 FIR 路径均保留。GPU 空间中间值为 FP32，CPU 显影仍是 FP64。两种 Vulkan 方案分别在曝光与 DIR 各提交一次。 [Nehab 等人论文](https://hhoppe.com/recursive.pdf)

## 真机性能

同一 3072×4080 室内四帧 RAW，两配方，关颗粒，HDR，8 位，PC3D 与额外阶段同步关闭。两次交错进程／配方／后端，每进程处理两张，起止热状态均为 0。表中为同张次中位数。首轮复用手机当时的界面状态，未固定屏幕唤醒状态，且部分相同配置的整链样本差异较大。合成取景间隔来自回放程序。整链为 RAW 引擎，范围止于成片输出，包含 HDR 生成，实际应用的相机采集、JPEG/R 封装与系统保存另计。

## 画质与留存

固定四张 DNG 人像 110832、室内绿植 110846、建筑 110904、鲜花 110936。两配方与两色深共 16 组完整单 RAW 回放。原尺寸 RGB 最大差 1 码，最坏 786／37,601,280 通道改变，最大全图平均绝对差 0.000021 码。16 张 HDR 增益图逐字节一致，回放 JPEG 解码最大差 6 码，最坏全图平均绝对差 0.000128 码。整图及 1:1 裁块目视无明显变化。GPU 递归块长只验证了此次输入尺寸，其他尺寸和机型未进入验收。

证据在 `test_temp/spektrafilm-vulkan-block-iir-20261126/`。包括 `spatial-block.patch`、`replay.sh`、`perf.json`、`no-preview.json`、`quality.json`、原始日志、裁块和无损输出归档。删除前校验了 48 个重复基线输出和四个衍生 Bayer；原片与现存基线归档继续保留。Vulkan 1.1 SPIR-V 校验通过，常规 ARM64 构建通过。手机版本为 0.14.56（853）。
