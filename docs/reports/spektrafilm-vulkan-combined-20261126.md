# Vulkan 成片链：把两端的收益放到同一次真机回放

2026-11-26 · vivo V2509A / Mali-G1-Ultra MC12 · 手机上保持 FilmKit 0.14.56（853）。

**结论：组合路线的引擎提速在此夹具上复现；首张相对现版只省 66／95 ms，不是快门到保存的体感提升，不发包。**

## 测试路线

- **关**：现有 GLES RAW 前链；CPU FP64 投影和扫描尾段。
- **现版开**：同一 RAW 前链；成片 HDR 场景分带读回，Vulkan 投影，CPU 扫描尾段。
- **组合**：RAW 末端直接写 RGBA16F AHardwareBuffer，由 Vulkan 原地投影；完整曝光、DIR、印相／扫描光谱仍为 CPU FP64；扫描颜色、完整 FIR/USM、量化、打包及 HDR 底图连在第二段 Vulkan，CPU 准备下条带与上一条带的执行重叠。保留本张增益图的真实消费者。不是全链 Vulkan，不叠加已撤回的 D1 融合或改变降噪。

三路线用同一个 ARM64 实验库。固定室内 3072×4080 四帧 RAW、HDR、8 位、PC3D 和颗粒关，30 Hz 合成预览并发。每配方四块，每块三路线交错，每路线每进程两张，共 48 张；24 个进程起止热状态均为 0、屏幕亮。同一组按首张／第二张分别统计。确认组合的 Vulkan 投影处理完整 12,533,760 像素、走直接共享、双输入扫描实际运行、HDR 增益图生成；无诊断同步读回。早期试跑漏开 AHB 编译选项，未计入；正式批的每次分支均由日志核验。

## 整引擎结果

| 指标，首张／第二张 | Gold 200 / Endura | Provia 100F 直扫 |
|---|---:|---:|
| Vulkan 关：引擎中位数 | 2544／2686 ms | 2162／2102 ms |
| 现版开：引擎中位数 | 2476／2435 ms | 2124／2037 ms |
| 组合：引擎中位数 | **2432／2252 ms** | **2031／1885 ms** |
| 组合比现版开快：块内配对中位数 | **66／201 ms** | **95／159 ms** |
| 其中改动的两段时间合计：现版开→组合配对差 | 115／134 ms | 77／133 ms |
| 合成取景 P95：现版开→组合 | 45.8→46.9／48.1→44.1 ms | 48.6→48.2／45.7→43.5 ms |
| 合成取景最长间隔：现版开→组合 | 62.5→60.5／82.6→65.9 ms | 57.4→59.7／63.2→63.8 ms |

- 表中「其中」是按每样本计算「读回＋Hanatos」和「扫描输出＋打包＋HDR 增益图」之和，再按同块配对取中位数，不能直接用群组中位数做差。Gold 第二张对关闭的整引擎配对差约 440 ms，其中被改两段约 196 ms，其余阶段的波动很大；不把 440 ms 当成 Vulkan 可归因收益。Provia 第二张对关闭的整引擎配对差约 220 ms，被改两段约 196 ms。
- 组合相对现版开的 16 次同块、同张次整引擎对照均为正向，但首张配对中位数不到 0.1 秒，第二张不到 0.21 秒。合成取景未见两配方一致退化，不能代替 App 取景验收。
- 引擎计时不含快门采集、App JPEG/R、EXIF 或 MediaStore。历史同机 Vulkan 开的两张实拍，曝光＋DIR 为 2.138／2.290 秒，回放组合的第二张约 0.681／0.663 秒。这不是一个可相减的因果对照，却足以说明外部回放不能代替 App 内真实负载。下一步若要做出半秒级首张改善，应在 App 进程同 RAW 测真实的 CPU 执行与等待、GPU 队列与交接，再选择改动；不能用换 API 这件事本身作为性能预测。

## 画质与留存

四张指定 DNG（110832 人像、110846 室内绿植、110904 室外建筑、110936 鲜花），两配方、8/10 位共 16 组。组合的全尺寸 RGBA、HDR 增益图和回放 JPEG **48/48** 逐字节匹配历史同 RAW、已验过像素差的 Vulkan 扫描路线。四帧性能回放两配方也逐字节匹配历史同四帧 Vulkan 扫描路线；三路线之间的 HDR 增益图逐字节一致。扫描启用后 RGBA/JPEG 哈希不同于当前的 CPU 尾段，不声称和 CPU 逐字节一致；上一轮针对相同四张 DNG 的 CPU 对照验证原尺寸 RGB 最大为 1 码，见 [扫描尾段画质](spektrafilm-vulkan-front-scan-20261126.md#画质与证据)。

实验代码撤回，重编的常规 ARM64 库 SHA-256 与开工前一致，Vulkan 支持检测及 Ultra HDR JNI 保留。没有发包或安装、没有代按快门。手机只清理本轮回放目录，充电常亮恢复为 0。校验原片和送测哈希后回收约 96 MiB 本轮生成文件，证据目录约 10 MiB；四张 DNG 原片均未改动。
