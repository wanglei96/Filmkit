# Spektrafilm：RAW 高光准入等价 SIMD

2026-11-25，vivo V2509A；生产对照 0.14.53（850）。只改拍照成像的共享 RAW 阶段，没有改取景、采集、光谱或保存。目标不是把局部 SIMD 倍率算作成像收益，而是验证它有没有减少两条成片路线的关键路径等待。

## 选择的路径

0.14.53 两张实拍中，Gold 200 / Endura 和 Provia 100F 直扫的 `totalMs−branchMs` 分别约 2.01 / 2.03 s；其中高光准入 462 / 546 ms，guide join 104 / 97 ms、双向配准 105 / 168 ms、掩模 175 / 188 ms。`uploadMs` 覆盖 RAW 上传到融合前的同步、配准、准入和 mismatch；`frontSubmitMs` 在 `finishStillChain` 内从 t1 到光谱入口；两者都不是 GPU 实际执行时间。首条 `glReadPixels` 仍可能包含同一 RAW 的未完成 GPU 工作（实拍约 97 / 68 ms），且计在光谱 `branchMs` 内。未给候选添加阶段 `glFinish`，也未提前提交 mismatch 或用旧帧统计。

1. **SAD**：小 tile 的同一行搜索将横向候选放进 SIMD lane，不是上轮针对单候选的八采样点尾部。整数累计无溢出，候选仍按原 dy / dx 顺序选最小；已有整数分数供亚像素邻域复用。出搜索框的邻居及靠边位置仍用原夹边计算，不改 L4、采样相位、搜索窗口或双向几何。
2. **Guide**：以四个独立横向输出像素并行，不合并 3×3 RGB 矩、18 个绿色观测或两套短帧 guide。依旧保留噪声 LUT、裁切哨兵、方差符号和每次 binary16 存储舍入，不把 FP32 运算改成 FP16。镜像横边、尾部及非常规浮点控制使用原标量代码。
3. **掩模**：把每像素重复的位移归一和 binary16 往返提到每格一次，对全部格子验证有限性；guide 有限性检查向量化。没有改镜像双线性、阈值、连通域、合并掩模下采样或 GPU 融合。本项之前只确认局部快，这轮作为组合复测，不能把组合收益单独归给它。

## 对照口径

四帧、3072×4080、颗粒关、HDR 开、独立 still context、有合成 30 Hz 取景，冷全尺寸目标但已暖小图 shader。用实际裁切白灯罩 burst 和无有效裁切的正常室内 burst，各跑 Gold 印相与 Provia 直扫。A 从 0.14.53 APK 校验一致，B 是候选，按 ABBA/BAAB 交错，按始末热状态 0 核查。回放不测快门采集、Android 应用调度或 MediaStore；不能拿回放绝对时间替代用户拍摄时间。

单独 SAD：真机微基准高光 tile 单向由 24.3 降至 7.9 ms（生产基线算法，而非刻意关闭 NEON），完整位移场和统计一致；真实灯罩回放的双向时间少约 14–24 ms，但整引擎没有两路一起稳定加快。SAD + guide 初版：灯罩两路的准入少约 70–75 ms，无裁切室内原本的 guide join 就约 0 ms。初版 Gold 有较慢的未改光谱样本和合成取景长帧，不能以初版 as-is 交付。

## 画质及边界

- Android ARM64：12,000 组八 lane 分数对标、旧 SAD 的 12,000 组随机 / 1,134 组全宽、72 组真实路径的完整位移及残差逐位对照；2,048 组四种 CFA、奇数尺寸、裁切临界、曝光和浮点模式的 guide 逐位对照。全尺寸 4096×3072 和 80 组小图的 RGB、signed variance、裁切和掩模二进制快照一致。
- Host 高光恢复 4,715 项、高光几何 301 项通过。Release JVM 测试 851 项（2 跳过，0 失败）。
- 单独 SAD 16 次、加 guide 16 次、组合 8 位 32 次的同 RAW 回放全部匹配原尺寸 RGBA、HDR 增益图和回放 JPEG 哈希。先验证是原始真实白灯罩 burst；不使用人为衰减后会发品红的替代 RAW。
- 最终组合另做默认链 10 位 8 次、PC3D+CS+CM 真灯罩 8/10 位 8 次，均与各自 0.14.53 输出哈希一致；最终组合共 48 次（含 A/B）。RGBA、增益图与 JPEG 逐字节一致，不以目测替代同 RAW 验证。追加 Android 合同 4,715 项、掩模 240 组逐位、108 组非法输入及 4096×3072 全尺寸逐位通过。独立高覆盖合成图的同进程 ABBA/BAAB，guide 与掩模合计中位 194.34 → 142.92 ms，算法级结果相同；该场景不是实拍。
