# 0.14.20：当前帧高光引导行缓存

0.14.19 云边品红修复已获用户两张实拍验收；恢复性能优化。0.14.20 / 817 已成功
安装并核实版本。本轮质量参数、帧数、采样、浮点精度、短帧准入政策、DNG 用户偏好均不改。
**目标仍未达成**：三张新样本均超过 5s，处理期与启动预热也仍存在预览停顿。

## 改动与质量边界

重新对照 PC `GlesMgcRawSpatialShaders.guide` 完整四相位/3x3 统计路径。
仅在 `highlightGenerateGuide` 的当前调用、每个工作线程内缓存三行校准 CFA 四元组，
消除相邻输出重复读取 RAW/校准的工作。不是缓存成片、上一张统计或协方差近似。
反射中心、奇数 RAW 尾部 clamp、全部 RGB 二阶矩、18 个 green 观测、噪声 LUT、
signed variance 分支、binary16 存储及逐样本累加顺序保留。三个独立曝光域仍分别完整生成。
4096 宽时额外缓存上限约 0.75MiB，调用结束即释放。不采用 ponytail 简化成像链。

## 实际 App 拍摄

用户确认手机固定、静止场景、相机页，可自动采样。两版各三张；当前场景均完整执行
短帧高光准入后报告 `no_clipped_pixels`，不等于覆盖了真实高光恢复所有成本。
输出均 3072x4080、理光正片标定。下列帧率只统计完全包含在合成期的约 1s 窗口；
全流程间隔来自与快门到保存重叠的窗口，可能含少量窗口边缘样本。

133.31ms，仍不能称预热流畅。本轮没有靠延迟统计、降低预览分辨率或丢成像工作换速度。
