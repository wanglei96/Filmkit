# Spektrafilm 0.14.44：印相和扫描光谱积分提速

对比 0.14.43 / 840；候选为 0.14.44 / 841，2026-11-23 安装至 vivo V2509A。

## 实现

- 大尺寸 ARM64 成片按锁定上游 `3bb2c2d2801ff68b92019cf1dbcbb133d60832bc` 的 PCHIP 方式，分印相曝光和扫描两段构建 `49³` FP64 表。各节点做完整光谱积分，越界直接积分；不重用图像统计，不改曝光、显影、滤波、颗粒或 RAW 融合帧数。
- 表内对数亮度沿用 FP64 向量指数解码。HDR 中性响应保留 1024 个完整求值点，四线程并行；扫描眩光保留原随机数顺序，只并行指数变换。未改取景调度。

## 实测

3072×4080、四帧同源 RAW、HDR 开、颗粒关、并发合成取景，按旧、新、新、旧交错回放；各轮 Thermal Status 为 0，未固定频率。时间为两次中位数。

| 路径 | RAW 回放到 RGBA（`RENDER elapsed_ms`） | 印相曝光 | 光谱扫描 | 处理期合成取景最长 GPU 完成间隔 |
| --- | ---: | ---: | ---: | ---: |
| Gold 200 / Endura | 4.847 → 3.977 s（耗时 -18.0%） | 453 → 146 ms | 466 → 145 ms | 111 → 69 ms |
| Provia 100F 直扫 | 3.807 → 3.530 s（耗时 -7.3%） | 不经过 | 487 → 142 ms | 118 → 71 ms |

计时不含实体快门、相机采集、编码和落盘；合成取景不代表手机屏幕实际跟手程度。带颗粒的单次对照虽然缩短了光谱段，整段只少 22 / 58 ms，未证实整体有明显提升。

## 画质判定

- ARM64 签名包内引擎和桌面参考分别测了 132 款可用配方的 147 组合成对照；ARM64 最大 ΔE00 约 0.014，最大未量化通道差小于 0.025 个 8 位码阶。两条路径的串行、并行 HDR 参考探针输出逐点一致。
- Gold / Provia 全尺寸同 RAW：无颗粒、有颗粒和 10 位各自对照，渲染输出最大差一个对应位深的码阶，增益图逐字节一致。无颗粒 JPEG 解码后局部最大差 5 / 6 个 8 位码阶，16×16 块均值最大差约 0.10 级。整图以及最大差值附近 1:1 并排未见偏色、变淡或明显细节变化，本批差异可接受。
- 实拍色彩、曝光和主观跟手程度待用户确认。系统相册个别照片变暗未纳入本次改动。
