# Spektrafilm 0.14.47：扫描输出和预览调度

基线为已通过移动实拍成片验收的 0.14.46（843）；新版为 0.14.47（844）。

## 改动

- ARM64 扫描输出使用固定指数 FP64 SIMD：按尾数分 256 段，预计算段中心和二进制指数倍率，以五阶二项式计算段内残差。特殊输入和超出范围的输入仍用原 Arm 向量 `pow`。CAM16 逆变换以同一对立色半径恢复两轴，去掉重复除法，不改色相、色域压缩或 sRGB 曲线定义。
- 六级色度小波的水平和垂直趟都用现有 scissor 条带提交，每趟八条。保留所有波段、tap、精度和原着色器；未更改采集请求及当前帧取景统计。
