# 理光负片（Ricoh GR Negative Film）标定报告 · 2026-11-01

> 目标：在**没有固件配方、没有 RAW 配对**的条件下，把「理光负片」预设从旧的自创配方
> 重标为贴近 GR 机内观感的版本。产出包 `filmkit-0.12.213-RICOH2.apk`。

## 1. 样片与证据

| 来源 | 数量 | 用途 |
|---|---|---|
| GR Blog（grblog.jp）8 篇文章，逐图读图注 | 19 张**标准** Negative Film | 灰轴偏色、亮度分布、黑白点 |
| 同站 7151 的 3 组「同场景 Positive↔Negative」 | 2 组可像素对齐（相关 0.99） | 蓝/绿的色相与饱和度 delta（实测） |

排除项：所有 `custom` 标记、以及图注带非默认参数（Hue±/Sharpness±/Saturation±/Contrast±）的图。
第一版曾用 12 张（其中 5 张 custom +B5）定目标，方向被骗（把「加蓝 5」当成模式本身），已废弃。

## 2. 实测结论

**2.1 亮度传递（Positive → Negative，逐像素按亮度分档）**

| Positive 亮度 | Negative 亮度 | Δ |
|---|---|---|
| 0–50 | 15.8 → 53.8 | +2 … +9 |
| 75–125 | 98.9 → 123.1 | +9 … +16 |
| 175–250 | 188.1 → 231.1 | ±0 |

⇒ **Negative 与 Positive 的曲线几乎相同**（中调略亮 10~16/255，高光不动）。
Negative 的味道在**色彩**，不在曲线。此前的「低对比 / 抬黑 / 柔高光」假设来自 custom 样片，错误。

**2.2 黑白点（19 张的中性像素 C\*<10）**

- L\*<5 占 **20.7%** ⇒ 黑位实，不抬黑；
- L\*>95 占 5.96%，p99.5 = 99.7 ⇒ 白点到顶，不压白。

**2.3 灰轴偏色（同上，按 L 分桶取中位）**

| L* | a* | b* |
|---|---|---|
| 5 | +0.5 | **+1.1**（暗部微暖）|
| 35 | +0.8 | −0.4 |
| 55 | 0.0 | **−1.3**（中调偏冷）|
| 85 | −0.8 | **−1.9**（亮部偏冷）|

**2.4 色相/饱和度 delta（2 组配对实测）**

| 色相 | Δh | C 比 | 出处 |
|---|---|---|---|
| 蓝 | −4° | **×0.67** | 实测（官方 "muted blue"）|
| 绿 | **+13°** | ×0.90 | 实测（官方 "strong bluish tint"）|
| 红 | （无配对）| ×0.92 | 文章定性 "faded vermilion"，推断 |
| 黄/青/品红 | （无配对）| 0.86~0.90 | 按邻近色相推断 |

## 3. 参数决定表（完整版）

| 槽 | 参数 | 定值 | 依据 |
|---|---|---|---|
| [4] | contrast | 1.0（基线）| 2.2 的黑白点已到端点；无证据要求偏离 |
| [5..10] | shoulder / toe | 0.01（基线）| 2.1：Negative 无额外曲线形状 |
| [20..22] | 三段饱和 | 1.0（基线）| 降饱和已由 LUT 承担（蓝 ×0.67、绿 ×0.90），不叠第二层 |
| [23][24] | 分离色调 | 0 | GR 直出无此层；旧配方 0.41/0.6 是自创 |
| [26][27] | 颗粒 | 0 | GR Negative 直出干净 |
| [34] | LUT 强度 | 1.0 | 色彩全由 LUT 承担 |
| [37][38] | filmic 黑白点 | **−8 / +4 EV** | 2.2 实测：黑位实、白点到顶，与 darktable 出厂一致 |
| [66..68] | 暗角 | 0 | GR 直出无 |
| [88] | 色温偏移 | 0 | 灰轴偏色已由 LUT 的 a\*/b\* 曲线承担 |
| [94] | 褪色 | 0 | 同上（旧配方的 0.04 是自创）|

## 4. LUT

`app/src/main/assets/luts/ricoh_negative_v2.lut`（64³ uint8，`tools/bake-ricoh-lut.py`）：

- 灰轴：按 2.3 的实测 a\*/b\* 曲线，L→0 处衰减到 0（保证纯黑不染色）；
- 色相：按 2.4 的表做局部旋转 + 饱和缩放，360° 周期平滑（格点跳变 29 LSB）；
- 只做色彩，不动亮度（中灰 50% 输入 → 50% 输出；旧 LUT 会把它提到 59%）。

## 5. 未决项

| 项 | 为什么没定 | 怎么定 |
|---|---|---|
| 对比度 [4] | 缺「同场景」的我们 vs GR 对照 | 拍 6 个题材各一张 RAW，按题材取区域指标反推 |
| 三段饱和 [20..22] | 同上（LUT 已降部分，余量未知）| 同上 |
| 红/黄/青/品红的 delta | 只有文章定性，无配对样片 | 找到对应题材的 Positive/Negative 配对，或真机对照 |

## 6. 复现

```bash
python3 tools/bake-ricoh-lut.py            # 重烘 LUT + 判据
python3 tools/bake-ricoh-lut.py --preview <成片.jpg>   # 套一张看观感
```
