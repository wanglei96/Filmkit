# Spektrafilm 0.14.45：FP64 曝光和滤波提速

对比 0.14.44 / 841；新版为 0.14.45 / 842。

## 实现

- 胶片和相纸曝光采用已锁定 Arm Optimized Routines 的 FP64 AdvSIMD `log10`；sRGB 编码复用 FP64 向量 `pow`，保留原分段和颜色矩阵。
- 小核合并对称项，保留所有采样和反射边界。加权宽核让前向递推连续写入既有工作区，不改递推、系数或边界。
- 成片直接写满两个 FP64 缓冲；在本次 3072×4080 样本省去约 602 MB 的初始化写入，不新增全图拷贝。未改 RAW 融合、曝光统计、颗粒和取景调度。

## 实测

vivo V2509A，3072×4080、四帧同源 RAW、HDR 开、颗粒关、并发合成取景。旧、新、新、旧交错，各次 Thermal Status 为 0，未固定频率。时间取每版两次中位数。

| 路径 | RAW 回放到 RGBA | 耗时降幅 |
| --- | ---: | ---: |
| Gold 200 / Endura | 4.123 → 3.648 s | 11.5% |
| Provia 100F 直扫 | 3.521 → 3.281 s | 6.8% |

回放不含相机采集、编码或落盘。合成取景最长 GPU 完成间隔指标，Gold 平均 174 → 73 ms，Provia 67 → 89 ms，不能据此声称取景普遍改善。开颗粒和 10 位各跑一对，作为画质覆盖，不作为稳定速度结论。

## 画质与交付

- 两条路径的全尺寸 8 位无颗粒、8 位有固定种子颗粒、10 位无颗粒对照中，像素、HDR 增益图及回放编码的 JPEG 全部逐字节一致。10 位对照比较的是打包 RGB10_A2 与增益图，不是 HEIF 编码器。
- ARM64 132 个配方、147 组对照的最大 ΔE00 为 `1.57e-12`，最大未量化通道差为 `6.22e-12` 个 8 位码阶；新版 vector 接口与成片缓冲接口的一致性检查通过。滤波探针最大绝对误差 `1.78e-15`。
- Release 构建及 JVM 测试完成（851 项、0 失败、2 跳过）。APK v2/v3、版本、DEX、四个 JNI 符号和 FP64 `log10` 核验通过。包内 ARM64 库与回放构建产物字节一致。
- `adb install -r` 覆盖安装，未清数据。根目录保留 0.14.44 回退版，0.14.43 移入证据目录归档。
