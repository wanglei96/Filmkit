# Spektrafilm 关颗粒整链：扫描查表与高光前链

2026-11-25，vivo V2509A，0.14.51（848）APK 的 ARM64 库为基线。优先看两条配方共用的链路，不重做 RAW 与光谱重叠、不改变 MFNR、去马赛克或 HDR 的质量设置。实拍参考是此前关颗粒的 0.14.50：Gold 200 / Endura 7.442 秒、Provia 100F 直扫 6.274 秒，从快门到保存。下面的新旧对照是真机回放，不含相机采集、实际取景和 MediaStore，不可与上述实拍直接相减。

## 扫描输出：首次初始化和逐张成本必须拆开

候选采用 65³ 节点、平方根分布和四面体插值；每个节点执行原完整 CAM16 色适应、J/C 压缩与逆变换；负通道、超范围和经验误差筛查不通过的格子继续执行原模型。筛查不是误差上界证明。没有删散射、光晕、DIR、扫描锐化、HDR 计算。两条路线在同一份 4 帧实拍 RAW 上查表命中约 93.5% / 95.4%。

- **把建表放在首次成像内**：ABBA、每版每配方各两次，CAM16 中位数 Gold **319 → 260 ms**，Provia **303 → 255 ms**。Provia 整引擎略慢；Gold 的总差大于改动范围，不能归因给查表。
- **把建表移到进程启动**（性能探针，不是产品加载实现）：BAAB、每版每配方各两次，CAM16 Gold **536 → 96 ms**、Provia **536 → 82 ms**。Provia 整引擎 **4.652 → 4.229 s**；Gold **5.701 → 6.014 s**，两次候选中未改 RAW 前链的首轮比对照慢约 0.9 s，不能用这组样本确认两路线整链收益。
- 新旧每路线均从完全相同的四帧 RAW 开始，8 位回放 RGB **最大差 1/255，平均绝对差 0.032 / 0.030 个码值**，只变动约 3.2% / 3.0% 的 RGB 通道值；HDR 增益图分别 5 / 3 个像素差 1 个码值。两路线的 SDR 全图和 100% 暗部对照未见明显差异。这是同一场景，不是全配方视觉覆盖；压缩 JPEG 不再逐字节相同。合成渐变／宽亮度测试有少数极值：锐化＋OETF 后 FP64 最大差约 1.10 个 8 位码值，量化后的 10 位最大差 3 码，不能把实拍的 8 位结果当 10 位或强饱和色的保证。

### 同进程重放，单独确认逐张开销

使用同一候选库、同一 still renderer、相同四帧 RAW 和预建表。先让原算法和查表各热身一次，再按原／查／查／原切换。该探针**没有并发取景**；与上一组独立进程、有合成取景的测试互补。每批两端热状态 0。以下为每版两次的中位数：

| 路线 | CAM16，旧 → 查表 | RAW 引擎，旧 → 查表 |
| --- | --- | --- |
| Gold 200 / Endura | 588 → 101 ms | 5.387 → 6.090 s |
| Provia 100F 直扫 | 624 → 79 ms | 4.225 → 3.532 s |

Gold 两次候选引擎是 7.420 / 4.760 s。慢样本的 **DIR 在扫描前耗时 3.059 s**，同批另三个计时样本 0.571–0.805 s；CAM16 当次仍只有 109 ms。表在四次计时都已分配，不因开关改变；缺页统计只覆盖整进程，不能把 DIR 长尾归因给查表或认定是缺页。不能删掉这一样本后宣布 Gold 整链提速。Provia 在两种测法里整引擎都变快（约 0.42–0.69 s，不能把全部差额都归给查表）。两条路线在两种测法里都复现了 **CAM16 本段少 0.44–0.55 s**。同进程两路的 JPEG 哈希也复现独立进程所见的新旧输出。

若拿到可发布的收益，须把建表改成离线预制（也要单测冷加载、内存和取景），再做 132 配方／147 参数、HDR 中性响应、8/10 位与更多场景检查。不能把进程启动增加的成本当成已经消失。

## RAW 前链：相同高光判断，减少重复工作

不减帧、不减搜索、不放宽高光准入。对齐位移按原归一和 binary16 舍入**每格只做一次**，连无高光格也验证有限性；完整掩膜的有贡献像素、阈值和连通区域规则不改。合并掩膜预计算双线性坐标，保留 R8 互补量化与 3×3 边界定义；另在默认 FPCR 试 ARM64 原位二进制半精度转换及向量有限性校验。不是把内部计算改成 FP16，只替换已有的 FP16 存储往返。

- 4715 项高光合同、240 组逐位对照、108 项非有限输入拒收及 4096×3072 合成前链逐位对照通过。四帧 RAW 含真实裁切、两条路线各 ABBA：全部 **4 次候选及 2 次基线重复** 的 RGBA、HDR 增益图、JPEG、诊断统计逐字节一致。
- 高光掩膜评估中位数：Gold **60.5 → 26.0 ms**，Provia **58.2 → 22.7 ms**；高光准入总计 **304 → 192 / 292 → 219 ms**，含其它未改阶段及等待。同进程独立合同探针里包含诊断的掩膜评估也更快，不能把 guide/对齐或未改光谱的波动记成提速。全部运行始末热状态 0，但进程最多约 14.3 万次 major faults；未得出稳定整链收益，不作为单独发布候选。

## 决定

查表保留为优先候选，不合入或出包。当前两项实验已恢复生产源码，重编 ARM64 Release 与 0.14.51 APK 库逐字节一致。未安装、未改手机设置或素材。后续优先做离线表和冷加载，并单独测 Gold 的 DIR 逐阶段等待与内存压力，验证两条路线各自的快门到保存及取景；不把启动挪动或局部提升包装成整链已达标。
