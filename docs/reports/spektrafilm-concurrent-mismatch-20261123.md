# 成片期间的预览卡顿：MFNR 运动残差

2026-11-23，vivo V2509A / Mali-G1-Ultra。基线已包含 R8 对齐金字塔和 NEON SAD。本轮未更改或覆盖安装 0.14.42。

## 实现

- 运动残差 pass 保留完整视口、CFA 各相位采样、原生码饱和阈值、四点插值及残差/噪声归约顺序。相同纹理码同时用于饱和判定和线性化，参考点每次只读取一次，不对相位、像素或帧降采样。
- 残差图分成最多 16 条 scissor 条带，每两条用现有 fence 窗口约束排队；小目标沿用单次绘制。未加固定 sleep，预览仍使用本帧完整统计。
- 新增 `check-renderer-device --concurrent-preview`：独立线程以 30 Hz 调用实际预览渲染代码，用合成输入、现有拍照期的 0.5 分辨率倍率和正常当帧测光，计到 GPU 完成。EGL 实际授予预览 HIGH、成片 LOW。测量不含相机出帧、窗口 swap 或 SurfaceFlinger 上屏。

## 真机回放

同一组 4080×3072 四帧 RAW，旧、新、新、旧交错。最长间隔取与 `mismatch` 到 `fuse` 主机日志区间重叠的预览帧间隔，列为两次的范围；阶段耗时和 RAW 到 RGBA 为两次中位数。

| 配方 / 降噪 | 残差阶段最长预览间隔 | 残差阶段耗时 | RAW 回放到 RGBA |
| --- | ---: | ---: | ---: |
| Gold 200 / Endura，PC3D | 124–129 → 56–57 ms | 101 → 82 ms | 5.175 → 5.089 s |
| Provia 100F 直扫，PC3D | 116–125 → 56–57 ms | 94 → 85 ms | 4.388 → 4.351 s |
| Gold 200 / Endura，PC3D 关 | 97–114 → 49–68 ms | 93 → 81 ms | 4.930 → 4.600 s |
| Provia 100F 直扫，PC3D 关 | 133–136 → 55–60 ms | 105 → 94 ms | 3.946 → 3.821 s |

只缩窗口时，PC3D 组的残差阶段耗时反而增加，Gold 约 102→137 ms，Provia 约 104→126 ms；消除重复取样后才收回这部分开销。支持的结论是残差区间的长停顿约减半，残差阶段本身缩短约 9–19 ms，不能将整链差值全部归因给此改动。全程 P99 的趋势好于最大值：协方差纹理释放附近仍观察到约 117–154 ms 的候选间隔。该时间相关性不能证明是释放调用本身阻塞 GPU。PC3D 关闭组 Gold 还出现了与此释放时点无关的长间隔，需要进一步归因。

## 画质与复现

- 真实 RAW 两种配方、两种降噪配置下的 RGBA、HDR 增益图、Q100 4:4:4 JPEG 对应输出逐字节一致。
- 合成多曝光与等曝光回放的残差图、实际融合权重图和成片逐字节一致；短帧准入/缺失切换、尺寸及旋转变化、两种 Spektrafilm 路径的 10 位输出、预览重建均通过。ARM64 Release 构建和 GLSL 校验通过。
- 证据和冻结库在 `test_temp/spektrafilm-perf-concurrent-20261123/`，子目录 `window-ab`、`mismatch-ab`、`mismatch-p4-ab`、`quality`。可用 `test_temp/spektrafilm-perf-01437-baseline/device-ab.sh`，设置 `AB_PREVIEW=1`，以 `AB_PC3D=0` 切到 PC3D 关闭组。基线 SHA-256 为 `71d63850d051c3c7afbb7ee06abcc7fa16f566452570c1b15d3f35f4f3577250`。
