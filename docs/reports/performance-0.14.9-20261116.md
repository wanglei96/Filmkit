# 0.14.8--0.14.10 性能实测（2026-11-16）

> 后续版本、诊断跨线程根因和当前结果见 `performance-0.14.13-20261116.md`。
> 本文“当前包”是 0.14.10 测试结束时点的历史状态，不代表最新安装版本。

## 验收目标与状态

- 快门至相册保存 3--5s，优选不超过 4s；处理中预览几乎不掉帧。
- **尚未达标**。0.14.8 前三张为 6.904 / 5.777 / 5.374s，中位 5.777s。
- 当前保留并安装 **0.14.10(807)**。三张快门至保存为 **6.073 / 6.243 / 5.639s**；处理中仍明显掉帧，不能交付为性能达标版。
- 0.14.9(806) 首次 USB 安装被系统拒绝，用户确认重试后成功；其条带 fence 候选实测未达标，已在 0.14.10 撤回。
- 本文承接 `performance-0.14.6-20261116.md`；旧文的“生产未修改”仅指首轮定位时点。

## 已实施的改动与质量边界

1. PC3D 用完整对称主元 LDLT 计算二次型，替代通用 `inverse`。保留六分量协方差、原 ridge、全部邻域、双路权重及输出噪声传播；不是 scalar 或低精度近似，也不宣称逐位相同。
2. 高光 guide 和 mask 的独立行使用原 Align 的有界并行工具。整数计数按行累加后串行归约，准入阈值、双向配准、可观测支持、连通性及接受判定不变。
3. 查询实际 EGL 优先级。设备实际返回预览 HIGH=12545、still LOW=12547，不再把请求成功当作实际分配等级。
4. 预览通知独立派发；偏好读取与所有 GL 仍在 FilmRender。0.14.7 暴露丢通知竞态并冻结预览，0.14.8 使用 sequence/recheck gate 修复。冻结预览期间的低耗时不纳入成功结果。
5. 0.14.9 跳过相同 SurfaceTexture 时间戳的重复绘制/计数，`finally` 始终完成 gate，此修复保留。条带 fence 候选将两项在途 GPU 工作限制从整 pass 改为每条带，viewport/采样/像素公式不变；实测不达标后撤回。
6. 0.14.10 增加低分辨率预览慢提交的 draw/swap 边界计时，不加 GL 同步、不改变任何像素。日志事件为 `preview.slow_submit`，只在合计不低于 40ms 时记录；这些样本的分位不能冒称全帧分位。

成像管线没有删除功能、降低分辨率、减少 taps、减弱降噪或放宽高光准入。
这不等于所有品红/灰斑场景已验收：当前静态 App 场景没有原生剪裁高光；日光问题场景仍需复验。

## 完整管线与数值验证

- 16384 个 SPD 压力样本，包含带符号交叉项、1..1e-14 特征值比例及原 ridge；独立 double 部分主元消元作 oracle。主元 LDLT 权重最大误差 0.00452393，RMS 0.000494867，非有限值为 0。较快的 cofactor 候选因病态误差被拒绝。
- 普通完整 shader fixture：RGB 最大差 0.00048828125；协方差按完整 PSD trace 归一后最大分量差约 0.000183。50 项真机检查、17 次 GPU draw、30 次读回及生产 link 通过。
- 同输入 2048² 四帧 HDR、真实 FrameRenderer 与 JPEG：原 `inverse` 与 LDLT 的 12582912 个 RGB 通道最大差 1 LSB，变化通道占 0.0027100%，没有通道差超过 1；不是逐位一致。
- 同输入完整 RGBA：CPU 按行并行与 LDLT 串行逐字节一致；0.14.9 条带 fence 候选与按行并行版也逐字节一致，JPEG 均为 1660920 字节。条带候选离线渲染 2217.681ms，不等于实际 App 并发耗时。
- 高光恢复/准入 4635 项断言复跑通过；真实 Align 几何测试此前 301 项通过。预览 gate 三项单测通过，包含 300000 个并发通知。
- DNG 诊断保护检查通过；未为了性能采样开启公共 DNG 或 RAW 转储。

`uploadMs` 包含上传、时域配准及高光准入；PC3D 包含在 `dnMs`。不要重复相加。完整窗口仅纳入起止均处于 upload 开始至引擎完成之间的窗口；不能把多个窗口 P95 合并冒称全局 P95。

## 调度候选与撤回结果

0.14.9 三张拍摄均成功，快门至保存 6.271 / 6.757 / 6.712s，引擎 5317.24 / 5827.17 / 5728.65ms，PC3D 2259.37 / 2950.80 / 2982.45ms，均为 11x11 核、scale=1。前三张前后检查 Thermal Status=0，但不是持续硬件计数器跟踪。

候选处理中仍约 18--27 FPS，没有接近持续 30 FPS，未满足目标，已撤回。0.14.8/0.14.9 同为真实并发但非同 RAW、未严格锁定全部温控/AE，不能把耗时差全归于 fence，也不能把候选的某个较好窗口冒称全程改善。
