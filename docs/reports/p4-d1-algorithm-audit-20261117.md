# P4 / 多尺度色度降噪审计与 0.14.24 修复

日期：2026-11-17。分支：dev。设备：Vivo V2509A / Mali-G1-Ultra MC12。
用户授权修复算法问题并自动实拍。PC3D=0、强边缘色度门=0、核尺寸=自动，未更改。

## 结论

旧 P4 + D1 有确定的实现问题，已经修复并交付 0.14.24(821)。这不是一次单纯提速：
修复的是色度重建、噪声域、亮度守恒和参数连续性。没有减少核、采样、帧数或精度。

不能把 PC3D 称为 BM3D，也不能仅按名称判断“更先进”。当前 PC3D 是自适应空间核、
结构张量引导、两趟处理及 guided upsample 的 RGB 空间滤波；P4 + D1 是局部联合双边
加完整多尺度色度分解。PC3D 能降亮度噪声，P4 + D1 保留输入亮度，职责不同。

本轮证据支持：修复版改善细色度结构和色度偏差；PC3D 在平坦区及亮度降噪上仍有优势。
不能据一组室内照片判定某条路线全面领先，或宣布 PC3D 没有质量收益。

## 已修复的问题

1. **D1 不是可重建的原图变换。** 旧版先 2×2 box 缩小，再做五层 à trous，最后放大；
   没有保留缩小丢掉的最细色度残差。即使噪声阈值为零，细彩色图案仍会被抹掉。
   改为全分辨率 generation-1 B3 starlet，六层 step=1/2/4/8/16/32，补齐最细层并保留
   原来最粗层的空间尺度。重建等价式 `c0 - Σ(d-d') = cL + Σd'` 保留所有频带。
2. **各频带误用同一噪声标准差。** 旧版所有层都用同一 sigma；高层的噪声已被前面低通
   显著改变，却继续用原尺度阈值。新版本按完整 B3 脉冲响应的 L2 范数缩放：
   `[.8907963103,.2006638510,.0855075048,.0412174444,.0204249666,.0101897592]`。
   这是空间独立噪声的理论增益，不是对 P0/RCD/P4 后相关噪声的精确标定，边界见后文。
3. **无局部高光协方差时，噪声域不匹配。** 旧版把 WB 后相机 RGB 的 A/B 系数用于 CCM 后
   工作 RGB，忽略 CCM 引入的交叉通道协方差；LSC 的 shot 传播也不完整，旋转后 LSC 坐标
   不一致。新路线从 CCM 前相机 RGB 构造 `A*g*z+B*g²`，按原生坐标取 LSC，再传播完整
   `CCM diag(v) CCMᵀ` 六分量；P4 使用完整色差距离，D1 分别投影 Cb/Cr 方差。
   RCD、AMaZE 和双线性分支均接入；高光融合已有 RAW 方差路径保持其输入含义。
4. **亮度空间错误。** P4/D1 仍用 Rec.709 的 Y 系数，但上游矩阵与 film 是 Rec.2020。
   改为 `.2627/.6780/.0593`，噪声投影和 RGB 重建用同一组轴。
5. **D1 未消费降噪混合强度。** 很小的非零强度仍触发完整 D1，零点不连续。现在收口乘
   `mix_p4`，强度趋零时连续趋于恒等。强度>1 仍由既有噪声尺度控制。
6. **饱和核保护在 D1 丢失。** P4 已旁路饱和核，但 D1 又改写。现在最终收口也旁路同一核。
7. **G 单通道钳位破坏亮度。** 改为在固定 Y 的色度位移上限制步长，使 RGB 非负，同时保留
   输入 Y。P4 同样约束非负域。强边缘门的 `d²+sigma` 量纲错误改为 `d²+sigma²`。
8. **资源与失败可观测性。** 补释放 D1 纹理/FBO；增加分配及 FBO 错误日志。D1 失败时停止
   该次成片，避免悄悄跳过质量 pass。独立工具增加 `--expect-chroma`，仅非黑图不算通过。

P4 的局部协方差分支过去覆盖了伪彩放宽尺度，导致其 moire 参数没有正确影响该分支。
现在放宽在协方差距离上也实际消费，完整噪声矩阵没有退化成标量。

## 算法边界与参考

变换按 [scarlet2 wavelets](https://pmelchior.github.io/scarlet2/_modules/scarlet2/wavelets.html)
的 generation-1 B3 分解、全频带重建与脉冲响应范数校验；图像边界沿用本项目 clamp。
完整 5×5 B3 张量积拆为两次 5-tap 可分离卷积，没有删权重。所有多尺度工作缓冲为 FP32。
六张全分辨率 RG32F 逻辑存储约 574 MiB（4080×3072），旧八张半分辨率 RGBA16F 约191 MiB；
新增约383 MiB，不含驱动开销和另行保留的协方差。App 连续三次实拍未 OOM，不能据此
推断所有设备都足够，低内存设备后续应采用等价分块/生命周期复用，不能降精度兜底。

保留现有有理收缩与20% detail revert；本次没有宣称它是完整 darktable BayesShrink。
[darktable denoiseprofile](https://raw.githubusercontent.com/darktable-org/darktable/master/src/iop/denoiseprofile.c)
和 [eaw](https://raw.githubusercontent.com/darktable-org/darktable/master/src/common/eaw.c)
还包含 VST、边缘感知分解、信号统计及阈值策略，不能因为都叫 wavelet 就视为等价移植。

噪声模型是 RAW profile/merge 模型经过 WB、LSC、CCM 的传播；**没有冒充非线性 RCD、P0、
P4 的精确 Jacobian 或空间协方差**。输入空间相关性与非平稳噪声会影响最佳各频带阈值，
目前理论 band gain 适用于独立噪声条件。后续若要声称最优噪声估计，必须做传感器/整链
残差标定或完整噪声传播；不能简单改一个全局 sigma 来替代。当前已修复确定错误，
尚不能宣布降噪链达到成熟参考实现的全部质量能力。

PC3D 参考 [ESD3D2 steered shader](https://raw.githubusercontent.com/eszdman/PhotonCamera/dev/app/src/main/assets/shaders/denoise/esd3d2_steered.glsl)
及 [ESD3D2 Java 编排](https://raw.githubusercontent.com/eszdman/PhotonCamera/dev/app/src/main/java/com/particlesdevs/photoncamera/processing/opengl/postpipeline/ESD3D2.java)。
其结构张量、尺度引导使它比单独一个双边核更复杂，但没有非局部分组/协同三维变换。
本轮没有改 PC3D 算法，完整同 RAW 输出与旧引擎逐字节一致。
