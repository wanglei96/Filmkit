# Spektrafilm 0.14.49：高光准入与滤波内存布局

基线 0.14.48（845）；候选 0.14.49（846）。三张 0.14.48 实拍均为 `no_clipped_pixels`，仍执行了两份短帧导图、双向高光对齐和全幅掩膜评估。

## 改动

- 先校验完整参考掩膜，包括原生 CFA 3×3 邻域、WB 后 RGB 软阈值及原二进制量化；掩膜全零才跳过短帧导图与高光专用求解。时域 MFNR、Bayer 合并、长帧保护和 HDR 交付不变。
- 非零掩膜下保留完整双向几何及连通域拒收。零权重位置仍是原来的零输出；有权重位置执行原 RGB 检验。生产合并不计算仅供诊断的短帧裁切图与误差图，诊断 API 仍完整输出。
- ARM64 长尾滤波把横向中间结果按列带布局，复用原工作缓冲。递推和边界不变；全尺寸双 tap 微基准快 4.8%–7.4%，与 0.14.48 逐位一致。

## 同 RAW 回放

V2509A，3072×4080、四帧 MFNR、HDR、生产诊断和合成取景并发。无高光夹具由原有高光 RAW 对黑位以上信号等比例乘 0.25 得到，同组旧新使用相同 RAW。首轮是尚未更改非零掩膜评估的候选，每路线 3+3；最终反序复测每路线 2+2。最终样本的 Thermal Status 均为 0，未锁频。

数据为 `raw.render.totalMs` 中位数，不是快门到保存。无高光最终准入分别为 216 → 3 ms 和 199 → 4 ms；有高光时掩膜评估 72 → 42 ms 和 70 → 39 ms，整链未显示两条路线均明显提速。无高光合成取景最长间隔的中位数约 231 → 93 ms 和 100 → 70 ms；有高光 Gold 有波动，不能据此断言实拍卡顿已解决。
