## 4. 已知限制（非缺陷，记录在案）

| 限制 | 说明 |
|---|---|
| DNG 会出现在相册网格但**编辑器打不开** | M 档 RAW 也进 `MediaStore.Images`；编辑器用 `BitmapFactory` 解不开 DNG（E5 才支持）。用户要"所有照片"故未过滤 |
| API 26–28 未授权时相册为空 | 依赖 scoped storage 的"自有媒体免权限可见"（API 29+） |
| Android 14"仅选择部分照片"未支持 | 未声明 `READ_MEDIA_VISUAL_USER_SELECTED`，按"拒绝"降级 |
| `RenderClient.stopInternal()` 的 `join(2000)` 超时边界 | 相机线程未退出时理论上与编辑器线程并发持有 `g_renderer`（UAF）；已在 `close()` 注释写明假设，概率极低 |
| 48MP 图导出 OOM 风险 | 峰值 ≈570MB；已捕获异常并提示，但体验差。编辑器一期只接本 App 成片（12MP） |

## 5. 关键决策索引（ADR）

- **ADR-7 订正 v2** ★：编辑器**能**做成片上的完整调整（曝光/WB 走**成对往返**、对比度/饱和度/清晰度走显示域）；真正做不到的只有"恢复已丢失的信息"
- **ADR-6a**：预设管"风格层"、设置页管"基础层"，两者不重叠 ⇒ 无仲裁冲突
- **ADR-11**：颗粒按短边归一化（顺带解决预览/导出分辨率差异）+ GLSL 数组陷阱的替代方案
- **ADR-12**：不许假滑杆（只暴露引擎已实现且已验证的参数）
- **ADR-9**：halation 在两条链路同域处理；暗角两链路同域共用逻辑
- **§6 引擎改动检查清单**：GLSL 三禁、诊断三件套、`glTexStorage2D`、契约四处同改、白名单同步
