# Vulkan 首张：FilmKit 进程实测与 CPU 核数对照

2026-11-26 · vivo V2509A / Mali-G1-Ultra MC12 · 已安装 0.14.56（853）。**现版 Vulkan 的交接＋Hanatos 确实更快，但没有证明稳定的首张整链提升。此次最大的可复现差值来自 CPU 资源对照，不是 Vulkan 提速，也没有接入正式版。**

## App 进程：交接变快，整引擎不稳定

test-only instrumentation 在已安装 FilmKit 进程调用原版 JNI。固定 3072×4080 室内四帧、HDR、8 位、关颗粒、PC3D 和诊断额外读回。每次新进程，在相同尺寸 GLES 资源预热后送首张；Vulkan 没有提前初始化。手机留在桌面，不开相机/取景。计时截止 RAW 引擎返回，不含相机采集、应用 JPEG/R 或 MediaStore。

## 调度证据与 CPU 核数对照

Perfetto `sched_switch` / `sched_waking` 区分实际运行、可运行而未上核、睡眠；阶段边界用 JNI 日志及其阶段计时反推，近似到毫秒。对上表八张均找齐 FilmStill 主线程与本次新建的七个原生 worker。桌面 instrumentation 的 FilmStill 实测可用 CPU 0–5，没有上 CPU 6 或 7；超时样本快照显示在 `/l-foreground`。设备上 0–3 同簇，4–6 同簇，7 单独；各簇最高频率依次为 2.70 / 3.50 / 4.21 GHz。上表八张中 FilmStill 仅在曝光及 DIR 内观察到的 runnable 未上核时间合计约 143–421 ms。线程等待可能互相重叠，也不等于从整链可直接省掉的时长。

另用同一个实验 ARM64 库在 Shell 交错重复，Vulkan 全程开启，保持同四帧、同配方、同出图参数，无预览。通过 `taskset` 仅改变整个 Shell 回放进程可用核；另在同 0–5 掩码内改变光谱组的 worker 总数，保留每个像素、tap、边界和 FP64 运算。每配方 6 次，表为每格两次独立进程的中位数，毫秒。

| CPU 掩码／光谱 worker | Gold RAW 引擎 | Gold 曝光＋DIR | Provia RAW 引擎 | Provia 曝光＋DIR |
|---|---:|---:|---:|---:|
| 0–5／8（参照） | 2812 | 821 | 2275 | 779 |
| 0–5／6 | 2782 | 788 | 2325 | 820 |
| 0–7／8 | **2336** | 663 | **1920** | 653 |

- 允许使用 6、7 核后，Shell 整引擎少 **476／354 ms**，其中曝光＋DIR 少 **159／126 ms**。Hanatos shader 仍约 8–9 ms。掩码影响整个进程，剩余差值不能全归到曝光和 DIR；Shell 与 App 的系统调度组不同。**这是证明这台机器上 CPU 资源足以造成数百毫秒差异的控制实验，不是 App 已加速。**
- 只减线程数，Gold 省约 30 ms、Provia 慢约 51 ms，不合入。全部 12 次回放的 RGBA、HDR 增益图与回放 JPEG 在同配方内逐字节一致。Shell Vulkan 输出的 RGBA、增益图也与现版 App 开 Vulkan 的同四帧回放逐字节一致。
- 一条早期 Vulkan Gold 回放的 RAW 引擎为 4.241 秒，曝光＋DIR 1.491 秒，已返回 RGBA 和增益图；外层命令随后被超时停掉。原生工作线程的创建已被该长 trace 的环形缓存淘汰，不做更深统计。后续带显式清理标记的对照通过，说明不能以早期 “Process crashed” 文本判定 Vulkan 成片挂死。早期另有日志流丢失/无法分类的样本，未计入上表。

## 下一步与留存

先在真实取景时被动取一次调度轨迹，核对成片工作线程可用核、等待窗口和预览帧间隔。若在真实取景中也复现 CPU 等待长尾，下一候选只对从快门到光谱处理的任务做调度 A/B，不强绑大核、不提升取景线程优先级；若实拍 CPU 已能用全核且没有同类长尾，按真机热点重新定 Vulkan 分工，不拿桌面结果代替。验收仍是首张快门到保存稳定省约半秒，且取景不退；任何提交到生产的算法/调度候选再做四张指定 DNG（110832、110846、110904、110936）的画质验收。

没有代按快门、修改设置、安装新的正式版本或触碰照片。探针包已卸载，正式 APK 的手机端 SHA-256 与本地签名包一致。临时 worker 试验已撤回；常规库和源文件均恢复到实验前的 SHA-256。证据在 `test_temp/spektrafilm-app-scheduler-20261126/`：`app-sched.json`、原始 logs/压缩 Perfetto、`workers-bench/`、探针代码与回放脚本、`cleanup.json`。仅清理该目录的可重建副本，原始 RAW 和历史四片 DNG 不动。
