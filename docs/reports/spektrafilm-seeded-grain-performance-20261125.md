# Spektrafilm：固定种子颗粒的全链提速

2026-11-25，vivo V2509A，3072×4080，基线为 0.14.50 的渲染逻辑加既有计时。只保留通过画质和性能对照的 CPU 颗粒改动。默认颗粒关闭；本轮收益只适用于打开颗粒的照片，不是默认路线、快门采集或保存的提速。

## 保留的实现

- 按原实测密度曲线的二分路径建立区间索引。只有输入落在该路径的完整有效区间内才用索引，否则执行原二分；不排序、不减节点、不改插值算式或 FP64。每个通道的三层共用索引。相等节点、局部回折和端点沿用原结果。
- 固定 32768 像素抽样块和 `seed_seq` 不动，任意 worker 可抢下一块；块内 Poisson 样本、通道/层顺序及密度累加顺序不变。复用成片 worker，有效滤波之后的全图处理并行；颗粒工作区不做随后会被覆盖的初始清零。微结构仍按原通道/像素顺序生成固定种子样本，独立的指数处理才并行。
- 染料云 sigma 仍为原式 `blur * sqrt(od)`；只在原 `gaussianBlur` 本来会按半径 0 原样复制时，直接把粒子加进结果，不落全帧临时平面。非零半径和非有限 sigma 沿用原路径。核、边界、最终颗粒模糊、颗粒微结构和所有 HDR 算法不变。对照本地锁定上游 `3bb2c2d2801ff68b92019cf1dbcbb133d60832bc` 的 `grain.py`、`density_curves.py` 与 `fast_gaussian_filter.py`；以当前 FilmKit 的固定随机流做逐位门槛。

## 真机同 RAW 性能

两组四帧 RAW 按 SHA-256 校验；PC3D 关闭，合成取景并发、关闭回放额外阶段同步。含高光组通过高光准入，10 位、每版每配方三次；无高光组 8 位、各两次且反向起跑。固定颗粒种子，所有 20 次回放始末 Thermal Status 均为 0。以下为各组中位数、单位秒，包含一次完整 RAW 引擎调用，不含实体快门、真实取景、应用编码、MediaStore 发布。

| 条件 | 配方 | 颗粒阶段 旧 → 新 | RAW 引擎 旧 → 新 | 引擎节省 |
| --- | --- | ---: | ---: | ---: |
| 含高光、10 位 | Gold 200 / Endura | 2.011 → 1.463 | 4.985 → 4.476 | 0.509 s（10.2%） |
| 含高光、10 位 | Provia 100F 直扫 | 2.156 → 1.535 | 4.837 → 4.208 | 0.630 s（13.0%） |
| 无高光、8 位 | Gold 200 / Endura | 2.161 → 1.611 | 4.930 → 4.407 | 0.522 s（10.6%） |
| 无高光、8 位 | Provia 100F 直扫 | 2.136 → 1.555 | 4.563 → 3.979 | 0.585 s（12.8%） |

首次只做索引、调度与并行收尾（尚未把等价复制融合）时，含高光两路引擎中位数已分别少 293/341 ms。最终候选的 `grainDyeCloudMs` 为 0，是这两个配方/设置下核本来就是恒等；累加计入 `grainParticlesMs`。两次复验的颗粒总段都少约 0.55–0.62 s，与引擎净变化方向一致。部分样本仍有 major faults，但没有把缺页长尾单独当作优化。预览合成 GPU 完成间隔的逐次最大值中位数：含高光 Gold 59.4→75.8 ms、Provia 70.1→78.7 ms；无高光分别 62.5→90.7、113.2→99.4 ms。不把此数据当作真实取景通过，待手持移动实拍。

## 画质回归

- 20 次最终颗粒回放：10 次新旧跨版本对照、6 次同版本重复对照均逐字节一致，覆盖 RGBA8 / RGB10_A2、HDR 增益图、回放 JPEG、诊断统计。10 位是引擎打包检查，不是 HEIF 编码器实拍验收。
- ARM64 同进程，重复／回折节点、正负片、夹断、微结构开关、单层及禁用，并用相同的 1/4/8 workers 对照：120 组、12,744,180 个 FP64 值逐位相同。原上游固定 draw fixtures（Portra、Provia、clumping、单层、关闭）及 786,432 像素平场统计通过，固定 draw 最大密度差 `1.48e-14`，平场最大相对标准差误差 `0.42%`。统计回归是对上游模型的补充，不替代 FilmKit 逐位对比。

- 全 132 配方／147 参数案例：固定种子开启颗粒的 FP64 图像及独立 HDR 中性响应均逐位相同。颗粒关闭另外做了两配方各一对全尺寸 RAW 回放，RGBA、增益图、回放 JPEG、诊断统计也逐字节一致，只作为回归，不把两对的时差当成绩。
- ARM64 和 x86_64 HDR Release native 构建通过。JVM Release 851 项，0 失败、2 跳过。

## 已撤回的尝试

- Planar DIR，初显影直接写三个 FP64 抑制平面、结果覆盖旧曝光：24 次 8 位回放全部比对一致，含高光两路引擎中位数只少约 2/12 ms。减少内存驻留，不算端到端提速，撤回。
- 加上 RAW 已无消费者的 RCD 纹理提前回收：28 次回放均通过画质；含高光 Gold 3.240→3.170 s，而 Provia 2.718→2.949 s。仅名义回收约 382.5 MiB 纹理，不是测得等量 RSS。继续测试连续拍摄的重新分配无助于放行这个整链已不稳定的候选，撤回。
- 短核扫描锐化、OETF 和 RGBA 直接流水化：28 次回放画质通过；含高光不含 CAM16 的扫描收尾（含阶段间开销、打包和释放）只从约 86–87 ms 到约 84 ms，整引擎两路无可复现收益。撤回；未改变 RAW／光谱调度。
