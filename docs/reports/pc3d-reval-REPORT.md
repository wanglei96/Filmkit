## 0. 一句话结论

**用新 KPI 重测，[54] 是有效的，且旧评估的两条定性结论被推翻**：

1. **"替换档不稳（152207 +27.5%）"不成立**：新 KPI 下替换档（档 1）在 152207 上超额持平（−1.9%），
   在其余三张 −25~−28%，四片平均超额 **×0.797**（旧口径给的是 +21% 恶化）。
2. **"达不到 3.68 ⇒ 无效"的前提错误**：正确基准是边缘局域超额（PC = **+1.668**）与剖面 core
   （PC = **+1.08**），不是 3.684。三档中**叠加档（[54]=2）core 四片全改善（×0.676）且无一恶化**、
   色渗红线全绿；替换档（[54]=1）超额/边缘色度结构改善最大（×0.797/×0.623）但旧色渗指标
   （hue15blk 8.2~8.4%）在警戒侧。
3. **核尺寸 M11（自动）即近最优**：M21 的边际收益只剩 −5~−7%，不值得 2.83× 采样数。

**建议默认值（供拍板）**：`[54] = 2`（叠加档）+ `[55] = 0`（自动 ⇒ 11），前提是真机 `pc3dMs` 实测可接受；
替换档留作真机 A/B 单独验证，判据按本报告新 KPI（旧判据"152207 变差"作废）。

## 8. 局限与诚实性声明

1. **离线域不是引擎输入域，且"档 0"是双重处理。** 样张本身已是真机链（v0.10.171/174，含 P4/D-1）
   的成片；离线档 0 = 成片反推后**再跑一遍** P4/D-1，不是真机 `[54]=0` 的复现。
   实证：离线档 0 把反例 161533 的超额从 input 的 +3.282 抬到 +4.807（+46%）、平坦区 σ 抬 46~89%——
   这部分是离线基建自己的伪影。**因此各档绝对值不可当真机预测；有效的是"同域同链下档位间相对差"**
   （档 2 vs 档 0 唯一差 = PC3D，是最干净的对照；input 行是真机现状成片的实测锚点）。
2. **CPU 参考实现 ≠ GPU 引擎逐位。** pc3d_cpu.py 与 kFsPc3d 同构但非同一次编译执行；离线 ds=3 域
   （1024 宽）经 BOX 上采样到 1777 测 KPI，与 PC 基准（原生 1777）的分辨率历史不同，
   **跨域绝对数（含与 PC 的对照）只有量级参考意义**。
3. **KPI3 core 对剖面形状敏感。** 档 0 的 core 低是"窄峰被摊平"的产物，不是质量改善（§3.2）。
   读 core 必须连同形状（峰位/FWHM）与超额/σ 一起，本报告所有判读均按此执行。
4. **替换档的观感风险离线不可测。** LUMA 0.8 的亮度重塑、hue15blk 8~11% 的色相偏移，最终要看真机样张。
5. **GPU 成本无真机数据**（沿用旧报告 §7.2：采样数/显存是解析值，`pc3dMs` 无实测）。
6. **没有为结论调参**：MOIRE 恒 1.5（PC 默认），LUMA 恒 0.8，扫描只动核尺寸且档 1/2 全扫（非挑最优）；
   样张为旧评估三张 + 用户点名反例，无增删；全部 PNG/JSON/日志在 `/tmp/pc3d-reval/` 可复算
   （`python3 eval_reval.py --scan`）。
7. **本报告未改任何引擎/APP 代码，未 git commit；未改 /tmp/pc3d、/tmp/pcfix 下任何已有文件。**
