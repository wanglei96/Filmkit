# Spektrafilm 胶片曝光＋DIR：最后一轮 CPU 等价方案

2026-11-26，vivo V2509A，以已安装的 0.14.55（852）为 A。只验曝光与 DIR，保存、MediaStore、取景设置和线程优先级均未改。结果：**不合入，不发包。**

## 候选：融合三个长程滤波的反向列扫描

旧 ARM64 对三项长程高斯混合是「两项一起、第三项单走」。候选把三个完整横向递推放在同一轮，列正向仍逐项保持原初值和递推，列反向直接按 `((w0 × v0) + (w1 × v1)) + (w2 × v2)` 写出结果。第三项横向结果借最终累加平面，列任务始终独占同一列带，直接原位写回，不新增额外全帧平面。仅覆盖原可整带分组、且恰好三个 IIR 的情况；混合 FIR、非对齐尺寸等仍走原实现。无改动核、采样、边界、FP64 运算与显影曲线。

3072×4080、8 workers，固定输入、预热后同进程交错；最终原位候选针对每种长程核每版 20 个样本。逐像素 FP64 字节比较都一致。

| 单通道混合滤波 | 0.14.55 | 原位候选 |
| --- | ---: | ---: |
| 代表性 DIR 尾部 3 个长程 tap | 43.13 ms | 34.54 ms |
| 代表性光晕反射 3 个长程 tap | 42.69 ms | 34.69 ms |

有额外整帧平面的原型在相同组为 33.76 / 33.29 ms；不为约 1 ms 级额外收益增加全帧内存。典型散射是 FIR/IIR 混合，不进本优化。以三个 DIR 通道和两个有效光晕通道作粗略预算，隔离测试只省约 40 ms，不解读成最终整链收益。

## 完整真机回放

两组固定四帧 RAW（室内／白灯罩），全尺寸 3072×4080，关颗粒、HDR、8 位，关闭额外阶段同步，与 30 Hz 合成取景并发。3 个配方，5 组 ABBA/BAAB 共 20 次，按组比较 RGBA、HDR 增益图和普通回放 JPEG 的 SHA-256，全部逐字节一致；起止热状态均为 0。不是实拍，整引擎不含相机采集与 MediaStore，预览列不等同真实取景。每格为该版两次的中位数，单位 ms。

Vision 2383 的结果正向，两个候选样本的曝光＋DIR 都短于两个旧版样本；同一白灯罩的 Gold / Endura 和 Provia 没有这么一致的净收益，合成预览还有更长间隔的样本。Endura 各版样本跨度较大，不判定候选必然导致回归；也不把 Vision 2383 的 107 ms 全引擎差值当成稳定因果收益。局部更快成立，达到跨场景、跨配方、取景不退步的发布条件不成立。
