# Spektrafilm 原生 Vulkan Hanatos 真机回放

2026-11-26，vivo V2509A，Mali-G1-Ultra MC12。以 0.14.55（852）手机 APK 的读取资产为基准，同一个测试库切换 CPU FP64 与原生 Vulkan。Vulkan 保留 CAT16 到 XYZ、色品坐标保护、镜像边界、Mitchell 4×4 全 16 tap、归一和曝光增益。Shader 用 FP32，膜层散射、光晕、DIR、印相、扫描和 HDR 参考仍走原有计算。生产 CMake 默认关闭，实验库由 `-DFILMKIT_VULKAN_HANATOS=ON` 构建，回放时环境变量 `FILMKIT_VULKAN_HANATOS=1` 启用 CPU 像素输入，`=2` 启用直接读回。设备连接检测及分带失败会走 CPU 回退。默认与实验 ARM64 均编译通过，实验 SPIR-V 通过静态校验。

## 内存和计时

固定实际拍摄的正常室内与裁切白灯四帧 RAW（3072×4080 输出），逐帧 SHA-256 核验，启用 HDR 与 30 Hz 合成取景，关闭颗粒、额外阶段同步及主交错组的 PC3D、CS、CM。每个 8 位场景/配方按 CPU–Vulkan–Vulkan–CPU 启动四个进程，每个进程跑两张记录首张及第二张。开始和结束热状态均为 0。数据为引擎回放，未计快门采集及 App 编码和保存。

首版相干、不可缓存映射的 CPU 转回 FP64 花约 298–299 ms，Vulkan 路径比 CPU 慢。允许 CPU 可缓存、非相干映射并显式 flush/invalidate 后，同一白灯附加配置的转回开销降到 16–21 ms。CPU 输入的 Vulkan 版本在交错组 8 位第二张的 Hanatos 中位 57–67 ms，CPU 104–109 ms，四组首张 GPU 均较慢。直接读回版保留同一精度的 GLES 源格式，按行将读回字节写到 Vulkan 映射缓冲，跳过 GPU 前整帧 FP64 转换和回传打包。Vulkan 后按原有 FP64 管线继续。直接读回经过主机映射和 EGL/Vulkan 顺序同步。

下表为 8 位的第二张，同配方每路线两次的中位数。正数表示缩短，负数表示增加。

| RAW / 配方 | 读回＋Hanatos CPU → Vulkan | GPU 时间戳 | RAW 引擎 CPU → Vulkan | 合成取景间隔 P95 CPU → Vulkan |
| --- | ---: | ---: | ---: | ---: |
| 室内 / Gold 200 + Endura | 262 → 122 ms | 29 ms | 3.572 → 3.288 s | 36.5 → 35.6 ms |
| 白灯 / Gold 200 + Endura | 250 → 124 ms | 27 ms | 3.808 → 3.504 s | 36.2 → 37.5 ms |
| 室内 / Provia 100F 直扫 | 250 → 126 ms | 29 ms | 2.795 → 2.765 s | 36.1 → 42.9 ms |
| 白灯 / Provia 100F 直扫 | 248 → 131 ms | 30 ms | 2.919 → 2.860 s | 37.4 → 35.2 ms |

读回加投影在四组第二张省 116–140 ms，首张省 57–104 ms。Gold 的整链差值同时含 RAW 前链与后续 CPU 阶段的波动。8 位首张两组 Gold 整链分别少 241／97 ms，两组 Provia 分别多 119／41 ms。Provia 的合成取景最长间隔在室内第二张由 100 变成 127 ms。白灯 RGB10_A2 单组每路线两个连拍样本，第二张读回加投影少 126 ms（Provia）和 139 ms（Gold / Vision 2383）。对应整链少 12／157 ms，首张整链分别多 123／185 ms。单次补测只用于覆盖 10 位链路和 Vision 2383。

## 画质和放行

- 直接读回版两场景两配方的 8 位 RGBA 与对应 CPU 输入 Vulkan 版逐字节一致，两组原尺寸白灯 10 位补测也通过。对 CPU FP64，直接读回版 8/10 位 RGBA 最大差 1 码，每图 384–2,276 个通道值有差异（全图 37,601,280 个 RGB 值）。HDR 增益图逐字节一致。回放 Q100 4:4:4 JPEG 解码的最大通道差 5 码，CPU 与 Vulkan 的 JPEG 文件哈希不同。
- 使用原始传感器裁切灯面，保留原 WB 和高光处理。8 位灯面中央 64×64 完全一致，Gold 为约 (218,218,216)，Provia 为 (218,218,219)。原尺寸 600×600 灯面与边缘对照保留在回放目录。CPU 与两种 Vulkan 路径均有同样的原有细灯缘色边。
- ARM64 合成回归覆盖 132 个配方、147 组参数。192×96 的 RGBA16F 输入走同一个直接读回 shader 和原有下游，颗粒关闭，使用固定种子控制其余随机输入。最终连续 sRGB 最大绝对差 1.34×10⁻⁶，最大 ΔE00 为 5.16×10⁻⁵，8/10 位最大差均为 1 码，分别有 33／153 个通道值不同（各 8,128,512 个通道值）。这批覆盖片型与成像参数，实际 RAW 回放负责验证高光链、接缝及 HDR 增益图。
- 先保留为回放候选。设备安装版本仍为 0.14.55。合成取景有回退样本，实际取景和快门到保存尚未验收。实拍阶段由用户操作快门。

真机日志、产物哈希、比对脚本及已逐文件核对 SHA-256 的输出压缩包位于 `test_temp/spektrafilm-vulkan-hanatos-20261126/`。主要批次是 CPU 输入交错 `run-112328`、直接读回 8 位 `run-113042`、10 位补测 `run-113608`。
