# 10 · 内建编辑器与胶片预设调研(2026-10-04)

> 问题定义:主页左下角相册图标(胶卷位)→ 进入**内建编辑器**,对成片切换 LUT 与专业后期;
> 专业参数需要能**在预设中提前预置**(拍摄时生效)。编辑器与预设应一体设计。
> 本文档 = 项目现状盘点 + 外部调研 + 预设参数 schema 提案 + 实施阶段建议。

## 1. 项目现状(已有基础设施)

| 组件 | 现状 | 缺口 |
|---|---|---|
| **预设机制** | `CameraPresets.kt` 47 槽 DoubleArray:WB 增益[1-3]、对比度[4]、**染料串扰矩阵[11-19]**、分区饱和[20-22]、影调[28]、LUT 强度[34]、filmic 黑白点[37/38]、锐化[39]、gamut[40]、高光重建[41/45]、RCD[46] 等;内置仅"标准"中性基线 | **无管理 UI**(保存/命名/应用/导入导出);胶片特有参数(颗粒调制/halation/暗角/趾肩形状)无槽位 |
| **LUT** | M4 完整:42 内置 .lut + .cube 导入 + 强度滑杆 + 拍摄时选择 | 无"对已拍成片换 LUT" |
| **引擎渲染** | 单帧直通 `nativeEngineSubmitStill/SubmitRaw`(成片全链);预览降载 `g_preview_scale` | 编辑器"改参数→快速重渲染"循环未做 |
| **入口** | `CameraScreen.kt:1232` 胶卷位 = 最近样张缩略图占位 | 点击后无去处 |
| **DNG 底片** | `dng_enabled` 可存(单张 10-20MB) | 编辑器未利用——**DNG 是编辑器自由度的上限** |

**关键判断:编辑器与预设必须一体做。** 两者共用同一个参数源(FilmParams schema):
编辑器 = 预设的"编辑界面",拍摄 = 预设的"实时应用"。分离做会导致两套参数语义漂移
(历史教训:预览链/成片链参数只接两条 = 第三条静默漏)。

## 2. 外部调研

### 2.1 胶片模拟 App 的编辑器与预设(Dazz / RniFilm / VSCO / 配方社区)

- **Dazz 相机**:不支持从零创建滤镜,基于内置预设做**强度调节 + 专属参数微调**;
  编辑器可调:曝光、色调、**颗粒(量级 + 大小两维)**、**光晕(halation)**、漏光、暗角、褪色。
  ([App Store](https://apps.apple.com/cn/app/id1422471180)、[Google Play](https://play.google.com/store/apps/details?id=app.grain.camera)、[pconline](https://g.pconline.com.cn/ask/264887.html))
- **VSCO**:已内置 halation 工具(官方演示 CineStill 800T 对比)。
- **Jamie Windsor 胶片预设**:9 个型号变体,halation 用自动化 Photoshop Action 单独提供——
  说明 **halation 是独立于 LUT 的形态学效果**,不能靠色彩 LUT 表达。
- **社区配方**(Joe D'Agostino 的 Cinestill 800T Lightroom 公开配方等,
  [peva3/Lightroom-Presets](https://github.com/peva3/Lightroom-Presets/blob/main/research/Cinestill-800T/community-recipes.md)):
  型号 = 曲线 + WB 偏移 + 分通道 HSL + 颗粒 + 暗角 的固定取值组合。
- **共性结论**:预设 = 「LUT/色彩响应」+「曲线」+「颗粒(强度/尺寸)」+「halation」+「暗角」+「漏光/边框(可选)」
  的参数包;编辑器 = 对这个包的逐项微调;自定义 = 微调后另存。

### 2.2 filmulator(开源胶片显影模拟)

([官网](http://filmulator.org)、[GitHub](https://github.com/CarVac/filmulator-gui)、[HN 讨论](https://news.ycombinator.com/item?id=25885760))

不做 tone-mapping,而是模拟"显影剂耗竭"(developer depletion):
- 核心参数:**exposure comp(感光/曝光)、develop(显影时间 → 高光压缩与对比)、
  highlights(高光恢复)、shading(密度相关衰减 → 暗角类)、vibrance(亮部饱和提升)、warmth**
- 显影模拟的四个可感知效果:大亮区压暗(压缩输出 DR)、小亮区周边变暗(局部对比)、
  亮区饱和提升(天空/肤色/日落)、高饱和区亮度衰减(保细节)
- 对我们的启示:曝光/显影两参数分开(拍后可再分配中间调 vs 高光),比单一"对比度"更胶片

### 2.3 darktable negadoctor(扫描负片转换的科学参数)

([官方手册](https://docs.darktable.org/user-manual/4.2/en/module-reference/processing-modules/negadoctor/))

- **Dmin**(未曝光片基密度 = 反转后黑点)、**Dmax**(负片最大密度 = 白点)、
  **扫描曝光偏置**、**密度平衡**(分通道密度残差 = 残余色罩)、**暗部色罩/胶片材料色**
- 对我们的启示:即便不真拍负片,"胶片预设"的影调端应以**密度域**思考
  (黑点/白点/肩趾),而不是 sRGB 曲线拉拉——我们的 filmic 黑白点[37/38]槽位已在此方向

### 2.4 halation / 颗粒 / 层间效应 的模拟方法

- **halation**(CineStill 800T = Vision3 500T 撕掉 remjet 防光晕层的标志性效果,
  [jie60517/emulsion](https://github.com/jie60517/emulsion)):
  提取高光(阈值)→ 红橙色模糊大半径 → screen/add 叠回。参数 = 阈值、强度、半径、色相、不透明度。
  VSCO/Resolve 均内置;**必须在 LUT 之前的高光判断 + 之后叠色,不能进 3D LUT**。
- **颗粒**:胶片 RMS granularity 随 ISO 上升、随曝光量(密度)变化——负片**暗部颗粒最重**、
  亮部最少;数码模拟 = 单色亮度调制(不走 RGB 独立通道,避免假彩噪)+ 密度相关调制曲线 +
  尺寸参数。我们已有颗粒管线(引擎尾部),需补**调制曲线与尺寸**两个维度。
- **层间效应(interlayer interimage effects)**:Kodak(暖肤色、中性偏洋红罩)与 Fuji
  (青绿、冷高光)的色彩差异主要来自 DIR 耦合层的分通道抑制——数码近似 =
  **按亮度分区的分通道饱和/色相偏移**(高光/中间调/暗部分别),这正好是我们
  分区饱和[20-22] 槽位的扩展方向。

## 3. 预设参数 schema 提案

原则:**已有 47 槽不动**(契约不移位),胶片特有参数**追加新槽位**(47+)。
预设文件 = JSON(参数集 + LUT id + LUT 强度 + 名称),prefs 持久化,可导入导出。

### 3.1 已覆盖(拍板保留,不需新做)

| 组 | 参数 | 槽位 |
|---|---|---|
| 影调 | 基准曝光、filmic 黑白点、对比度、局部色调映射 | [0][37/38][4][36] |
| 色彩 | WB 增益、分区饱和、LUT 选择 + 强度、gamut | [1-3][20-22][34][40] |
| 风格化通路开关 | 锐化、高光重建 ×2、RCD、局部映射 | [39][41/45][46][36] |
| 结构 | **染料串扰矩阵**(胶片色彩科学核心,槽位已在) | [11-19] |

### 3.2 需新增(对"接近真实胶片"贡献度排序)

| 优先 | 参数 | 作用 | 典型范围 | 对胶片感贡献 |
|---|---|---|---|---|
| ★★★ | **颗粒强度** | 单色亮度调制量 | 0–2(1 = ISO 真实) | 高(胶片感第一要素) |
| ★★★ | **颗粒尺寸** | 银盐簇团半径 | 1–3px | 高 |
| ★★★ | **颗粒密度调制** | 暗部多、亮部少(负片密度关系) | 曲线斜率 0–1 | 高(真颗粒 vs 噪点的分界) |
| ★★★ | **halation 强度** | 高光红橙光晕 | 0–1 | 高(逆光/夜景氛围) |
| ★★ | **halation 阈值/半径/色相** | 触发与形态 | 阈值 0.7–1.0、半径 8–32px、红橙 | 中 |
| ★★ | **暗角强度** | 镜头失光 | 0–0.5 | 中 |
| ★★ | **趾部/肩部形状** | D log E 曲线两端 | 0–1 各一 | 中(胶片"耐看"的灰阶) |
| ★ | **层间效应** | 高光/中间调/暗部分通道偏移(Kodak 暖/Fuji 冷) | 3×3 系数或简化两轴 | 中(型号差异化的来源) |
| ★ | **漏光/边框** | Dazz 式氛围件 | 0–1 / 样式 | 低(可选,后期 UI 层) |

### 3.3 预设 schema(JSON 草案)

```json
{
  "name": "Portra 400 暖调",
  "base": "standard",            // 继承的中性基线
  "lut": "kodak_portra_v1.lut",  // 色彩响应(LUT 承载)
  "lut_strength": 0.85,
  "tone": { "black_ev": -7.65, "white_ev": 4.56, "toe": 0.3, "shoulder": 0.4 },
  "color": { "wb_shift_k": 0, "sat_shadow": 1.0, "sat_mid": 1.05, "sat_high": 0.95 },
  "grain": { "strength": 0.6, "size_px": 1.5, "density_mod": 0.8 },
  "halation": { "strength": 0.35, "threshold": 0.92, "radius_px": 16, "hue": 15 },
  "vignette": { "strength": 0.18 },
  "crosstalk": [[1.02,-0.02,0],[0,1.0,-0.02],[0,0,1.0]]   // 染料串扰(槽位已有)
}
```

## 4. 编辑器方案要点

1. **入口**:胶卷位缩略图点击 → 编辑器(先本 App 最近成片,二期接系统相册选择器)。
2. **素材决定上限**:**DNG 底片开着时,编辑器从 DNG 重跑全链**(WB/曝光/影调/LUT/颗粒全部可逆,
   这才是"专业后期");只有 JPEG 时退化为 OETF 后的有限调节(LUT/颗粒/暗角/边框)。
   ——编辑器立项时须明确这个分级,避免按 JPEG 能力设计接口。
3. **渲染循环**:复用单帧直通链 + 预览降载;参数变更只重跑风格化后段
   (LUT 之后 = 颗粒/halation/暗角 → 快;WB/影调 = 全链重跑,预览用小尺寸控时)。
   热机全链 2~3s 是成片链现状,**编辑器必须先落"预览分辨率全链 <300ms"的实测基线**再定交互。
4. **交互**:滑杆分组(影调/色彩/胶片/颗粒/halation/暗角),逐参数 A/B 长按对比
   (沿用"自带可关闭 A/B 通路"纪律);导出覆盖 JPEG 或另存。
5. **预设联动**:编辑器"存为预设" → 拍摄页胶卷仓条直接可选(预设 = 拍摄实时套用,同一 schema)。
