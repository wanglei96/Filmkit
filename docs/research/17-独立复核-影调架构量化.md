## 1. A 组：死白起点复算

### 1.1 口径还原（复核的前提，先把它钉死）

16 号 §8 附录 A 自述口径：

1. 输入 `s = 0.1845·2^EV`，EV ∈ [−1, +9]，步长 0.05；
2. 输出统一为**线性显示值 → 真 sRGB OETF → 8bit**；
3. "死白起点" = 从该 EV 起，此后每 0.1 EV 的输出差**恒 ≤ 1 LSB** 的最小 EV（自述"与 R-2 的 `analyse()` 同判据"）；
4. 纯曲线口径：不含 gamut mapping / primaries inset / LUT / highlightRolloff。

**我反推出的实际口径（这是本次复核第一个关键发现）**：报告的全部数值只有在下述实现下才能逐位复现 ——

- 第 3 条实际用的是 **未量化（浮点）的 8bit 值**做差，而不是真机量化的整数 LSB；
- "输出差"用的是**单向增量** `Δ ≤ 1`（只卡上界，不卡回跌），不是 `|Δ| ≤ 1`；
- filmic 侧取 R-3 新配方（`builtin.json` 当前值，DR≈16），sigmoid 侧取 **double 精度**的 `commit_params`。

**量化 vs 未量化差多少**（同一根曲线，`diag_criteria.py`；sigmoid 为 darktable 实跑的 float32 参数，ACES 为 double）：

| 曲线 | 白纸 2.30EV（未量化） | 死白起点（未量化） | 白纸（量化） | 死白起点（量化） |
|---|---|---|---|---|
| filmic R-3 新配方（M9） | 220.45 | **3.55** | 220 | **3.40** |
| sigmoid c=1.2 | 203.60 | **4.25** | 204 | **3.95** |
| sigmoid c=1.5 | 218.84 | **3.65** | 219 | **3.45** |
| ACES2 peak=55 nit | 197.67 | **4.60** | 198 | **4.35** |
| ACES2 peak=100 nit | 175.54 | **5.25** | 176 | **4.90** |

⇒ **真机 8bit 交付口径下，报告的所有死白起点都要提前 0.20~0.30 EV**。这不改变架构排序（见 §1.5），但"3.55 EV 已覆盖真机 2.47~3.0 EV 高光"的安全余量应从 0.55 EV 修正为 **0.40 EV**（量化口径 3.40 − 3.0）。

### 1.5 A4：判据本身的合理性

**判据定义**：从某 EV 起，此后每 0.1 EV 输出差恒 ≤ 1 LSB 的最小 EV。

**缺陷 1：阈值 1.0 落在"恰好可分辨"的等号上。** 8bit 的 1 个码值就是最小可分辨单位；"每 0.1 EV 恰好 1 LSB"是一条**理想的均匀分配曲线**（既不浪费码值、也不可再分辨更细），却在 `≤1` 判据下被判为"从该点起死白"。`run_C.py` 的构造反例直接演示：

```
白纸 2.30EV = 204.0 LSB；中灰 0EV = 119.0 LSB（与现有锚点一致）；全段非降 = True
可分辨跨度（每 0.1EV ≥1 LSB）= 5.1 EV（2.30 → 7.40 EV，用满 8bit 255）
flat01≤1 判据给出的"死白起点" = 2.30 EV   ← 被判为最早死白
```

**缺陷 2：只看斜率上限，不看累积层次。** 一条曲线可以在 3.9 EV 处把斜率压到 1.9 LSB/0.1EV（满足 ≤2），但白纸之上总量只有几 LSB；判据会给它高分。

**缺陷 3（后果）：排序不是架构的稳定属性。** 同一批曲线，只换判据阈值：

| 曲线（原始参数） | ≤0.5 | **≤1（报告口径）** | ≤2 | ≤3 |
|---|---|---|---|---|
| filmic R-3 新配方（M9） | 3.75 | **3.55** | 3.15 | 2.75 |
| sigmoid c=1.2 | 5.20 | **4.25** | 3.15 | 2.25 |
| sigmoid c=1.5 | 4.40 | **3.65** | 2.85 | 2.25 |
| ACES2 peak=55 nit | 5.75 | **4.60** | 3.30 | 2.25 |

- 在 **≤1**：ACES(4.60) > sigmoid1.2(4.25) > **sigmoid1.5(3.65) > filmic(3.55)**；

```c
// darktable master ddc0bc5  src/iop/filmicrgb.c:2590-2600（滑杆范围 MIN 1 / MAX 10，见 :182）
p->output_power = CLAMPF(logf(p->grey_point_target / 100.0f)
                         / logf(-p->black_point_source / (p->white_point_source - p->black_point_source)),
                         min, max);
```

```cpp
// 本项目 FrameRenderer.cpp:13442-13447（cp 补偿用）
auto derive_power = [&](float wv) {
  const float bl = std::min(b, wv - 0.2f);
  const float wh = std::max(wv, bl + 0.2f);
  return std::log(kGrey) / std::log(-static_cast<double>(bl) / static_cast<double>(wh - bl));

const double power = std::log(kGrey) / std::log(-black / dr);
```

## 3. C 组："守恒律"论断的构造性检验

### 3.1 报告原文与前提

> "'白纸够白'与'白纸之上还有层次'争的是**同一段显示灰阶**（8bit 下上限 ~246.5）。**没有任何架构能同时给足两者**……若最终交付 8bit JPEG，量化上限是物理事实；要兑现'可逆'必须提高中间/输出位深（10bit HEIF）。"

### 3.2 定量化：8bit 的硬上界是成立的（证实）

在**单帧 + 全局单调映射 + 8bit 交付 + 白纸亮度固定**的前提下，白纸之上只剩 `255 − paper_lsb` 个码值；
若要求每 0.1 EV 至少 1 LSB（= 恰好可分辨），则可分辨跨度 ≤ `(255 − paper_lsb) × 0.1` EV：

| 白纸 | 剩余码值 | 跨度上界 | 可分辨到 |
|---|---|---|---|
| 199 LSB | 56.0 | 5.60 EV | 7.90 EV |
| **204 LSB** | 51.0 | **5.10 EV** | **7.40 EV** |
| 220 LSB | 35.0 | 3.50 EV | 5.80 EV |
| 240 LSB | 15.0 | 1.50 EV | 3.80 EV |
| 246.5 LSB（R-2 实测上限） | 8.5 | 0.85 EV | 3.15 EV |

**⇒ 报告"白纸越白、白纸之上层次越少"的定性结论成立，且这是信息论上界，不是实现缺陷。**

### 3.3 但三种架构离上界很远（报告未提，影响结论解读）

| 架构（等白纸 204 LSB） | 可分辨跨度 | 上界 | 用掉 |
|---|---|---|---|
| filmic（white_ev≈15.6） | 1.65 EV | 5.15 EV | 32% |
| sigmoid c=1.2 | 1.95 EV | 5.04 EV | 39% |
| ACES2（peak=41.8） | 1.90 EV | 5.10 EV | 37% |
| sigmoid c=1.5（默认白纸 219） | 1.40 EV | 3.62 EV | 39% |
| ACES2 peak=55（白纸 197.7） | 2.35 EV | 5.73 EV | 41% |

**⇒ "没有架构能同时给足"在**当前三种 S 曲线/渐近曲线族**内成立，但它们连上界的 40% 都没用满。真正的瓶颈是曲线族的码值分配形状（把大量码值摊在极宽的低斜率长尾上），不是 8bit 的信息量。**

### 3.4 构造性反例（强表述被证伪）

在**允许任意单调曲线**（题目允许改中灰锚点、非单调/感知映射等前提）时，存在反例：

```
控制点：0EV=119 LSB（与现有中灰一致）→ 2.30EV=204 LSB（白纸）
        2.30EV 以上每 0.1EV 恰好 +1 LSB → 7.40EV 处到 255（用满 8bit）
实测：全段非降 = True；白纸 = 204.0 LSB；中灰 = 119.0 LSB
      可分辨跨度 = 5.1 EV（到 7.40 EV）——是 ACES(1.90 EV) 的 2.7 倍
```

即：**8bit、单帧、全局单调、白纸 204 LSB 的条件下，"白纸够白 + 白纸之上有层次"可以同时给足到 7.4 EV**。
代价是这条曲线的形状不是平滑 S 曲线（控制点处二阶不连续；用单调保形三次样条替换线性插值可平滑化，结论不变）。

⇒ 报告的守恒律**在"全局单调曲线族"这个宽前提下就被证伪**；它只在"filmic/sigmoid/ACES 这类 S 曲线"这个窄族内成立。**报告把架构族的局限写成了物理定律。**

更强的突破手段（报告完全没提，也超出本次复算范围）：
- **局部影调映射**（本项目已有 `[36] local_tone`）：允许空间变化的映射，同一码值在不同空间位置代表不同场景亮度 ⇒ 直接绕过"全局曲线一一对应"的信息论前提；
- **多帧/时域**：同理（不同帧复用码值）；
- 代价是 halo / 噪声 / 时域一致性，属于另一类权衡，但与报告的"物理事实"无关。

### 3.5 "要兑现可逆必须上 10bit"是否成立

**部分成立，且必须拆分**：

- 对 **sigmoid / ACES**（线性域严格单调、渐近不发散）：成立。它们的不可逆**只**来自 8bit 量化，10bit/16bit 可把不可逆范围缩小或消除（严格说 10bit 也只是缩小 4 倍，真正可逆要浮点/16bit 中间产物）；
- 对 **filmic**：**不成立**。filmic 在 `e = 1`（= 白点）后输出**逐位恒定**（我实测 plateau = 4.00 EV，白点后所有输入映射到同一输出）。这是**连续不可逆**，与位深无关 —— 上 10bit/16bit/浮点都不恢复信息。

⇒ 报告把两类不可逆混为一谈。正确表述应是："**sigmoid/ACES 在 8bit 下损失的是量化可逆性（提高位深可救）；filmic 在 plateau 之后损失的是映射可逆性（任何位深都救不了）**"——后者恰恰是"换架构"最硬的理由，比"多 0.7 EV 层次"更值得写进决策依据。

## 6. 对决策的含义（只陈述复算能支撑的部分）

1. **"换掉 filmic 的参数化"这一主结论仍然成立**，最强理由不是"多 0.7~1.05 EV 层次"（等白纸后只剩 0.25~0.30 EV），而是 **filmic 的 plateau 是连续不可逆**（4.0 EV 之后逐位恒定），而 sigmoid/ACES 在线性域严格单调 —— 前者任何位深都不可逆，后者提高位深即可兑现可逆。
2. **"白点参数消失"这一点完全成立**：sigmoid 的白点由 `display_white_target`（设备/风格量）+ 显示端点决定，ACES 由 peak luminance 决定，两者都与**场景**无关；filmic 的白点是场景端点（`e` 的 clamp 位置）⇒ 这是架构级的差别，不受本次口径修正影响。
3. **不能声称"换架构就够"**：三者都只用掉 8bit 上界的 32~41%；若目标是"白纸 204 + 高光可分辨到 5.5 EV"，按 §3.4 的构造，**曲线形状本身需要重新设计**（每 0.1 EV 均匀分配码值），换 sigmoid/ACES 只是走近一步。
4. **AES/sigmoid 的取舍仍需真机拍板**：ACES 的中灰（112.7/90.3 LSB）比现状低 6~29 LSB，属于"中灰重锚"级改动，报告已列为未验证项。

## 8. 未验证 / 局限（诚实标注）

1. **我的 filmic 是 double 纯曲线实现**，未接入 `kFsFilm` 的 sat/split/mono、`kFsOut` 的 highlightRolloff 与 `uGamut=1`。与 R-2 的 GPU 口径存在 **±0.1 EV / ±0.5 LSB** 的系统差（已在对拍中量化）。**未逐位复刻 GPU 链路**是本报告最主要的局限。
2. **sigmoid 未跑 darktable 本体**，是按 `commit_params` 逐行重写（float32/float64 两版）。darktable 的 per-channel 处理（`process_loglogistic_per_channel`）对中性灰与我的一致，但彩色路径未验证。
3. **ACES 只验了 tone scale**，未接 Hellwig 2022 JMh 输入变换与 gamut cusp 表；归一化口径（÷peak）是从报告数字反推的，若 16 号的实现另有约定，白纸值可能有 ±0.3 LSB 偏移（但我的值与报告逐位吻合，说明口径一致）。
4. **D4 的"逐位同步"是抽样核对**（长度 + 尾部三槽 + 端点槽 + 索引覆盖），**未做 98 槽全量语义等价证明**。
5. **守恒律反例是"存在性证明"**，未评估这种曲线在真实场景/噪声下的观感（可能因暗部斜率过大出现 banding）。"局部影调可突破"是定性判断，未做数值实验。
6. 本报告**未改任何产品代码**；所有产物在 `/tmp/verify-tone/` 与本文档。
