# 项目状态
## 目标
胶片相机 App（Android 首发，vivo X300 专项适配）：Camera2 RAW/YUV 双输入 → 引擎胶片风格化（基准色彩科学 + 理光系 LUT 风格层）→ 全分辨率成片。核心卖点：M 档专业拍摄 + RAW 底片 + 胶片渲染全 GPU。里程碑 M0–M6 见 docs/开发计划.md。**色彩口径（D8/D9）**：基准 = 中性正确的色彩科学，风格 = 用户提供的理光系 LUT。
## 结构
- `app/`：Kotlin/Compose UI（相机/设置/能力/日志四 Tab）+ CameraController（Camera2 双流）+ RenderClient（预览渲染）+ StillRenderClient（拍照渲染）+ CameraAudit + `camera/StdColorMatrix.kt` + `ui/CameraPresets.kt`（FilmParams 槽位唯一来源，**kCount=105**）+ `ui/ParamControls.kt`（参数表单一来源，拍照与编辑器共用）
- `core/engine/`：C++20 引擎——render/（FrameRenderer + Align）、gl/、spike/（SpikeFftMerge）、log/、jni/Bridge.cpp、`film/FilmParams.h`、`film/EngineRegistry.{h,cpp}`
- `assets/`：`luts/` 46 个 .lut（33³ 为主 + `leica_m9_ccd`128³ + 3×64³ 自烘 + `ricoh_negative_ye` 33³）+ `noise_models/` 三摄 + `presets/builtin.json` **七条**预设；`tools/`：validate-shaders / check-diag-* / bake-{m9,ricoh}-lut / normalize-lut-luma / recipe-fit / tuning 工具族
**历史发布（2026-11-17 14:36）**：0.14.25(822, `9613b51`) 的 dev/main/tag/GitHub Release 当时同步；当前 0.14.27 状态见末节。
切镜头黑图与焦段假保持已修复。性能目标 3--5s/优选≤4s 与预览几乎不掉帧仍未全面证明；
0.14.20 保存中位 5.599s，剩余热点仍是 PC3D/共享 GPU、warmup、RAW producer 与 histogram 同步。
旧账：高光扩展场景、Spektrafilm、理光曲线重标、绿植/绿段、亮部亮度降噪、超广畸变。

## 预览卡顿与 T3（11-12 晚，0.13.10→0.13.16）
- [2026-11-12] **卡顿根因不是 strip**：PC 的 strip = LOW 优先级 EGL context（`EGL_IMG_context_priority`，X300 Mali 支持）+ 线程降级 + fence 窗口；上轮只抄了「条带 + glFlush」且加在 P0（300ms），而冻结来自 DFT 单 dispatch ~300ms。补齐后用户确认「好很多」；DFT 按 tile 行拆 2 块 + 在飞限 2，单 job 300→150ms，代价 dftGpu +400ms。
- [2026-11-12] **融合默认切空间域**（0.13.16，`mfnr_dft=false`）：明亮 ISO 1163 6033→4233ms、暗光 ISO 662 8000→5240ms；暗部 σ 2.08→1.71、高频 −18% 但 100% 裁剪无可见差。写新融合的模拟（1~30px 位移）两条权重路径差 0~1.7 LSB ⇒ 不做。
## HDR 灯盘与 gainmap 语义（11-13）
- [2026-11-13] **gainmap 改回标准乘性比值**：`gainTrue` 从加性 `sdr+max(0,hdr−1/anchor)` 改成 `hdrDisp/sdrLin`（libultrahdr `encodeGain` 口径，clamp [1,4]）。加性版实测灯盘 63% 像素 ratio=1.00、只有灯泡核心有增益（HDR 屏上灯盘不亮、灯泡四周一圈灰），PC 同场景 整盘 3.9；改后 0% 恒 1、中位 2.2~2.9、p90 4.0。
- [2026-11-13] **两个 gainmap 必修**：① 输入必须同 exposure（SDR 已乘，参考帧没乘 ⇒ EV+3.8 时整张退化 ratio=1、画面发紫）；② 用单锚点线性换算近似不了 filmic S 曲线 （固定 2.56 与本张 0.42 都让整张顶满 4x）。
- [2026-11-13] **灯面白的根因在曲线不在融合**：4 帧离线复算证明 satW 正常（f0/f1/f2 权重 0、 短帧 f3 权重 0.98，融合后灯面 scene 1.52），而 filmic 白点 2.95 把 1.52 映射到 0.8 （8bit 232）；PC 同场景映射到 0.55（139）。
- [2026-11-13] **采集端高光保护的判据源不可用**：`p999pv=0.68 / dom=2.0` 换算 0.89EV， 真实 3.04EV，低报 2.15EV；`dom` 是中位比，ISP tonemap 在高光段压 7~14×，修不了肩部。
