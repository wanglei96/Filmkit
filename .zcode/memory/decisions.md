## P4 真实 gainmap 与徕卡一瞬（10-25/26）
- [2026-10-25] **gainTrue 中灰自锚定**：scene 锚 = ae_p50_、display 锚 = 0.1845；ratio clamp [1,4]（下限 1 = 暗部零放大，上限 4 = 元数据全量程）；A/B 档 + 预案 kHdrCeil（HDR 亮度 ≤2×SDR 白按 sdrY 收）
- [2026-10-25] **样片代表性**：旧样片对 gainmap 指纹有效、对 base 曝光账目无效（AE 删除 0.12.71 分界）——两类判据分开算
- [2026-10-25] **徕卡一瞬一期 = 现有引擎 + 烘焙 LUT**：PC 配方 → 64³ 纯色彩 display 域 LUT；**曲线不烘**（影调归 filmic latitude）；**B 方案否决**（不能为了预设改引擎）。
- [2026-10-25] **单链拍照拟合取代双链 minimax**：拍照链为主判据、编辑器链残差记账；双链 14.75 是假墙；影调目标 = 暗部 M9 + 中高段旧观感。

- [2026-10-25] **内置预设不带 engine_slot**；**样张后缀 = LUT 标题**、真机验收必须带引擎槽位归因。

## 边缘伪彩与开关（10-29）
- [2026-10-29] **锐化过冲限幅 ±0.4 → ±0.12**（`sharpenLuma`）：USM 在阶跃处亮侧提亮/暗侧压暗，±0.4 = 40% 过冲；显示域实测 13.5→8.4 LSB。这是"阴影渗水边"回到可接受的唯一已验证改动
- [2026-10-29] **D4 大半径 USM 默认关**（`[100]`）：离线能收窄亮缝（25→18px、对比 +33%、无暗环），但会整体变硬；用户判定"画面毁了"⇒ 只作实验开关
- [2026-10-29] **不改 tone curve 补对比**（用户拒绝）；开关化：高光滚降 `[99]` 开、高光重建 `[45]`、D4 USM `[100]` 关；kCount 99→101。

## 高光、掩码与 HDR（10-30）
- [2026-10-30] **HDR 整体提亮是观感选择、不是规范语义**：有意偏离 ISO 21496-1（固定 2.56 锚定、整张 2.4~3.3×），引用时不得当原版语义。
- [2026-10-30] **饱和判定回传感器域**：`raw >= ceil(black + (white−black)×0.98)`、逐相位整数比较，不含 WB 增益与噪声项。
- [2026-10-30] **短帧真值按 2×2 块整块接管**（四相位都未饱和才接管）；**禁止块内混帧**（色比撕裂，0.12.133 的黄绿）。

## 预设边界与饱和分区（11-01）
- [2026-11-01] **管线开关不进预设**：预设只带风格（对比/曲线/分区饱和/色温/颗粒/暗角/LUT），开关唯一事实源 = 设置页；`setFilmParams` 换数组后全部 applier 缓存置哨兵。
- [2026-11-01] **饱和度听预设、删设置页饱和补偿**：`[20..22]` 不再有第二个写入者；三段饱和拆成三条独立滑杆（方案 B），复刻机内直出就把三条拉同值。
- [2026-11-01] **ESD3D2 默认替换档（1）**：与 `FilmParams.h` 一致；此前两处 getInt 兜底写 2 是"代码说替换、实际跑叠加"的偏差。
- [2026-11-01] **未重新标定的预设不锁 engine_slot**（只有徕卡一瞬锁）。~~LUT 只做色彩不做影调~~ → **11-11 推翻，见下条**
- [2026-11-01] **理光标定方法论**：无固件配方 ⇒ 同场景 Positive↔Negative 配对测亮度传递 + 多张样片灰轴统计 + 配对色相 delta；不做无数据拟合。

## 预设群与 LUT 方法论（11-01→11-02）
- [2026-11-01] **需要"参数配方"的预设必须锁 filmic**：sigmoid 的 shader 只有 `sigmoidTone(out3)` + 7 个编译期常量 uniform，**没有任何从 FilmParams 读取的通道** ⇒ [4]/[5..10]/[37][38] 全被旁路，预设退化成"换个 LUT"。7 条里 5 条锁 filmic；理光负片/徕卡黑白缺省。
- [2026-11-01] **LUT 归一 = 只换 L\*、保留 a\*/b\***，超域点硬裁（缩 C 会把亮黄/青砍到 0.46~0.63）；只用于自带影调的 LUT（富士压白 8.2%），不用于 5219（2.7%）。
- [2026-11-01] **摄影师调色版只借指标、不搬色彩**（灰轴 a\* −2.4~−3.7 是签名，照搬白墙 a\* −4.1 发绿）。
- [2026-11-02] **压黑能压掉负片 base fog**（5219 最黑处 4.7% 是蒙灰来源）；**人工暗角不是原厂特征**（M9 机内默认开校正）⇒ 去掉。
- [2026-11-02] **颗粒按胶片物理**（DLT 是减少不是消除；500T `grain 12 / size 500`）；**外部 AI 评价只采纳数据能对上位置的条目**。

## 取景器对齐与蓝天（11-04）

- [2026-11-04] **显示域对齐用同一把尺，不用标量**：预览与成片都调 `robustMidToneDisplayRgba8`（截尾四分位 + 中心高斯 sigma 0.32，同 PC `MeteringSystem`）；成片 `passOutput` 后量中心 1/2、差多少补 `exposure_ev`。`g_domain_ratio` 降级为纯诊断。
- [2026-11-04] **闭环用两遍渲染 + 0.7 阻尼 + 最多两轮**：`tex_scene_` 与曝光无关 ⇒ 只重跑 filmic+output；实测闭环增益 1.0~1.76（`ev_shift` 联动），全量步进会过冲。
- [2026-11-04] **HDR 回 ISO 21496-1 标准语义**：中灰及以下 ratio 恒 1，只有 SDR 白点之上延展；`hdrAligned = sdrLin + max(0, hdrLin − 1/anchor)`（不是 `hdrLin*anchor − 1`）。
- [2026-11-04] **蓝天目标必须用晴天样片**：官方晴天深蓝天 h 270.9 / C\* 17.8；阴天街景 h 258 / C\* 13.1 只能代表阴天。
- [2026-11-04] **LUT 里不做「只作用于某段亮度」的补偿**：display 域 3D LUT 是连续渐变的查表，任何随 L 开窗的补偿都会在窗边留下一圈色相凹陷（0.12.241 的白块）。要压某段的色相，只能在 filmic 的场景线性域做。
- [2026-11-04] **方案选择纪律（写入 AGENTS.md）**：只选最佳质量方案；禁止半成品（统计端做了消费端没接）；对标实现读完再动手；不许拿历史注释当豁免。

## LUT 影调与采集端曝光（11-11）

- [2026-11-11] **LUT 可以携带影调 + 采集端判据必须当帧**（推翻 11-01「只做色彩」）：归一成灰阶恒等 = 发灰 + 天空偏紫；同一张片子影调只能有一套主曲线，LUT 带影调时 filmic 目标曲线要重标。采集端判据跨张/全局硬压均被否决，HDR+ 包围下高光保护同样生效。

## 天空白块与闭环（11-12，0.13.0）

- [2026-11-12] **闭环只允许"当帧补 EV + 天空护栏"**：每步测顶部天空 P99，涨 >0.03 或 >0.88 撤销；宁留 `dispErr` 也不推白；禁止跨张/跨场景复用。**Spektrafilm 是引擎（slot=2，场景线性输入）**，不是 display 域 LUT，不做同场景 A/B。
- [2026-11-12] **RCD 方向场不改**（性能专项结论）：0.13.5 冷机实测 P1 净耗时只有 65–85ms（GPU 48–66ms），旧的 1202–1433ms 是「HR+P0+P1」合计（`d0` 打在 HR/P0 之前的口径错）。**热点排序 = DFT 1.2–1.5s / P0 300–352ms / P4 542–1131ms / 编码 189–290ms**。编码已换 libjpeg-turbo（用户授权；4:4:4 q100 色度误差 p99 stb 1.36 → 1.58/255，4:2:0 是 9.77，安全区内换 2.5× 速度，复用构建里已有的 `jpeg-static`）。不移植 PC 的 Sabre/MGC（逆向 GCam 专有二进制、许可不明、与 4 帧 DFT 融合强耦合）；将来若再碰方向场，前提是 `rcd_dir_half` 开关 + RT 结构（1/2 分辨率 + `lpf` 输入）+ `rcd-linecompare` 对 AMaZE 离线判据。
- [2026-11-12] **融合默认切空间域（`mfnr_dft=false`）**：两场景 A/B 快 1.8~2.8s、暗部 σ 2.08→1.71、100% 裁剪无可见差；DFT 保留为设置页开关。
- [2026-11-12] **不写新融合（T3 收尾）**：运动模拟 1~30px 位移下，现有 32px mismatch 权重与逐像素 rejection 差 0~1.7 LSB（肉眼不可见）；将来见运动拖影先做 mismatch 权重 guided upsample。**P0 不加 fence 窗口**（p0Ms 326→547，纯同步往返）；burst_dump 保留（默认关、哨兵控制）。

## 预览体感与条带/保活（11-13）

- [2026-11-13] **条带化只能用 `glScissor`**：全屏三角形 UV 按 NDC 插值，缩 `glViewport` 会让每条带重复整幅图（0.13.18 事故，预览"重复 N 次"）。
- [2026-11-13] **still 引擎按生命周期保活**（相机页可见+亮屏；不可见/熄屏释放），不再定时释放：显存驻留不耗电，重建 init 135~265ms + 2.4GB 分配才耗电且卡。
- [2026-11-13] **fence 窗口（在飞 2）与时间片让路不采用**：真机实测 fps 零收益，时间片纯亏 231ms；掉帧不是队列深度问题。
- [2026-11-13] **快门定格到动画结束即恢复**（不等合成），处理期掉帧换体感；相机页请求 120Hz（窗口默认 60 会锁死 Compose 动画帧率）。

## HDR gainmap 语义与高光判据（11-13）

- [2026-11-13] **gainmap = 标准乘性比值**（`y_hdr/y_sdr`，clamp `[1, hdr_white/sdr_white]`，对照 libultrahdr `gainmapmath.cpp:775`）：规范里没有"中灰以下 ratio 恒 1"、也没有白点门限；0.12.230 的加性写法是自创，实测把灯盘 63% 像素留在 ratio=1。
- [2026-11-13] **欠曝不设硬上限**：相机工程的做法是"判据带面积权重"，不是钳 EV；1EV 硬限会砍掉大面积高光（逆光/白墙）的合法欠曝。总提亮 2EV 保留为兜底。
- [2026-11-13] **相册/大图 = 覆盖层，相机页常驻**：整页替换会销毁 SurfaceView，返回要重建 EGL + openCamera + session（1~2s 黑屏）。
- [2026-11-13] **跨页动画用单层淡入，不用 Crossfade**：两层不透明全屏页共存时中间帧会混合，观感是整屏闪一次。
