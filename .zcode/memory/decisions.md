## 平台与成像内核

- [2026-09-17] **首发 Android、vivo X300 专项 Tier-0** — raw/YUV 对应 Camera2；**全 GPU 路线**（RCD/降噪，CPU 路径删除）；需求基线 v2.0（D1–D13）：爱好者向、「M 档」、DNG 开关默认关、RAW binned 4080×3072、接受预览/成片差异、**基准色彩科学 + 理光 LUT 风格层**
- [2026-09-18] **采集/媒体基础** — 预览走 SurfaceTexture 系统路径（Mali RG8 TexSubImage2D 静默全黑）；手动对焦默认 10D；镜头按 ID 启停；FILMKIT_*/tools/bin 不入库
- [2026-09-18] **版本与出包** — 远端 `wanglei96/Filmkit` main、附注标签 `v<versionName>`；`filmkit-<versionName>.apk` 单文件覆盖制（更新原"根目录 filmkit.apk 覆盖制"）；**每轮对话只打一个 tag**（曾违反，清理 56 个中间 tag）
- [2026-09-18] **相机 UI 走专项** — PhotonCamera 结构骨架 + DAZZ 胶片质感；**主动审计约定**：UI 改动先按规范+交互清单自查再报用户
- [2026-09-18] **焦段条按发现镜头生成**（X300=15/24/70）；**变焦画质优先**（到长焦即切镜头，±3% 迟滞；数码延展被用户否定）
- [2026-09-19] **参数 A/手动模型** — EV、AE(Tv+ISO)、WB 三组独立默认 A；范围/步进取自 HAL；**手动 WB = HAL 恒 AWB AUTO + 引擎侧补偿**（HAL 三路径全证伪），**作用点 = raw 域**（黑阶后 CCM 前、G 归一相乘），三链同语义、DNG 不动
- [2026-09-20] **M 档=RAW 快捷开关**（与 DNG 解耦）；JPEG 质量 95/100 可选
- [2026-09-30] **CI 只手动触发**（`workflow_dispatch`）——push 自动构建顶爆 500MB Actions 配额；出包在本地做、不上传 artifact

- [2026-09-20] **RCD 单趟三段 fragment 管线** — 研读 PC 结构+论文自写（GPL 不抄码）；默认 RCD、bilinear 保留 A/B；**性能取向=中间量预计算全图复用**（12MP 1969→477ms）
- [2026-09-20] **降噪两段式** — P0 RAW 域同色 bilateral + P4 色度平滑（色差域、Y 零损失）；只接 RCD 质量档
- [2026-09-21] **LSC 接在去马赛克后、CCM 前**（网格低频单元≈240px；关闭档绑 1×1 全 1 网格）；**P2 标准色彩链自建**（ColorMatrix/ForwardMatrix 双光源 + Bradford，默认开、可 A/B、缺失回退 HAL CCM）
- [2026-09-21] **斑马纹只进预览**；**FilmParams 契约按实际长度读取（下限 26）**，新增参数一律末尾追加 + 防呆
- [2026-09-21] **影调/色彩类改动必须自带可关闭 A/B 通路**（无开关致跨时刻无法归因）；**离线调参只在"同一时刻 A/B 对"上成立**
- [2026-09-22] **提亮用线性域曝光不用幂提亮**（ev/p/blk 三旋钮正交）；**自适应影调判据 = 中间调锚定**（职责=提中间调以提色彩，**提亮上限才是控制量**）；高光软肩 knee 必须与目标白点对齐
- [2026-09-22] **饱和/外观类改动只能用"有边界"的手段**；**色度增强判据=亮度相对饱和**；**DNG 对照只定位缺口不当绝对标尺**
- [2026-09-22] **LUT 插在输出 OETF 之后**（display 域）、kFsHist 必须同源；**不做"理光/徕卡引擎"、不照搬 RawProfile**（PC 8 引擎无理光/徕卡，其 RawProfile 是未接线代码）

## 色彩链、管线与 MFNR

- [2026-09-23] **两条管线细节**：P4 降噪职责归空间半径（σc 只保真实色度边缘）、**关降噪也走 P0**（k=0 与直读数学等价且更快）；局部色调映射低频图尺寸随渲染分辨率（固定尺寸致预览/成片提亮尺度差 3.4×），预览流上限 2160
- [2026-09-23] **MFNR 对彩噪特别有效且让大尺度空间降噪变得不必要**（彩噪跨帧独立；HDR+ 原文 "making aggressive spatial denoising unnecessary"）
- [2026-09-24] **色彩基准**：先定为同机位 PC 成片 → **后改为"色准对标基准 = 实物本身"**（用户拍板），PC 降级为参照
- [2026-09-24] **方向链路三定案** — `orientationStep`=设备物理旋转步进（**绝不能喂 Display.getRotation()**，语义相反）；成片裁切跟设备姿态、与窗口解耦；相机页不转窗口（正解=GL 预览收设备旋转 + UI autoRotate）

- [2026-09-27] **管线顺序定稿**：多帧融合(Bayer)→黑阶+WB→去拜耳→LSC→高光重建→CCM→局部色调映射(可选)→filmic/AgX→基准曝光+EV→高光滚降→锐化→OETF→3D LUT→颗粒→JPEG；硬约束 LUT 必须 OETF 后
- [2026-09-27] **EV = 单一来源**（`FilmParams[0]=base_ev+用户EV`）+ 撤 HAL AE 补偿；EV = filmic 前线性域；删旧 log 域胶片链与色彩外观层设置项（域外延展 = 篡改 filmic 输入）；ccm_std 与局部色调映射保留
- [2026-09-27] **MFNR 立 P0 优先于 AgX**（用户拍板）；管线加**轻度锐化**层（线性显示域 luma USM、OETF 前）
- [2026-09-27] **MFNR 阶段一三定案** — ① 对齐 tile 直接进阶段一（全局单一位移不成立）② **融合=等权均值**（置信度加权被证系统性判低）③ **tile 64 + 每通道网格亚像素双线性**；设置三档（0/自动暗光/强制）；采集 = maxImages 4 + 帧 1-3 拷贝即 close
- [2026-09-27] **空间降噪 σ 融合后 ÷√N**；**噪声测量必须用与噪声水平无关的选块判据**（低频图梯度，自适应梯度 mask 有幸存者偏差）
- [2026-09-28] **手部验收标准（用户定义）**：允许自然拖影、不容重叠错误 → 权重分段（m≤0.10 全融合、m≥0.35 硬清零）；**MFNR 运动判据 = 残差 + 位移幅度双判据**；**诊断插桩先于修改**的方法论确立

## 质量铁律与方法论

- [2026-09-28] **项目大前提（用户拍板，写入 AGENTS.md）**：质量 > 成本/工期；严禁简化关键质量管线（论文一手 + 成熟开源实现逐行对照）；**性能取舍必须实测、不替用户决定**；**对标口径 = 标准做法，非 PC**
- [2026-09-28] **OETF 改真 sRGB**（`pow(c,1/2.2)` 不是 sRGB；kFsOut/kFsHist/measureSceneStats 三处同步）
- [2026-09-28] **色度差定位到 filmic 前的色彩矩阵**；**PC 选 filmic 不经 DCP**；**全局 EV 路线关闭**（正解必须局部手段）
- [2026-09-29] **渲染工作点配平** — base_ev 默认 0→+0.7（PC 链首恒乘 0.7EV 标定）；验收同刻三方 C\* 差 14.5%→−1.1%
- [2026-09-29] **LSC 边缘软限幅必须通道共享阻尼因子**（独立压缩引入边缘 a* ±0.9 漂移）；**图像增益/阈值的硬拐点一律改平滑**（硬 knee 在插值后成可见马赫带）
- [2026-09-29] **降噪不压弱彩（三连拍 A/B 定案）** — 白墙 C\* 零差异；弱彩差剩余嫌疑 = 模拟 LSC/RCD/链间差异
- [2026-09-30] **出包前两件必做**：新增 GPU 路径必跑 `tools/check-diag-fields.py`；**同刻 100% 裁剪目视**（定量指标只作辅证）。配套两条判据纪律：判据必须先在已知正/负样本上验证（"相邻像素相同占比"在 PC 纯黑区 77%，不成立）；纹理保真必须覆盖 2–4px 细纹尺度且 σ 分解（亮度分层 + 色度 1–32px）

## C / A / D 专项

- [2026-09-29] **C 落地 = 逐通道 (A,B) 方差系数 + 强度滑杆即 σ 乘子**（1.0 = 真实 σ）；mismatch/tile-RMS 用 k=1；**噪声模型优先级**：用户导入 > 内置实测（型号+焦距）> Camera2 > ISO 估算；**多摄标定方法学**：DNG 水平差分横向比值 × HAL 主摄模型；**设备内自动标定暂不做**
- [2026-09-30] **A 落地形态**：按 CFA 平面独立合并（HDR+ 语义）、16×16 平面 tile 半重叠 + 修改升余弦窗；位移 tile 中心 round 偶数；c=256；**neff 恒 4**、不叠 mismatch/conf 权重
- [2026-09-30] **compute program 现场创建、用完删除**（init 创建的在该 Mali 上写入全丢）；**实验路径严禁进 init 阻塞检查**（失败仅日志 + 运行时回退）；**imageStore 目标纹理一律 `glTexStorage2D`**
- [2026-09-30] **对标口径修正（用户指正）**：PC 对照样片同为 **4 帧** → 加帧数不是追平 PC 的正当路径
- [2026-09-30] **降噪分级职责**：P4（半径 3）管 1–3px 彩点；D-1（à trous 5 级）管 4–32px 色斑；**单帧后段空间核路线否决**（两次真机证明保纹理与强降噪不可兼得）
- [2026-09-30] **亮度杠杆在 merge 阶段**（时域×空间联合 P0 = 4 帧 × 24 邻域 = 96 样本）；**对齐最细精化层 = 1/2 域**（HDR+ §4），真机同帧 A/B 全胜、整机 +0.1s
- [2026-09-30] **P0 亚像素默认开**（用户拍板：+43.7%/+46.5%、细节无损失）；**两个杠杆必须一起看**（整数采样会把对齐精度的差别整个抹平）；**D-2 收线**：颗粒 = 胶片感、是风格不是缺陷

## 拍照线程与 LUT（10-01）

- [2026-10-01] **拍照独立线程/context 重做必须带开关**（0.10.83 那次失败丢了用户的照片）；**"只启动不销毁"**从根上消除竞态；**空闲释放要连 context 一起销毁**（只销 FrameRenderer 会让 Mali 分配不出全分辨率纹理）；**进程级设置必须能被后建实例补齐**（LUT/YUV 矩阵走进程快照）；**largeHeap 兜底连拍内存**；**OOM 时「这张失败」优于「进程 abort」**（用户红线：失败不以丢照片为代价）
- [2026-10-01] **调度类优化在本平台不再投入**：DFT 分片/glFlush/sleep/线程降优先级四种手段实测**全部无效**（Mali 不在 context 间轮转）⇒ 帧率定性为 GPU 算力·带宽硬约束
- [2026-10-01] **LUT 无损口径**（float 不重采样不量化、原文件字节存档；超上限三线性重采样 128³）；**预览降载落点 = 引擎中间纹理**；**强度滑杆 = 相对拖动**、拖动中不写 prefs

## NN 判死与曝光决策（10-02）

- [2026-10-02] **判死：跨域模型不可直接用 + 微调需数据量 → 转 HDR+**：口径全修对后真机观感仍无改善（文字区梯度 −24%、平坦区斑块状伪影），**不如 P0**；四次微调留出集**全过拟合**（官方 3 万+ 对 vs 我们 4 场景）；代码与开关保留（`nn_dn` 默认关）

- [2026-10-02] **曝光 ×N + ISO ÷N = 亮度与高光裁切完全不变，纯赚 SNR**：离线解析收益 √N 与物理上限逐位吻合（N=8.66 → 2.95×）；约束三条 = ISO 下限/快门上限/运动预算
- [2026-10-02] **运动判据 = 1s 窗口矢量平均角速度**（Night Sight §2.3，不用 RMS——帧内模糊是角度积分）；**纹理预算维持细节优先 2.2px**（放宽 4.5px 属误读用户意见，已撤回）；曝光上限交用户拍板
- [2026-10-02] **σ 恒为真实噪声；强度 <1 走输出 mix、>1 才作 σ 乘子**：σ 被压小 ⇒ bilateral 的 `exp(−0.5d²)` 指数塌陷 ⇒ 降噪近似归零，且散粒噪声 ∝√x 使**亮部受害最重**；`nzPostP90 ≈ nzPreP90` 是失效指纹
- [2026-10-02] **三摄噪声模型改用 GCam 生态标定**：HAL 的 cam2 profile 其 G 通道比 R/B 低一半（物理上不合理）；优先级 = 用户选定 > 内置 > Camera2，**手动选定是全局的**

## 影调与曝光判据（10-03）

- [2026-10-03] **曝光目标 = "刚好不烧高光"（HDR+ §4），但用户优先噪声 ⇒ 默认曝光给足**：实测该场景渲染域高光 3.02 > 白点 2.438 达 0.58EV，两者**物理上不可兼得**；用户拍板：先压噪声，高光交给影调层
- [2026-10-03] **判据的域必须与物理过程一致 + 不为 0.1% 的饱和像素牺牲全图**：预览链走 OES（ISP 已 tonemap）与 RAW 归一化域不是一个尺度（`w999` 2.09 vs 成片 2.674）⇒ 曝光判据只认成片域 `sw999`；`w999` 是 P99.9，那 0.1% 基本是窗/灯，为它们欠曝 0.35~0.85EV ⇒ 全图光子 −25%~45% ⇒ 中高亮表面冒白斑
- [2026-10-03] **影调层固定、曝光层自适应**（标准做法）：darktable/AgX/ACES 的影调映射都是一套固定参数，场景差异由曝光吸收；我们做反了（曝光固定、影调每场景自适应）才是设置爆炸与"修一个坏一个"的根源
- [2026-10-03] **横拍方向与画幅必须快门瞬间快照**：MFNR 渲染 3~4s，凡"拍照时刻的状态"被数秒后的链路读取，一律快照
- [2026-10-03] **超广畸变只能自校正**（HAL 无能力、无标定）；裁边取舍待拍板：完整校正（视场窄 5~10%）/ 部分校正 / 不校正

## 高光重建、品红与紫边（10-03 → 10-06）

- [2026-10-03] **filmic HR 的 `threshold` = 曝光前域白点**（旧实现写死 1.0 致大面积误重建，真机 clipB 523→2）；**opposed chrominance 置 0**（输入已 P0 降噪使补偿方向反了，四张 DNG 验证安全）；**inpaint 噪声取 0**（相对幅度 3× 致彩色颗粒）。**伪彩判据被真实样片否决**："色度高亮度平坦"前提反向（品红亮度带通 = 全图 14×、56~66% 贴轮廓）⇒ 品红 = 逆光边缘紫边渐晕，正解 = defringe（RT 同形态，0.10.134 落地）+ 低频噪声另治

## 相册与预设（10-11 → 10-13）

- [2026-10-13] **预设交互一律照开源调研，架构师不自拟**：自拟两轮（全参数铺开滑杆 / 分层）被用户连骂；PR-2 调研后按 LrC/Capture One/darktable/RawTherapee 四家一致做法落地（"包含哪些"= 勾选或常用项、"调到多少"= 点开那一行）。配套三条：**一级页只给常用参数 + 「完整参数 >」**（完整参数进二级页 `CameraPresetFullEdit.kt`）、**面板用不透明底**（半透明会让取景亮色文字透出）、**返回键分层**（二级页→快捷菜单→面板→全关才退出 app，`cameraBackTarget`）
- [2026-10-13] **内置预设可改、只禁删 + 恢复默认**（推翻 PS-1 的"内置整体只读"）：改动走覆盖层（`BuiltinOverrides`），出厂 assets 不动 ⇒ 升级时未改过的内置跟着更新
- [2026-10-13] **白点取方案 A（不死白优先）**：`[38]` 2.5~2.7 → 4.0，死白起点 2.40~2.60 → 3.55 EV；代价亮部变暗 −15.9~−18.0 LSB、拟合残差 8~10 → 12.7~17.4。等真机验收后与方案 B（回滚）定档
- [2026-10-13] **编辑器链路白点 >2.44 EV 无效如实标注**（`wh` 被显示域 clamp 到 1.0）：不灰显、不收窄量程（会砍掉拍照链路实测有效档位）

## 设置页、图标与编辑器立项（10-04）

- [2026-10-04] **设置页信息架构**：主页只留拍摄高频项，其余按域收四个抽屉（画质 / 影调与色彩 / 暗光与曝光 / 实验与诊断）；已定案的 A/B 开关归实验与诊断；NN 降噪 / NN A/B / 静拍 YUV709 入口删除（读取端锁死默认值）。**应用图标定稿 = G 款光圈叶片 + 居中镜片 vector**（13 path），资源 = PC 同构完整套（vector fg + color bg + monochrome + legacy 全密度并存，缺一即真机渲染异常）
