## 基础与平台

- [2026-09-17] **首发 Android、vivo X300 专项 Tier-0** — raw/YUV 诉求对应 Camera2；**全 GPU 路线**（RCD/降噪，CPU 路径删除）；X300 审计已验证 RAW/逻辑多摄可用
- [2026-09-17] **需求基线 v2.0（D1–D13）** — 爱好者向；「M 档」模式；DNG 开关默认关；RAW binned 4080×3072；接受预览/成片差异；**基准色彩科学 + 理光 LUT 风格层**（替代复刻胶片曲线）；样张=公开库 CI+实拍；多帧融合 Backlog（收益=SNR √N）；预设命名中性（后改用理光系原版名）
- [2026-09-18] **采集/媒体基础** — 预览走 SurfaceTexture 系统路径（X300 Mali RG8 TexSub 静默失败）；手动对焦默认 10D 试值（HAL 报 0 但硬件支持）；镜头按 ID 启停（隐藏物理镜头输出黑帧）；FILMKIT_*/tools/bin 不入库
- [2026-09-18] **版本与出包** — 远端 GitHub `wanglei96/Filmkit` main，附注标签 `v<versionName>`；出包 `filmkit-<versionName>.apk` 单文件覆盖制；**每轮对话只打一个 tag**，中间验证包只出 APK 不打 tag
- [2026-09-18] **相机 UI 走专项（方向 C 定稿）** — PhotonCamera 结构骨架 + DAZZ 胶片质感（v0.4.6–0.5.1 落地 FilmTheme/FilmMotion/控制瓦片/LUT 菜单/沉浸导航）；**主动审计约定**：UI 改动先按规范+交互清单自查再报用户
- [2026-09-18] **焦段条按发现镜头生成**（更新早期"写死 15/24/35/50/85"）— 启用镜头等效焦段去重升序（X300=15/24/70），点按原生 1.0x 直切；倍率基线=主摄；自定义焦段 ≤3（20–120mm，setZoomEquiv）；**变焦画质优先**（到长焦即切镜头，±3% 迟滞带）
- [2026-09-19] **参数 A/手动模型** — EV、AE(Tv+ISO)、WB 三组独立默认 A；拖刻度进手动、点 A 回自动；范围/步进取自 HAL（evInfo）
- [2026-09-19] **手动 WB = HAL 恒 AWB AUTO + 引擎侧补偿** — HAL 的 CCT/GAINS/矩阵三路径 X300 全部证伪；补偿=wbGains(目标K)/wbGains(自动K)。**作用点后定为 raw 域**（黑阶后 CCM 前、G 归一相乘，v0.10.26）——预览 OES/YUV/RAW 三链同语义；DNG 底片不动
- [2026-09-20] **M 档=RAW 快捷开关**（与 DNG 底片开关解耦，prefs raw_mode）；预览框 `weight(1f, fill=false)` 自适应高度
- [2026-09-20] **早期成像小定稿** — BT.601 静拍解码正确（暗部 R/G 差 0.001）；JPEG 质量 95/100 可选；水平仪=旋转线式（EMA 0.22 + 滞回 0.4/1.2°）；预设收敛为单一「标准」全中性

## 成像内核（M3）

- [2026-09-20] **RCD 单趟三段 fragment 管线**（P1 方向场+LPF / P2 G@RB / P3 色度+CCM）— 研读 PhotonCamera 结构+论文自写（eszdman GPL 不抄码）；中间图 RGBA16F、WB 线性化前置；bilinear 保留 A/B；质量档 prefs demosaic_quality 默认 RCD；**性能取向=中间量预计算全图复用**（12MP RCD 1969→417ms）
- [2026-09-20] **降噪两段式** — P0 RAW 域同色 bilateral（步长 2 网格=9 同色位）+ P4 色度平滑（色差域、Y 零损失）；只接 RCD 质量档；两档定稿（标准 P0 0.28/P4 2.20、强 2.20/2.60）；noiseProfile 不回填时 ns=0.030 回退
- [2026-09-20] **胶片内核补 norm-controlled 高光处理**（Filmic RGB/AgX 思路自研）；风格层=中性基准+LUT 架构（M4 吃社区 CLUT）
- [2026-09-21] **色彩内核 = 三点锚定 S + norm-controlled + 高光去饱和 + 中间调提亮**（v0.5.41；后随 filmic 迁移重构）；**高光重建 v1=中性外推**（保守；后由原生小波 HR 接管并删除旧件）
- [2026-09-21] **LSC 接在去马赛克后、CCM 前**（网格低频单元≈240px，与 mosaic 域逐像素差异 <1%；关闭档绑 1×1 全 1 网格）；LSC 数据可得（17×13，角落 6.24）
- [2026-09-21] **色彩外观层参数回中性占位**（"寡淡"是 libraw auto_bright 测量伪结论；浓淡交 M4 LUT；FilmParams[31..33] 保留）
- [2026-09-21] **P2 标准色彩链自建** — CameraCharacteristics 的 ColorMatrix/ForwardMatrix 双光源 + Bradford → camera(白平衡后)→sRGB；默认开（ccm_std）、可 A/B、缺失回退 HAL CCM
- [2026-09-21] **斑马纹只进预览**（passOutput 显式参数、成片恒 false，接口层堵死）；**FilmParams 契约按实际长度读取（下限 26）**（新增末尾追加+防呆）
- [2026-09-21] **影调/色彩类改动必须自带可关闭 A/B 通路**（v0.5.36 无开关致跨时刻无法归因）；**离线调参只在"同一时刻 A/B 对"上成立**（跨时刻受场景光变化污染）
- [2026-09-22] **提亮改用线性域曝光不用幂提亮**（v0.6.17）— pow(x,g) 是抬暗部旋钮、x*exp2(ev) 才是亮度旋钮；三旋钮正交：ev/p/blk
- [2026-09-22] **自适应影调判据 = 中间调锚定**（kTarget 0.26、gain=clamp(0.26/lin_mid, 1, 1.6)、binAt(0.50)）— 职责=提中间调以提色彩，非校正曝光；P95→中位→P95→P99→中位五次反复的结论：**手段与推导必须分开判断**；**提亮上限才是控制量**（kMax=1.6）；高光软肩 knee 必须与目标白点对齐（旧版 knee<白点把正常亮部压进压缩区）
- [2026-09-22] **饱和/外观类改动只能用"有边界"手段** — look_sat 保 1.0、look_chroma 只放已浓色；全局乘性放大器会连白平衡残余误差一起放大
- [2026-09-22] **色度增强判据=亮度相对饱和**（rel=max|cc|/luma）；**knee 1.0→0.4 定向补低饱和**（缺口剖面"低饱和重、高饱和轻"）；**DNG 对照只定位缺口不当绝对标尺**（ForwardMatrix 缺失→libraw 退 ColorMatrix；libraw 的 C\* 是偏好非正确）
- [2026-09-22] **LUT 域与插桩** — 插在输出 OETF 之后（display 域）、kFsOut 内同 pass、**kFsHist 必须同源**；卡片预览=固定测试图一次性生成+缓存；内置 LUT 用原版名（ASCII 文件名、显示名取 TITLE）；**④ 纹素中心校正废弃**（恒等 LUT 实测现行 `t=c*(N-1)` 与硬件等价，照搬会二次偏移）
- [2026-09-22] **不做"理光/徕卡引擎"、不照搬 RawProfile**（PC 8 引擎无理光/徕卡；RawProfile 是未接线代码）；调研文档入库 `docs/research/`（不放 gitignore 目录）
- [2026-09-22] **误提交大文件用 git filter-repo 重写历史 + force push**（重写前必须先备份工作区副本）；`test_temp/` 与本地交接目录不入库

## 色彩链重构与对标（M4-9 起）

- [2026-09-23] **P4 降噪职责归空间半径，σc 只保住真实色度边缘**（旧 σc 0.035 吞真实色度）；**关降噪也走 P0**（k=0 = 仅线性化+WB，与 P1 直读数学等价且更快）
- [2026-09-23] **参考实现显示域数值不可直接当"提亮前"目标**（PC 中位 139/255 是提亮后；域混淆推出的 0.26 巧合可用）；**局部色调映射低频图尺寸随渲染分辨率**（每格≈128px；固定尺寸致预览/成片提亮尺度差 3.4×）；预览流上限 2160
- [2026-09-23] **M 档 RAW 所见即所得预览 = 立项（用户拍板先不做）** — 卡点=性能（RAW 全链 210–500ms vs 实时 33ms）；决定性未知量=X300 RAW 输出尺寸列表；LUT/预设已在预览生效
- [2026-09-23] **MFNR 对彩噪特别有效且让大尺度空间降噪变得不必要** — 彩噪跨帧独立、信号相关；HDR+ 原话 "making aggressive spatial denoising unnecessary"；大尺度色度平滑色度边缘仅剩 8–20%
- [2026-09-24] **色彩基准 = 同机位 PhotonCamera 成片**（用户指定；libraw/DNG 非标尺）→ **后更新：色准对标基准 = 实物本身**（用户拍板"拍出来比实物淡是事实"，PC 降级为参照，ColorChecker 专项）
- [2026-09-24] **高光去饱和判据用 max 通道**（蓝天空 luma 198/255 但 B 通道高命中；旧区间 (0.85,1.30) 从未触发）；改区间前必须反推判据点在真实成片的取值
- [2026-09-24] **方向链路三定案** — `orientationStep`=设备物理旋转步进（0/1/2/3，**绝不能喂 Display.getRotation()**，语义相反）；成片裁切跟随设备姿态、与窗口解耦；相机页不转窗口（PC 两段式：GL 收设备旋转 + UI autoRotate 90° 交换约束）
- [2026-09-24] **基础影调换哈苏形状 Reinhard 曲线**（`y=(1+k)x/(1+kx)`，k=5；旧 baseTone 暗部比哈苏低 565× 是"死黑/糊/白无层次"总根源；不复制专有 .hcurve 资产）→ 后由 filmic 原生件接管；kTarget 0.04 + 下限 0.35（静拍允许压暗）
- [2026-09-24] **预览直通（方案 A）** — HAL OES 与 RAW 域差 1.70–3.87×，线性增益无法同时对齐 → **已被 v0.8.0 域映射取代（本条作废）**
- [2026-09-24] **`docs/research/90-…原始转储.txt` 不可删**（含 LUT 同源独有结论：我们 .lut 与 `滤镜.cube` 逐点一致、与 PC .plut 78–90% 分量不同）；**"打包可切换渲染引擎"待办**（我们 filmic / 哈苏式 / AgX）
- [2026-09-24] **曝光差异归属相机侧**（PC 低曝光保暗部+曲线提亮 vs 我们 HAL 高曝光+曲线再提亮）→ 归入 MGC-AE 远期

## 管线定稿与 MFNR

- [2026-09-27] **管线顺序定稿**：多帧融合(Bayer)→黑阶+WB→去拜耳→LSC→高光重建→CCM→局部色调映射(可选)→filmic/AgX→基准曝光+EV→高光滚降→锐化→OETF→3D LUT→颗粒→JPEG；硬约束 LUT 必须 OETF 后（42 个 .lut 设计域 sRGB）
- [2026-09-27] **EV = 单一来源**：`FilmParams[0]=base_ev+用户EV`；撤 HAL AE 补偿（X300 对 RAW 流打折 +0.7→0.1）；**v0.10.22 更新：EV = filmic 前线性域**（PC/Darktable BaselineExposure 语义，静拍/预览统一）
- [2026-09-27] **「基准曝光」设置项**（−2..+2EV = BaselineExposure 语义；X300 实测差 0.5–0.9EV）；**删旧 log 域胶片链与色彩外观层设置项**（域外延展非恒等=老补丁篡改 filmic 输入；槽位保留引擎不消费）；**ccm_std 保留**（色准与影调正交）
- [2026-09-27] **局部色调映射保留**（A/B：暗部+中间调提亮、高光零影响、无噪声代价；去留不再议）
- [2026-09-27] **MFNR 立 P0 优先于 AgX**（用户拍板；AgX 归"可切换渲染引擎"选项待 MFNR 后）；管线加**轻度锐化**层（线性显示域 luma USM、OETF 前）
- [2026-09-27] **调参脚本迁 `tools/tuning/`**（test_temp 只存样片）；mimosa 插件禁用（git gate 误报无豁免；enabledPlugins=false）
- [2026-09-27] **MFNR 阶段一三定案** — ① 对齐 tile 直接进阶段一（HDR+/NS/PC 全 tile-based，手持全局位移不成立）② **融合=等权均值**（自加置信度加权因暗部噪声主导被否定；防鬼影归 P2）③ **tile 64 + 每通道网格亚像素双线性**（mosaic 2×2 打包点阵同相位 4-tap，零色度污染；2px 量化/1px+phaseFix 路线退役）
- [2026-09-27] **MFNR 设置三档**（prefs mfnr 0 关 / 1 自动暗光 ISO≥600 或曝光≥25ms / 2 强制；纯函数与单测同源）；**采集 = maxImages 4 + 帧 1-3 拷贝即 close**（maxImages 5+4 全程持有致 HAL 预配 125MB 闪退）
- [2026-09-27] **空间降噪 σ 融合后 ÷√N**（残余噪声漏过而纹理被抹）；**噪声测量必须用与噪声水平无关的选块判据**（低频图梯度；自适应 mask 幸存者偏差曾低估 σ 45%）
