# 决策

<!-- 已拍板的决策,append-only:只新增不改写历史条目;决策被推翻时新增一条说明。 -->

- [2026-09-17] **首发 Android、vivo X300 专项 Tier-0** — raw/YUV 诉求对应 Camera2；X300 审计已验证 RAW/逻辑多摄可用
- [2026-09-17] **全 GPU 路线（RCD/降噪）** — 用户拍板；CPU 路径会被删除，不做一次性工作
- [2026-09-17] **预设中性命名** — 规避胶片商标；用户后改为理光系 LUT 暂用原版名（成本低）
- [2026-09-17] **需求基线 v2.0（D1–D13）** — 爱好者向；「M 档」模式；DNG 设置开关默认关；RAW 用 binned 4080×3072（200MP 待审计）；接受预览/成片差异；**基准色彩科学+理光 LUT 风格层（替代复刻胶片曲线）**；胶片柔感优先（解析力保底）；样张集=公开库 CI+用户实拍；多帧融合 Backlog M6 后（收益=SNR √N 非文件大小）
- [2026-09-18] **预览改 SurfaceTexture 系统路径** — X300 Mali RG8 TexSub 静默失败，参照 PhotonCamera；静拍走 CPU 转 RGB888
- [2026-09-18] **手动对焦默认 10D 试值** — X300 HAL 上报屈光度 0 但硬件支持（vivo 自家 Pro 模式有滑杆）
- [2026-09-18] **镜头配置按 ID 启停（设置页）** — 隐藏物理镜头（超广 id4）输出黑帧无通用解，用户自关；参考 PhotonCamera per-lens 设计
- [2026-09-18] **焦段条统一镜头+变焦** — 15MM 自动切超广物理镜头、85MM 经逻辑相机无缝切长焦；等效焦距=物理焦距×43.27/传感器对角线
- [2026-09-18] **焦段条改按发现镜头生成（v0.4.4，更新上一条）** — 写死 15/24/35/50/85 与实际镜头组合不符（X300=15/24/70）；焦段条=启用镜头等效焦段去重升序，点按=原生 1.0x 直切
- [2026-09-18] **出包单文件覆盖制** — 根目录固定 filmkit.apk 每次构建覆盖，不再按版本号新建（用户要求省磁盘）；版本区分靠 build.gradle versionName + 开发计划记录
- [2026-09-18] **相机 UI 重设计走专项任务** — 用户对当前 UI 不满意；修 bug 会话不顺手改 UI，新窗口先设计定稿（参照 DAZZ/PhotonCamera）再重构 CameraScreen
- [2026-09-18] **版本管理：GitHub + 附注标签** — 远端 git@github.com:wanglei96/Filmkit.git（main）；每个 versionName 发版打 `v<versionName>` 标签；apk 不入库（gitignore），构建/发布靠 CI artifact 与 GitHub Releases
- [2026-09-19] **UI 专项定稿方向 C**（更新「走专项任务」条）— PhotonCamera 结构骨架 + DAZZ 胶片质感；v0.4.6–0.5.1 落地为 FilmTheme/FilmMotion token、控制瓦片、LUT 菜单、沉浸化导航
- [2026-09-19] **主动审计工作约定** — 每次 UI 改动先按设计规范+交互清单自查列项与用户确认（动效/触感/按压反馈默认检查项），不等用户批注
- [2026-09-19] **手动 WB = HAL 恒 AWB AUTO + 引擎侧补偿** — 补偿=wbGains(目标K)/wbGains(自动估计K) 写 filmParams wb 位；HAL 的 CCT/GAINS/矩阵三路径在 X300 全部证伪，弃用
- [2026-09-19] **变焦倍率基线 = 主摄等效焦距**（mainEquiv 最接近 24mm）— 70mm≈2.9x、15mm≈0.6x，非当前镜头
- [2026-09-19] **自定义焦段 ≤3 个** — 设置子页维护（20–120mm），与原生焦段合并去重总显示 ≤6；自定义=setZoomEquiv、原生=setFocal
- [2026-09-19] **参数 A/手动模型** — EV、AE(Tv+ISO 联动)、WB 三组独立默认 A；拖刻度进手动、点 A 回自动；UI 范围/步进取自 HAL 实际能力（evInfo）
- [2026-09-20] **变焦画质优先**（更新 v0.5.11「覆盖则留」条，数码延展被否定）— 到长焦焦段即切光学镜头；仅切换点 ±3% 迟滞带内保持当前镜头防抖
- [2026-09-20] **预设收敛为单一「标准」=全中性**（负片/黑白删除，中间调饱和 1.1→1.0）— 内置风格化预设无意义；预设=用户自建（LUT+参数保存，M4）
- [2026-09-20] **BT.601 静拍解码正确** — 实拍 A/B 定量（暗部 R/G 差 0.001）排除 709 错配；设置页开关保留供未来机型复查
- [2026-09-20] **JPEG 成像质量用户可选 95/100** — prefs jpeg_quality 默认 95；100 档体积 ~2.4 倍为预期
- [2026-09-20] **水平仪=旋转线式**（平移气泡否定）— 重力方位角 360° 连续 + EMA 0.22 平滑 + 模 90° 双向对齐 + 滞回 0.4/1.2°；对齐 Accent/不对齐白
- [2026-09-20] **M 档=RAW 拍摄模式快捷开关，与 DNG 底片开关解耦**（更新「DNG 开关默认关」语境）— prefs raw_mode 控制采集格式；dng_enabled 只管是否保留底片
- [2026-09-20] **预览框 weight(1f, fill=false) 自适应高度** — 预览按画幅占高，底部 UI 跟随；4:3 留白落屏底、16:9 受约束
- [2026-09-20] **RCD 实现=研读 PhotonCamera 管线结构+论文自写** — eszdman 仓库 GPL-3.0，算法可学代码不可抄；bilinear 保留 A/B 基线
- [2026-09-20] **降噪两步走** — M3 传统 RAW 域守 ≤900ms；NN 降噪+多帧融合 M6 后立项评估（夜景一流的必经之路）
- [2026-09-20] **胶片内核 M3 补 norm-controlled 高光处理**（Filmic RGB/AgX 思路自研）；风格层=中性基准+LUT 架构不变，M4 吃社区 CLUT 资产
- [2026-09-20] **成片样张与本地工具二进制不入库** — FILMKIT_*.jpg/dng、tools/bin/ 进 gitignore
- [2026-09-20] **RCD 单趟三段 fragment 管线**（P1 方向场+LPF / P2 G@RB / P3 色度+CCM）— 中间图 RGBA16F、WB 线性化前置；无迭代（参考实现本就单趟）；bilinear 保留 A/B
- [2026-09-20] **质量档 prefs demosaic_quality 默认 RCD** — submitRaw 加 demosaic 参数贯通；raw.render 日志加 demosaic/dirMs/gMs
- [2026-09-20] **性能取向：中间量预计算全图复用** — 方向场/低通图 P1 一次算完（预归一化），后续 pass 1-tap 读取；CFA 相位 uniform 查表；两项式梯度——12MP RCD 1969→417ms
- [2026-09-21] **M3-2 降噪为下一步主线（用户点名"降噪效果待优化"）** — RAW 域传统方法守 ≤900ms 预算；NN+多帧仍 M6 后
- [2026-09-21] **降噪只接 RCD 质量档** — bilinear 保持纯净基线；速度档无降噪
- [2026-09-21] **降噪两段式**：P0 RAW 域同色 bilateral（步长 2 网格=9 同色位，压源头）+ P4 色度平滑（色差域、Y 零损失）— 不做 bilinear 式钝化
- [2026-09-21] **noiseProfile 回退**：X300 不回填时 ns=0.030（归一化域），raw.meta 记录实测
- [2026-09-21] **handoff/ 交接文件夹不上 git** — gitignore 本地维护，README 按"接手 agent 视角"自包含，等用户指令更新
- [2026-09-21] **降噪两档定稿** — 标准 P0 0.28/P4 2.20、强 P0 2.20/P4 2.60；只接 RCD，bilinear 保持纯净基线（更新「降噪两段式」条）
- [2026-09-21] **色彩内核 = 三点锚定 S + norm-controlled + 高光去饱和 + 中间调提亮**（v0.5.41 定稿）— 黑位/高光 rolloff 保留，整体亮度对齐无 tone 水平（-2.5%）
- [2026-09-21] **高光重建 v1 = 中性外推（保守）** — 局部比值法只覆盖 0.128% 像素，降为低优先
- [2026-09-21] **斑马纹只进预览** — passOutput 加显式 zebra 参数、成片路径恒 false（接口层堵死）；拍摄类开关放快捷面板不放设置页
- [2026-09-21] **LSC 列 P0 / "寡淡"正解是色彩外观层** — LSC 数据已验证可得（17×13，角落 6.24）；DCP 只解决色准、其 LUT 不能提升饱和度；色彩外观层走 3D LUT
- [2026-09-21] **影调/色彩类改动必须自带可关闭 A/B 通路** — v0.5.36 无开关导致跨时刻无法归因
- [2026-09-21] **离线调参只在"同一时刻 A/B 对"上成立** — 跨时刻对比受场景光变化污染（neutral 变化即证据）
- [2026-09-21] **FilmParams 契约按实际长度读取（下限 26）** — 新增参数末尾追加 + 防呆，避免"整包静默全丢"
- [2026-09-21] **LSC 接在去马赛克后、CCM 前** — 网格低频（单元≈240px），与 mosaic 域逐像素应用差异 <1%，却省掉 5 个 shader 改动；关闭档绑 1×1 全 1 网格 = 恒等（shader 零分支）
- [2026-09-21] **色彩外观层（原 P1）参数回中性占位** — 真机复核证明"寡淡"是 libraw 默认 auto_bright 造成的测量伪结论；浓淡属风格，按 §0-D8/D9 交 M4 理光系 LUT（开关与 FilmParams[31..33] 保留）
- [2026-09-21] **P2 标准色彩链自建** — 用 `CameraCharacteristics` 的 ColorMatrix/ForwardMatrix 双光源 + Bradford D50→D65 自建 camera(白平衡后)→sRGB；默认开（prefs `ccm_std`）、可 A/B、标定缺失回退 HAL CCM
- [2026-09-21] **出包命名 `filmkit-<versionName>.apk` + 新包覆盖旧包** — 更新 2026-09-18「出包单文件覆盖制」条的命名部分（仍不留历史包）
- [2026-09-22] **每轮对话只打一个 tag（验收版）；中间验证包只出 APK 不打 tag** — 出包与打 tag 解耦（`filmkit-<versionName>.apk` 照出，tag 只在该轮收尾打一次）；本轮清理 56 个中间 tag，只留 v0.5.27-m2 / v0.5.47-m3 / v0.5.48-m3 / v0.6.8-m4，清单与恢复命令在 `docs/git-tags-backup-20260922.txt`
- [2026-09-22] **内置 LUT 用原版名、暂不中性化**（更新 §0-D9「命名中性化待定」）— 资产文件名用 ASCII（避路径编码风险），显示名取 .cube 的 TITLE
- [2026-09-22] **LUT 插桩＝display 域、接在输出 OETF 之后**（放在 `kFsOut` 内，同一 pass、不额外加 pass）；**`kFsHist` 必须同源**，否则选了 LUT 后直方图/斑马纹与画面不符
- [2026-09-22] **LUT 卡片预览＝固定测试图 × 一次性生成并缓存**（编译期 / 首次运行 / 导入时），**不做实时缩略图**（每次开面板 N 次渲染 + GPU 读回，费电）
- [2026-09-22] **误提交大文件用 `git filter-repo --invert-paths` 重写历史 + force push**；重写前**必须先备份工作区副本**（filter-repo 的 `reset --hard` 会删掉被移除路径的工作区文件）
- [2026-09-22] **提亮改用线性域曝光，不用幂提亮**（v0.6.17）— `pow(x,g)` 是"抬暗部"（降对比）的旋钮（线性域 0.01 放大 2.35×、0.5 只放大 1.13×），`x*exp2(ev)` 才是亮度旋钮。三个旋钮至此正交：`ev` 亮度 / `p` 对比 / `blk` 黑位
- [2026-09-22] **自适应影调默认开、可关**（v0.6.18，`FilmParams[35]`，设置页「自适应影调」）— 真机三场景场景白点（显示域 P95）普遍偏低，暗场景要 +1.2EV、亮场景只能承受 +0.3EV，**差 4 倍**，固定补偿无解；白点取 **P95**（P90 会把增益打满上限 4.0×、P99 被小面积高光骗）；增益限幅 [1,4]× 只提亮不压暗；统计放在 `passFilm` 内使预览/YUV 静拍/RAW 静拍三路径共用
- [2026-09-22] **高光软肩的 knee 必须与增益目标白点对齐**（v0.6.19）— knee 低于目标白点等于让"正常亮部"也落进压缩区（v0.6.18 的 knee 0.75 < 目标 0.90，把 L\*75–85 段梯度从 4.00 压到 0.00）；曲线用指数软肩 `1-exp(-u)`（l=1.0 处斜率 0.37）而非 `t/(1+t)`（0.25）
- [2026-09-22] **饱和/外观类改动只能用"有边界"的手段** — `look_sat`（全局乘性增益）保持 1.0；色度 S 曲线（`look_chroma`）只放大已浓的色。v0.6.14 用全局 1.5× 补 C\* 时把白平衡残余暖偏同比放大（白墙 b\* +1.63→+2.31）—— 乘性放大器不分"该放大的色"与"该保留的误差"
- [2026-09-22] **LUT 插桩位置（display 域、输出 OETF 之后）确认正确** — 独立调研核实 PhotonCamera 的预览链 `LutRenderer` 与成片链 `LutImageProcessor` 都在**非线性 sRGB 显示域**，其 `.plut`/`.cube` 的 curve 默认 SRGB、gamut 默认 SRGB，入口变换链 `srgbToLinear → applyLutColorSpace(identity) → applyLutCurve(linearToSrgb)` **恒等抵消**
- [2026-09-22] **不做"理光/徕卡引擎"，也不照搬 `RawProfile`** — PhotonCamera 的 8 个引擎（AdobeCurve/Hncs/Lumix/Canon/AgX/Spektrafilm/Sigmoid/Filmic）里**没有理光/徕卡**（徕卡仅是 Lumix 的一个 PhotoStyle）；其 `RawProfile`（色彩空间+log+基线 LUT）经核实**是未接线代码**（`rawLut` 指向不存在的 assets、`setColorSpace`/`setLogCurve` 无调用者）
- [2026-09-22] **调研文档入库 `docs/research/`**（不放 `handoff/`）— `handoff/` 在 .gitignore 内，报告放那里不会被 git 跟踪
