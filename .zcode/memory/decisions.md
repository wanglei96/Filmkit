## 平台与成像内核

- [2026-09-22] **饱和/外观类改动只能用"有边界"的手段**；**色度增强判据=亮度相对饱和**；**DNG 对照只定位缺口不当绝对标尺**

## 色彩链、管线与 MFNR
- [2026-09-24] **色彩基准**：先定为同机位 PC 成片 → **后改为"色准对标基准 = 实物本身"**（用户拍板），PC 降级为参照
- [2026-09-24] **方向链路三定案** — `orientationStep`=设备物理旋转步进（**绝不能喂 Display.getRotation()**，语义相反）；成片裁切跟设备姿态、与窗口解耦；相机页不转窗口（正解=GL 预览收设备旋转 + UI autoRotate）

## 质量铁律与方法论
- [2026-09-28] **项目大前提（用户拍板，写入 AGENTS.md）**：质量 > 成本/工期；严禁简化关键质量管线（论文一手 + 成熟开源实现逐行对照）；**性能取舍必须实测、不替用户决定**；**对标口径 = 标准做法，非 PC**
- [2026-09-28] **OETF 改真 sRGB**（`pow(c,1/2.2)` 不是 sRGB；kFsOut/kFsHist/measureSceneStats 三处同步）
- [2026-09-30] **出包前两件必做**：新增 GPU 路径必跑 `tools/check-diag-fields.py`；**同刻 100% 裁剪目视**（定量指标只作辅证）。判据必须先在已知正/负样本上验证；纹理保真必须覆盖 2–4px 细纹尺度且 σ 分解

## C / A / D 专项
- [2026-09-30] **P0 亚像素默认开**（用户拍板：+43.7%/+46.5%、细节无损失）；**两个杠杆必须一起看**；**D-2 收线**：颗粒 = 胶片感、是风格不是缺陷

## 拍照线程与 LUT（10-01）
- [2026-10-01] **拍照独立线程/context 重做必须带开关**（0.10.83 失败丢过照片）；**"只启动不销毁"**消除竞态；**空闲释放连 context 一起销毁**；**进程级设置能被后建实例补齐**；**largeHeap 兜底连拍内存**；**OOM 时「这张失败」优于「进程 abort」**

## NN 判死与曝光决策（10-02）
- [2026-10-02] **判死：跨域模型不可直接用 + 微调需数据量 → 转 HDR+**（四次微调全过拟合）；代码与开关保留（`nn_dn` 默认关）
- [2026-10-02] **曝光 ×N + ISO ÷N = 亮度与高光裁切不变，纯赚 SNR**（收益 √N 与物理上限吻合）；约束三条 = ISO 下限/快门上限/运动预算
- [2026-10-02] **运动判据 = 1s 窗口矢量平均角速度**（Night Sight §2.3）；**σ 恒为真实噪声，强度 <1 走输出 mix、>1 才作 σ 乘子**；**三摄噪声模型用 GCam 生态标定**（HAL cam2 profile G 通道不物理）

## 影调与曝光判据（10-03）
- [2026-10-03] **曝光目标 = "刚好不烧高光"，但用户优先噪声 ⇒ 默认曝光给足**（两者物理上不可兼得，高光交给影调层）
- [2026-10-03] **影调层固定、曝光层自适应**（darktable/AgX/ACES 标准做法；我们做反了才是设置爆炸的根源）
- [2026-10-03] **横拍方向与画幅必须快门瞬间快照**（MFNR 渲染 3~4s，凡"拍照时刻的状态"一律快照）；**超广畸变只能自校正**（HAL 无能力）

## 高光重建、品红与紫边（10-03 → 10-06）
- [2026-10-03] **filmic HR**：`threshold` = 曝光前域白点（写死 1.0 致大面积误重建）；**opposed chrominance 置 0**；**inpaint 噪声取 0**；伪彩判据被真实样片否决 ⇒ 品红 = 逆光边缘紫边渐晕，正解 = defringe
- [2026-10-06/07] **紫边两类分治 + 品红带机理闭环**：A = 4px 窄峰（锐化主放大器）；B = 逆光窗框品红窄峰。色散 = 管线产生（RAW 域三通道对齐、成片 dRG +0.9~1.0px）；**品红带 = B 缓 G 陡错位带，RCD 类固有**；[56]/[57]/[58] 默认关存档（三轮真机 A/B 未证明收益）

## 相册与预设（10-11 → 10-13）
- [2026-10-13] **白点 4.0 = R-3 定档值、不是上限**（2026-10-26 用户质疑后确认；死白起点 3.55 EV；改动需真机依据）

## 设置页、图标与编辑器立项（10-04）

- [2026-10-06/07] **设置页/图标/编辑器（P0-P8 期）范围定案**：设置页四 Tab、图标规范、内建编辑器（kFsStyle 链）；细节见归档快照

## 引擎插槽与影调架构（10-13）
- [2026-10-13] **引擎切换第 2 步直接对齐 PC**（公共管线 + 引擎插槽）：**引擎 = 1 pass**、输出契约线性 sRGB（OETF 只做一次）；**切口 = gamut 归引擎、外观层归公共**
- [2026-10-13] **参数面：`FilmParams` 只加 1 槽 `[98] engine_slot`**（0 = 内置 filmic）；引擎私有参数走独立 KV；**加/删引擎不改槽位布局与 DB schema**。阶段 0–1 硬判据 = `[98]=0` 时同帧 CRC32 逐字节等价
- [2026-10-13] **影调判据改用可分辨跨度**（每 0.1 EV ≥1 LSB 能持续多远）；**公共工作空间 Rec.2020 单独一期**（与插槽重构同期会毁掉零回归判据）；阶段 1 用"单真源 + 运行时切片"

## 引擎插槽阶段 2/3 与全局开关（10-14）
- [2026-10-14] **`[35]` auto_tone 必须旁路 —— 它"不走 uniform"**：`updateFilmicEV` 无条件调用 ⇒ 成员变量副作用逃出引擎边界 → 成片 `[0]`。**`[28]` 的旁路值是 1.0**（引擎 1 复用 uToneK 作为整条 sigmoid 的应用权重，置 0 = 空转）
- [2026-10-14] **新增判据 0：新引擎必须真的改变画面**（正向判据；纯负向判据会集体放过"什么都没做"的实现）——此后任何新引擎上线都必须配正向判据
- [2026-10-14] **设置页全局引擎开关 = 三档（方案 C）**：`-1` 跟随预设〔默认〕/ `0` 强制 filmic / `1` 强制 sigmoid，prefs `engine_override`；**只作用于拍照链路**（编辑器不参与 override）；**强制档覆盖预设的 engine_slot**（预设级入口保留 + 被覆盖提示）

## 期 B 域空间（10-19）
- [2026-10-19] **交付域保持 sRGB**（内部大盘子、输出小盘子）；PC 同构（AgX/Sigmoid/Filmic 跑 BT2020，输出 BT.709）
- [2026-10-19] **预设不重标**（沿用"预设先不动"）：本期只保证链路正确，观感变化留到"域完成后重估"

## 色相路线与 HDR（10-19）
- [2026-10-19] **ACES 与 Oklab L-only 都不做**（ΔE 恶化）；**HDR 路线定案 = 按 PC 做**（libultrahdr `packageJpegR`，4:4:4 + gainmap）

## HDR 交付（10-20）
- [2026-10-20] **三条 HDR 路径 + gainmap GPU 算**（`kFsGainmap` 1/2 分辨率 8bit）；开关 `-DFILMKIT_HDR`；真机验收通过（系统相册 + App 内 + SDR 导出）
- [2026-10-20] **"高光顶白"归因自动曝光策略，单独开期**（同场景 SDR base 亮度 85.2/98.4 vs PC 50.7、≥240 3.38%/2.22% vs 0.37%，HDR 输出几乎相同）

## 自动曝光（10-20 → 10-24 退役，压缩）
- [2026-10-20/24] **渲染端 AE 全链退役（用户拍板）**：`AeMetering`/`g_still_ae_ema` 在 0.12.71 全删 ⇒ 曝光 = HAL AE + planner + baseEv + 用户 EV，逐张独立；测光三档（系统/点测 6%/高光优先 PC 最亮簇）+ AF/AE 分离 + 长按锁定；**测光算法不许自创**

## 交付裁剪、删除与 ISZ（10-22 晚）
- [2026-10-22] **删除不做恢复（用户拍板）**：vivo 把 `createTrashRequest` 落成真删；不自建回收站，防误删靠闸门 + 删后核实
- [2026-10-22] **"保持原分辨率"不做**（PC 的纯插值且默认关；要真清晰只能多帧超分，另开一期）；**ISZ 标准版主摄不可达**（set 成功但 RAW 尺寸/crop 不变，`vsdofFeatureOpticalZoomSets=0`）
- [2026-10-22] **镜头表按等效焦距去重、物理相机优先**（逻辑相机让同焦段落到不同 id）

## 测光、AE 架构与 HDR（10-24）
- [2026-10-24] **DCP 生态不做，AdobeCurve 降 P2**（DCP 是相机原厂色彩身份；破坏 D8/D9 分工；不可分发）
- [2026-10-24] **HDR 曝光融合立项 → P3 架构对齐 PC RAW（定稿，取代 Mertens 直通）**：采集 0/0/+2.2/−1.5；**帧角色由采集端显式指定**（按实测 EV 推断是自创，暗场实锤）；全部进对齐+DFT 堆叠（frame_scale=2^−ev 归一）
- [2026-10-24] **侧帧 ISO 钳模拟增益顶 3200**（数字增益 = 假 EV）；**不自动退化**（用户否决）；**per-frame σ²=A·s·x′+B·(gr·s)²**（HDR+ "按实际合并更新噪声方差"）
- [2026-10-24] **不许为单个场景加采集规则**（长帧 +2EV 在阴天把长帧推到 41% 饱和）；**不引入跨张统计**（用户明确否决）

## HDR+ 包围曝光（10-24 晚，0.12.75-84，压缩）
- [2026-10-24] **P3 定稿上线**：4 帧原样进引擎、零新 shader；0.12.84 UI 两档化默认开；真机确认 hdrFs/confMed 0.833/brkRatio 2.83。P2 Mertens 直通退役（固定输入纹理/数字增益/自创判定/高光斑块四坑）

## P4 真实 gainmap 与徕卡一瞬（10-25/26）
- [2026-10-25] **gainTrue 中灰自锚定**：scene 锚 = ae_p50_、display 锚 = 0.1845；ratio clamp [1,4]（下限 1 = 暗部零放大，上限 4 = 元数据全量程）；A/B 档 + 预案 kHdrCeil（HDR 亮度 ≤2×SDR 白按 sdrY 收）
- [2026-10-25] **样片代表性**：旧样片对 gainmap 指纹有效、对 base 曝光账目无效（AE 删除 0.12.71 分界）——两类判据分开算
- [2026-10-25] **徕卡一瞬一期 = 现有引擎 + 烘焙 LUT**：PC 配方分支矩阵 → 64³ 纯色彩 display 域 LUT；**曲线不烘**（影调职责归 filmic latitude）；新引擎为备选；旧 leica_m9.lut 降级 A/B；判据双轨（配方逐位 + 样张指纹）
- [2026-10-25] **B 方案否决（用户拍板"不能为了预设改引擎"）**：M9 曲线不烘进 LUT、filmic 不退位；影调重标只能在现有参数族内做
- [2026-10-25] **单链拍照拟合取代双链 minimax**：成片质量优先 ⇒ 拍照链为主判据、编辑器链残差记账（declared 35.6）；双链 14.75 是互相拖累的假墙；**影调目标 = 暗部 M9（52→28.6/85→71.8）+ 中高段旧观感（157.9/191.3/219.5）**（真机 p50 +9.3 反馈后拍板）
- [2026-10-25] **LUT 满强度 1.0 保留**（一期验收浓郁度）；彩噪下一旋钮 = 强度 0.85~0.9；**sat_shadow 回 1.0**（暗部彩噪）；**发黄治本 = WB 锁定机制立项**：色温槽 `[88]` 是相对偏移、6500K=恒等点（不锁 WB）；AWB 逐张波动 ±5~15 是根源；预设侧无解
- [2026-10-25] **内置预设不带 engine_slot**（用户在 UI 自加引擎槽；强制档按设计覆盖预设）；**样张后缀 = LUT 标题**、真机验收必须带引擎槽位归因（diag tone=1.0 即 sigmoid 在跑）

## 边缘伪彩与开关（10-29）
- [2026-10-29] **锐化过冲限幅 ±0.4 → ±0.12**（`sharpenLuma`）：USM 在阶跃处亮侧提亮/暗侧压暗，±0.4 = 40% 过冲；显示域实测 13.5→8.4 LSB。这是"阴影渗水边"回到可接受的唯一已验证改动
- [2026-10-29] **D4 大半径 USM 默认关**（`[100]`）：离线能收窄亮缝（25→18px、对比 +33%、无暗环），但会整体变硬；用户判定"画面毁了"⇒ 只作实验开关
- [2026-10-29] **不改 tone curve 补对比**：RAW 亮缝 34px、我们 D4 26px、AHD 14px（AHD 是锐化伪影），补对比只能改 S 曲线 ⇒ 用户拒绝
- [2026-10-29] **开关化**：高光滚降 `[99]`（默认开）、高光重建 `[45]`（bracket 下不再隐藏）、D4 USM `[100]`（默认关）；kCount 99→101
