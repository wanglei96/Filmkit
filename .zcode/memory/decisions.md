## 平台、色彩与成像内核
- [2026-09-22] **饱和/外观类改动只能用"有边界"的手段**；**色度增强判据=亮度相对饱和**；**DNG 对照只定位缺口不当绝对标尺**
- [2026-09-24] **色彩基准**：先定为同机位 PC 成片 → **后改为"色准对标基准 = 实物本身"**（用户拍板），PC 降级为参照
- [2026-09-24] **方向链路三定案** — `orientationStep`=设备物理旋转步进（**绝不能喂 Display.getRotation()**，语义相反）；成片裁切跟设备姿态、与窗口解耦；相机页不转窗口（正解=GL 预览收设备旋转 + UI autoRotate）
- [2026-09-28] **项目大前提（用户拍板，写入 AGENTS.md）**：质量 > 成本/工期；严禁简化关键质量管线（论文一手 + 成熟开源实现逐行对照）；**性能取舍必须实测、不替用户决定**；**对标口径 = 标准做法，非 PC**
- [2026-09-28] **OETF 改真 sRGB**（`pow(c,1/2.2)` 不是 sRGB；kFsOut/kFsHist/measureSceneStats 三处同步）
- [2026-09-30] **出包前两件必做**：新增 GPU 路径必跑 `tools/check-diag-fields.py`；**同刻 100% 裁剪目视**（定量指标只作辅证）。判据必须先在已知正/负样本上验证；纹理保真必须覆盖 2–4px 细纹尺度且 σ 分解
- [2026-09-30] **P0 亚像素默认开**（用户拍板：+43.7%/+46.5%、细节无损失）；**两个杠杆必须一起看**；**D-2 收线**：颗粒 = 胶片感、是风格不是缺陷
- [2026-10-02] **曝光 ×N + ISO ÷N 纯赚 SNR**（收益 √N）；运动判据 = 1s 窗口矢量平均角速度；σ 恒为真实噪声；三摄噪声模型用 GCam 生态标定；NN 跨域微调判死（四次全过拟合）→ 转 HDR+
- [2026-10-03] **曝光目标 = "刚好不烧高光"，但用户优先噪声 ⇒ 默认曝光给足**（两者物理上不可兼得，高光交给影调层）
- [2026-10-03] **影调层固定、曝光层自适应**（darktable/AgX/ACES 标准做法；我们做反了才是设置爆炸的根源）
- [2026-10-03] **横拍方向与画幅必须快门瞬间快照**（MFNR 渲染 3~4s，凡"拍照时刻的状态"一律快照）；**超广畸变只能自校正**（HAL 无能力）
- [2026-10-03] **filmic HR · 品红 · 紫边**：`threshold` = 曝光前域白点（写死 1.0 致误重建）、opposed chrominance 置 0、inpaint 噪声 0；伪彩判据被样片否决 ⇒ 品红 = 逆光紫边渐晕。紫边两类分治（A 4px 窄峰 = 锐化放大器、B 逆光窗框）；**品红带 = B 缓 G 陡的错位带，RCD 类固有**；[56]/[57]/[58] 默认关存档
- [2026-10-13] **引擎切换对齐 PC**：引擎 = 1 pass、输出契约线性 sRGB（OETF 只做一次）、gamut 归引擎外观层归公共；参数面只加 `[98]`，阶段 0–1 判据 = 同帧 CRC32 逐字节等价。
- [2026-10-14] **引擎旁路与判据**：`[35]` auto_tone 必须旁路（`updateFilmicEV` 无条件调用 ⇒ 成片 `[0]`），`[28]` 旁路值 1.0；**新引擎必须配正向判据**；全局引擎开关三档（-1 跟随/0 filmic/1 sigmoid，只作用拍照链、强制档覆盖预设）。
- [2026-10-19] **交付域保持 sRGB**（内部大盘子、输出小盘子；PC 同构）；**预设不在本期重标**（"预设先不动"），观感留到域完成后重估
## 自动曝光、测光与 HDR 采集
- [2026-10-20/24] **渲染端 AE 全链退役（用户拍板）**：`AeMetering`/`g_still_ae_ema` 在 0.12.71 全删 ⇒ 曝光 = HAL AE + planner + baseEv + 用户 EV，逐张独立；测光三档（系统/点测 6%/高光优先 PC 最亮簇）+ AF/AE 分离 + 长按锁定；**测光算法不许自创**
- [2026-10-22] **删除不做恢复（用户拍板）**：vivo 把 `createTrashRequest` 落成真删；不自建回收站，防误删靠闸门 + 删后核实
- [2026-10-24] **HDR 曝光融合 P3**：采集 0/0/+2.2/−1.5，帧角色由采集端显式指定（按 EV 推断是自创）；侧帧 ISO 钳顶 3200 不自动退化；per-frame σ²=A·s·x′+B·(gr·s)²；不许为单场景加采集规则、不引入跨张统计。
- [2026-10-24] **P3 定稿上线**：4 帧原样进引擎、零新 shader；0.12.84 UI 两档化默认开；真机确认 hdrFs/confMed 0.833/brkRatio 2.83。P2 Mertens 直通退役（固定输入纹理/数字增益/自创判定/高光斑块四坑）
## LUT、预设与调色方法论
- [2026-10-25] **徕卡一瞬一期 = 现有引擎 + 烘焙 LUT**：PC 配方 → 64³ 纯色彩 display 域 LUT；**曲线不烘**（影调归 filmic latitude）；**B 方案否决**（不能为了预设改引擎）。
- [2026-10-25] **LUT 满强度保留**；**发黄治本 = WB 锁定机制立项**（`[88]` 是相对偏移、6500K 恒等；AWB 逐张 ±5~15 是根源）。
- [2026-10-25] **内置预设不带 engine_slot**；**样张后缀 = LUT 标题**、真机验收必须带引擎槽位归因。
- [2026-11-01] **管线开关不进预设**：预设只带风格（对比/曲线/分区饱和/色温/颗粒/暗角/LUT），开关唯一事实源 = 设置页；`setFilmParams` 换数组后全部 applier 缓存置哨兵。
- [2026-11-01] **饱和度听预设、删设置页饱和补偿**：`[20..22]` 不再有第二个写入者；三段饱和拆成三条独立滑杆（方案 B），复刻机内直出就把三条拉同值。
- [2026-11-01] **ESD3D2 默认替换档**（与 `FilmParams.h` 一致；两处 getInt 兜底写 2 是"说替换实跑叠加"）；未重标的预设不锁 engine_slot（只有徕卡一瞬锁）。
- [2026-11-01] **理光标定方法论**：无固件配方 ⇒ Positive↔Negative 配对测亮度传递 + 多张灰轴统计 + 配对色相 delta；不做无数据拟合。
- [2026-11-01] **需要"参数配方"的预设必须锁 filmic**：sigmoid 的 shader 只有 `sigmoidTone(out3)` + 7 个编译期常量 uniform，**没有任何从 FilmParams 读取的通道** ⇒ [4]/[5..10]/[37][38] 全被旁路，预设退化成"换个 LUT"。7 条里 5 条锁 filmic；理光负片/徕卡黑白缺省。
- [2026-11-01] **LUT 归一 = 只换 L\*、保留 a\*/b\***，超域点硬裁（缩 C 会把亮黄/青砍到 0.46~0.63）；只用于自带影调的 LUT（富士压白 8.2%），不用于 5219（2.7%）。
- [2026-11-01] **摄影师调色版只借指标、不搬色彩**（灰轴 a\* −2.4~−3.7 是签名，照搬白墙 a\* −4.1 发绿）。
- [2026-11-02] **压黑能压掉负片 base fog**（5219 最黑 4.7% 是蒙灰来源）；人工暗角不是原厂特征 ⇒ 去掉；颗粒按胶片物理（500T `grain 12/size 500`）；外部 AI 评价只采纳能对上位置的条目。
## 边缘伪彩、掩码与开关
- [2026-10-29] **锐化过冲限幅 ±0.4 → ±0.12**（`sharpenLuma`）：±0.4 = 40% 过冲，显示域 13.5→8.4 LSB；这是"阴影渗水边"唯一已验证的改动
- [2026-10-29] **D4 大半径 USM 默认关**（`[100]`）：离线能收窄亮缝（25→18px、对比 +33%、无暗环），但会整体变硬；用户判定"画面毁了"⇒ 只作实验开关
- [2026-10-29] **不改 tone curve 补对比**（用户拒绝）；开关化：高光滚降 `[99]` 开、高光重建 `[45]`、D4 USM `[100]` 关；kCount 99→101。
- [2026-10-30] **饱和判定回传感器域**（`raw >= ceil(black+(white−black)×0.98)`、逐相位整数、不含 WB/噪声）；短帧真值按 2×2 块整块接管，禁块内混帧（0.12.133 黄绿）。
## 显示域对齐、天空闭环与性能
- [2026-11-04] **显示域对齐用同一把尺，不用标量**：预览与成片都调 `robustMidToneDisplayRgba8`（截尾四分位 + 中心高斯 sigma 0.32，同 PC `MeteringSystem`）；成片 `passOutput` 后量中心 1/2、差多少补 `exposure_ev`。`g_domain_ratio` 降级为纯诊断。
- [2026-11-04] **闭环用两遍渲染 + 0.7 阻尼 + 最多两轮**：`tex_scene_` 与曝光无关 ⇒ 只重跑 filmic+output；实测闭环增益 1.0~1.76（`ev_shift` 联动），全量步进会过冲。
- [2026-11-04] **蓝天目标必须用晴天样片**：官方晴天深蓝天 h 270.9 / C\* 17.8；阴天街景 h 258 / C\* 13.1 只能代表阴天。
- [2026-11-04] **LUT 里不做「只作用于某段亮度」的补偿**：display 域 3D LUT 是连续渐变的查表，任何随 L 开窗的补偿都会在窗边留下一圈色相凹陷（0.12.241 的白块）。要压某段的色相，只能在 filmic 的场景线性域做。
- [2026-11-04] **方案选择纪律（写入 AGENTS.md）**：只选最佳质量方案；禁止半成品（统计端做了消费端没接）；对标实现读完再动手；不许拿历史注释当豁免。
- [2026-11-11] **LUT 可以携带影调 + 采集端判据必须当帧**（推翻 11-01「只做色彩」）：归一成灰阶恒等 = 发灰 + 天空偏紫；同一张片子影调只能有一套主曲线，LUT 带影调时 filmic 目标曲线要重标。采集端判据跨张/全局硬压均被否决，HDR+ 包围下高光保护同样生效。
- [2026-11-12] **闭环只允许"当帧补 EV + 天空护栏"**：每步测顶部天空 P99，涨 >0.03 或 >0.88 撤销；宁留 `dispErr` 也不推白；禁止跨张/跨场景复用。**Spektrafilm 是引擎（slot=2，场景线性输入）**，不是 display 域 LUT，不做同场景 A/B。
- [2026-11-12] **RCD 方向场不改**（性能专项结论）：0.13.5 冷机实测 P1 净耗时只有 65–85ms（GPU 48–66ms），旧的 1202–1433ms 是「HR+P0+P1」合计（`d0` 打在 HR/P0 之前的口径错）。**热点排序 = DFT 1.2–1.5s / P0 300–352ms / P4 542–1131ms / 编码 189–290ms**。编码已换 libjpeg-turbo（用户授权；4:4:4 q100 色度误差 p99 stb 1.36 → 1.58/255，4:2:0 是 9.77，安全区内换 2.5× 速度，复用构建里已有的 `jpeg-static`）。不移植 PC 的 Sabre/MGC（逆向 GCam 专有二进制、许可不明、与 4 帧 DFT 融合强耦合）；将来若再碰方向场，前提是 `rcd_dir_half` 开关 + RT 结构（1/2 分辨率 + `lpf` 输入）+ `rcd-linecompare` 对 AMaZE 离线判据。
- [2026-11-12] **融合默认切空间域（`mfnr_dft=false`）**：两场景 A/B 快 1.8~2.8s、暗部 σ 2.08→1.71、100% 裁剪无可见差；DFT 保留为设置页开关。
- [2026-11-12] **不写新融合（T3 收尾）**：运动模拟 1~30px 位移下，现有 32px mismatch 权重与逐像素 rejection 差 0~1.7 LSB（肉眼不可见）；将来见运动拖影先做 mismatch 权重 guided upsample。**P0 不加 fence 窗口**（p0Ms 326→547，纯同步往返）；burst_dump 保留（默认关、哨兵控制）。
- [2026-11-13] **条带化只能用 `glScissor`**：全屏三角形 UV 按 NDC 插值，缩 `glViewport` 会让每条带重复整幅图（0.13.18 事故，预览"重复 N 次"）。
- [2026-11-13] **still 引擎按生命周期保活**（相机页可见+亮屏；不可见/熄屏释放），不再定时释放：显存驻留不耗电，重建 init 135~265ms + 2.4GB 分配才耗电且卡。
- [2026-11-13] **fence 窗口（在飞 2）与时间片让路不采用**：真机实测 fps 零收益，时间片纯亏 231ms；掉帧不是队列深度问题。
- [2026-11-13] **快门定格到动画结束即恢复**（不等合成），处理期掉帧换体感；相机页请求 120Hz（窗口默认 60 会锁死 Compose 动画帧率）。
- [2026-11-13] **gainmap = 标准乘性比值**（`y_hdr/y_sdr`，clamp `[1, hdr_white/sdr_white]`，对照 libultrahdr `gainmapmath.cpp:775`）：规范里没有"中灰以下 ratio 恒 1"、也没有白点门限；0.12.230 的加性写法是自创，实测把灯盘 63% 像素留在 ratio=1。
- [2026-11-13] **欠曝不设硬上限**：相机工程的做法是"判据带面积权重"，不是钳 EV；1EV 硬限会砍掉大面积高光（逆光/白墙）的合法欠曝。总提亮 2EV 保留为兜底。
- [2026-11-13] **相册/大图 = 覆盖层，相机页常驻**：整页替换会销毁 SurfaceView，返回要重建 EGL + openCamera + session（1~2s 黑屏）。
- [2026-11-13] **跨页动画用单层淡入，不用 Crossfade**：两层不透明全屏页共存时中间帧会混合，观感是整屏闪一次。
## 预设覆盖层、相册与 HDR 语义
- [2026-11-14] **硬编码的「标准」预设也必须走进覆盖层**：它是 `CameraPresetApply.kt` 的出厂对象、不在 `builtin.json`，`applyBuiltinOverrides` 只认出厂列表里的 id ⇒ 修改永远匹配不上。拍照页改走 `BuiltinPresets.forCamera()`（标准 + 用户 + 内置全过覆盖层），`resolveCameraPreset` 先查列表再回落硬编码（`savedId` 为空时**也要查**：选中标准会删 `camera_preset_id`）。
- [2026-11-14] **删除后留在查看页切下一张**：只摘掉被删下标（`currentPage` 原地显示原下一张，零滚动），删最后一张夹到前一张，删空才退出。同页换图 ≠ 翻页：翻页必须丢旧像素，删除换图保留旧图当淡出底（`shownPage == page` 判据）。
- [2026-11-14] **gainmap = 纯比值 + LUT 补偿，没有任何 anchor**：对照 `bjzhou/PhotonCamera` 的 `HdrBufferEncoding.LINEAR_SRGB` 参考 + `RawGainmapMath.encodeLuminance`：`ratio=(hdrLuma+ε)/(sdrLuma+ε)`、`targetHdrLuma=(hdrLuma+ε)·lutGain−ε`、`[0.25,4]`、offset 1e-4。中灰 ratio≡1 是同域比值的自然结果；`film_src` 本来就在显示域，**不需要任何域换算系数**。
- [2026-11-14] **defringe 判据用 `min(R−G, B−G)`**：紫（B>R>G）与品红（R>B>G）的共性是 R、B 都高于 G；单看 `B−R` 会把品红整个排除。零误伤仍靠邻域色差标准差 + 亮度梯度两道闸。
- [2026-11-14] **HDR 高光用短帧，不用 HL 重建值**：`film_src` 的 8~9 含高光重建（偏高），短帧归一后 6.1 才是物理值，用户拍板"真实该多亮就多亮"。
- [2026-11-14] **短帧必须乘 `frame_scale[short_idx]`**：−1.5EV 短帧 ×2.82 才回到 frame 0 曝光域；乘在已融合 scene 上是二次曝光（0.13.71 的 `gmMax=1.00` 就是这么来的）。
- [2026-11-14] **HDR 延伸不能写在 `kFsFilm` 里**：`tex_work_` 同时是 SDR 成片源，任何 >1 改动都会被 `kFsOut` 的 `min(c,1)` 变成硬截断（0.13.66 的 SDR 横向波纹）。
- [2026-11-14] **不再用更大采样核 / 邻域最大救灰带**：kK=12 平均（0.13.68）、12×12 最大（0.13.76）都只换灰带形状。
- [2026-11-15] **禁止跨 CFA 相位的标量亮度 inpaint**：短帧各相位 `v/gain[c]` 仍是不同光谱响应；"平均再乘回 `gain[c]`"必然污染色比。PC/Bento 只做整帧接受 + 相位保真融合。`kHlInpaintOn=false` 已从生产链移除，代码保留作诊断 A/B。
- [2026-11-15] **`hr_raw` 开关 ≠ 高光链关闭**：`hr_on` 只控 `passHighlightRaw`，inpaint 独立执行且 P0 直接消费 `fused_src`；`hlOk=0, hlInp=1` 是合法组合，不能用来排除 inpaint。判定只认 `hlInp`。
- [2026-11-15] **成像关键链禁用 ponytail**：RAW/融合/高光重建/去马赛克/色彩科学一律"先读完一手参考再完整实现"；ponytail 只用于 UI/工具/构建类任务。HDR 融合链历史上的 `ponytail:` 临时形态授权（per-pixel Mertens）正是本类风险的来源。
## 高光融合与出片契约
- [2026-11-15] **CameraWhite 只在去马赛克后的完整 RGB 域施加**（undo LSC→白界→redo LSC，CA/CCM 之前）：它是 PC 的 source-neutral 输出白上界政策，不是满阱检测；放在 Bayer 相位内会跨 CFA 非线性截顶且与去马赛克不可交换。代价（压掉超源白界的真实颜色）必须如实记录，不称无损。
- [2026-11-15] **UNKNOWN ≠ 静止**：clipped reference + valid short 是兼容观测；可观测配对不足时普通时域保守退出，selected short 由准入 M 独立接管。禁止把 UNKNOWN 经 ISO fade/中值重新放行。
