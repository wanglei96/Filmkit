# 天空白块归因与0.13.0

## Summary

理光天空白块从"LUT 影调"一路归因到**显示域闭环把成片补亮 0.6EV**；闭环改为"当帧补 EV + 天空 P99 护栏"后天空不再顶白。顺带实测出 vivo 预览被 ISP tonemap **4.59×（+2.2EV）**，PC 的"YUV 即场景线性"假设在 X300 上不成立。发版 0.13.0(708)。

## Done

- **LUT 定名**：`ricoh_negative_ye.lut` 内部标题改为「理光负片」，去掉作者名；UI 的 LUT 名取自该字段；id 保持 `ricoh_negative_ye`（只做持久化键、不显示，改名会让已存 `lut_id` 失效）。单测通过，`3447742`。
- **诊断包（0.12.252）**：成片链加 `skyD4`/`skyFm`/`skyOut` 三段天空剖面（顶部 20%、`b>=r` 判据、每 8 行 × 8 像素采样）+ `pvLastMid`/`stillMid`（0.12.257，当帧预览 vs 成片的 filmic 输入中位）。
- **归因链（真机 11-12 08:57/09:19）**：D4 天空 p50 0.4375（相对中灰 +1.28EV，LSC 校正后的物理亮度）→ 基础曝光 0.698 → **闭环 `dispAdd` 一轮补满 0.60**（首轮读数成片中灰 0.084 vs 预览 0.152，差 0.86EV）→ filmic 白点 3.74 → 天空 8bit 230+/L* 90。
- **闭环修复（0.12.253→256）**：上限 0.60→0.15（253）→ 改喂域比（254，否决）→ 全步一次对齐（255，否决）→ **当帧补 EV + 天空护栏**（256：每补一步测成片顶部天空 P99，涨幅 >0.03 或绝对值 >0.88 就撤销该步）。
- **实测结果**：09:19 两张天空 L* 90.5→75.2、C* 6.2→13.3；逆光场景 `dispAdd` 停在 0~0.3，天空不再被推过 0.88。
- **预览域比实测（0.12.257）**：`pvLastMid 0.1267 / stillMid 0.0276 = 4.59` ⇒ vivo 的 YUV 去 gamma 后仍被 ISP 提亮 **+2.2EV**。PC 的 `RawPreviewRestoration.SceneLinearSrgb`（单位阵还原）在 X300 上不成立。
- **诊断开关（0.12.258）**：设置 → 实验与诊断 →「天空 / 亮度剖面诊断」，**默认关**；关 = 成片链零额外读回（原先每张 ~200 次逐行 `glReadPixels`、100~200ms）。闭环护栏的 `skyP99` 不受开关管（功能读数）。
- **关于页**：加「版本 x.y.z」，读 `BuildConfig.VERSION_NAME`。
- **调研**：Spektrafilm（光谱胶片模拟，GPLv3 代码 + CC BY-SA profiles，20 stock + 相纸）；PC 预览 = 引擎 + 65³ LUT 缓存、单次渲染无补 EV；AI 构图（TFLite 已就绪，P0 规则+检测可行，VLM 不现实）。

## Decisions

- [2026-11-12] **闭环不用跨张状态**：域比/中灰校准一律"当帧"，不同场景不复用上一张的值（用户指出：换场景后上一张的比值是别的场景的量）。
- [2026-11-12] **闭环补 EV 必须带高光护栏**：补一步测天空 P99，涨 >0.03 或 >0.88 就撤销该步并停手；成片宁留 `dispErr` 也不推白。
- [2026-11-12] **预览与成片的差先接受**（09:19 那张 1.25EV），不再为它牺牲高光。
- [2026-11-12] **Spektrafilm 定位是引擎（slot=2），不是 display 域 LUT**：H&D 曲线是"场景曝光→密度"的映射，挂在 `kFsOut` 会丢失语义；PC 的 65³ LUT 是引擎实现手段（光谱 CPU 太慢），输入仍是场景线性。与理光/徕卡并列，不做同场景 A/B（不同产品线）。
- [2026-11-12] **重读回诊断默认关**：只作排查开关，默认零开销。

## Pitfalls

- [2026-11-12] **"拍 4 张收敛"是设计错误**（用户批评）：校准是设备的事，不是用户的事；一次拍摄必须对齐，做不到就接受差异。
- [2026-11-12] **PC 的成片比预览亮**（用户纠正，我此前判断反了）：PC 不追求 WYSIWYG，它没有域比也没有事后补 EV。
- [2026-11-12] **标量域比只影响预览、不影响成片**：成片是 RAW，域比是"厂家 tonemap 增益"的估计，跨场景会失真（实测 2.0→4.59 波动）。
- [2026-11-12] **`skyOut` 掩码在 sRGB 域会筛错**：成片天空 `b>=r` 常不成立，`n` 只有 D4/Fm 的一半；判断天空只用 `skyD4`/`skyFm`。
- [2026-11-12] **contrast 对接近白点的天空几乎无效**（复算 s=0.972：contrast 1.23→0.9 只压 6 LSB）；白点提高则是整体变暗。压"接近白点"的天空只能靠曲线形变/teq，teq 的高光压深在 0.12.198 被关了。
