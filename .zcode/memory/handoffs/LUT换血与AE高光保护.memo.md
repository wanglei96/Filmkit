# LUT换血与AE高光保护

## Summary

理光天空白块的归因跑了五个方向（filmic 白点 / gainmap 折点 / 显示域闭环 / AE 高光保护 / LUT），
最终落在 LUT：此前的「只做色彩」归一削掉了原厂影调。AE 高光保护同时从"恒假"修成真正生效。

## Done

- **白块归因（排除 LUT 前的对照）**：LUT strength=0 的同机位样片天空同样 48.2% 像素 G≥240、
  单值 245 占 17.5% ⇒ 白块与 LUT 无关（那一层）；根因是 filmic 白点被 probe 闸钉在 2.94 EV，
  低于场景最亮 2.99 ⇒ 整片天空压进最后 15 级 8bit（离线复算：白点 2.94→27% 平台，3.39→0%）。
- **白点 probe 闸（0.12.243）**：`w99` 贴在 RAW 白点（≥2.40）时按 darktable autodetect 的
  max 语义放开到 `w_max+0.4`，不再被 `w99+probe` 收紧。孤立高光场景（红杯 w99=1.03）不变。
- **gainmap 折点（0.12.244）**：`max(0, hdrLin−1/anchor)` 换成斜率连续的 smoothstep 过渡
  （kSoft=0.12）。真机解出 gainmap 实测 boost 场「恒 1.00 → 跨过某条斜线变 1.10~1.35 → 又回
  1.00」，边界正是 `hdrLin==0.39` 的等值线；中灰/高光两端逐位不变。
- **显示域闭环上限（0.12.245）**：累计补偿钳 ±0.60 EV。实测理光 `dispAdd 1.24` 把天空从
  C\* 17 推进 L\* 95-100 / C\* 2.1（纯白块）；闭环补到 1 EV 以上说明链路有系统偏差，
  不该用高光去填。
- **AE 高光保护（0.12.248）**：`hlOn = hl_protect && !aeAutoOn && !bracketPref && hdrFusion<=0`
  在出厂配置下**恒假**（ae_auto 默认 true、hdr_fusion 默认 1）⇒ 这层从来没跑过。去掉两个
  旁路（渲染端 AE 已删、短帧救不了 +2.4EV 天空），并新增 `pw999`（当帧预览 P99.9 ÷ 域比
  回 RAW 等效域）作为判据，不再用上一张成片的 sw999。
- **预设三饱和**：徕卡 1.22→0.95（天空 C\* 38 对 M9 样张 C\*P90 29）；理光 0.92/0.90/0.80→
  1.12/1.08/0.85（全图 C\* 3.1 对官方 6.2，缺的是暗部/中调灰轴）。
- **LUT 换血（0.12.251）**：`ricoh_negative_v2`（归一过、灰阶恒等）换成 `ricoh_negative_ye`
  （LUMIX Lab 导出「理光负片 杨子祯」33³，逐字节复制）。灰阶 0.25→0.31 / 0.50→0.57 自带
  提中调——这正是被归一削掉的负片味道。
- **分支**：改动全部落在 `dev`（`31638b8`），已推 `origin/dev`。包 0.12.251(700)。

## Decisions

- [2026-11-11] **LUT 可以携带影调**（推翻 2026-11-01 的「LUT 只做色彩不做影调」）：
  LUT 是 display 域 3D 查表，自带影调是原厂味道的一部分；归一成灰阶恒等会让画面发灰、
  天空偏紫（同场景天空 hue：归一版 276.2 / Filmix 263.2 / 杨子祯 cube 260.8）。
- [2026-11-11] **采集端曝光不许跨张**：相机不会拿上一张的统计决定这一张。高光判据必须来自
  当帧（预览 P99.9 经域比换算，或 RAW 当帧统计）。
- [2026-11-11] **不许用全局压 EV 修局部问题**（用户否决）：它波及暗部、噪声与所有题材。
- [2026-11-11] **AE 高光保护在 HDR+ 包围下也必须生效**：HDR+ §4 要求主曝光本身"刚好不烧
  高光"，短帧只补细节；`-1.5EV` 的短帧救不了 `+2.4EV` 的天空。

## Pitfalls

- [2026-11-11] **归一 LUT 的代价是隐形的**：灰阶恒等看起来"分层干净"，实际削掉了原厂曲线，
  表现是"发灰 + 天空偏紫"而不是"少一点味道"。判据不能只看"L 是否恒等"，要看整张的观感。
- [2026-11-11] **预览统计不能当 RAW 高光判据**：预览是厂家 ISP tonemap 过的，RAW 等效
  P99.9（预览 1.03）比成片（2.91）低 **1.88EV** ⇒ `hlEv` 太小、保护不触发。两条链的统计
  不通用（用户在 11-11 当面指出"预览是厂家 YUV、成片是我们的 RAW"）。
- [2026-11-11] **filmic 白点 probe 闸会造 8bit 平台**：P99 撞 RAW 白点时 `w99+0.5` 常数比
  场景最亮还低，整片天空进最后 15 级 —— 表现为"有边界的白块"。
- [2026-11-11] **gainmap 的 `max(0,·)` 折点会在天空留硬边**：C0 连续但一阶导突变，8bit
  量化把它固化成可见边（boost 1.26 vs 周围 1.00）。
- [2026-11-11] **调参前先量同场景**：跨场景比较 p50/p99 会得出相反结论（本轮先误判"我们
  中灰更暗"，实际是构图差异）。
