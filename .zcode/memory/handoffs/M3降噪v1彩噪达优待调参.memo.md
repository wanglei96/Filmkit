# M3降噪v1彩噪达优待调参

## Summary

本窗口完成 M3-2 降噪 v1 全流程（v0.5.32-m3）：噪声基线量化（彩噪为主攻短板）→ P0 RAW 域同色 bilateral + P4 色度平滑两段实现 → 真机 A/B 验证：彩噪 1.41→0.74（-48%，达"优"档 ✅ 目标达成）、亮噪 -56%，但细节 Laplacian -48% 过猛（用户观感"清晰度下降"）→ 下一步调参收敛。另按用户要求建 handoff/ 交接文件夹（本地维护，不上 git）。

## Done

- 噪声基线量化（652/640，ISO~1200，平坦块法）：亮噪 σ(Y) 1.5–1.8 达标"优"；彩噪 1.78（RCD）/2.13（bilinear）未达优（目标 ≤1.0），B-Y 分量最重（与蓝通道 WB 增益 1.65 相关）——彩噪定 M3-2 主攻；RCD 亮噪高 18% 是细节保留代价（bilinear 假平滑），彩噪低 16% 是色差域插值优势
- v0.5.32-m3 降噪 v1（两 pass，仅 RCD 质量档生效，bilinear 保持纯净基线）：**P0** RAW 域同色联合 bilateral——任意 Bayer 相位下"步长 2 的 3×3 网格"恰为 9 同色位（无需相位判断），值域 σr=ns·1.6·√(0.2+4v)（shot noise 随信号 √ 增长），输出线性 mosaic `tex_mos_` 供 P1–P3 经 uMosaic 开关读取（顺带免整型解码/WB 重算）；**P4** 色度平滑——CCM 后场景线性域色差联合 bilateral，Y 原样保留（亮度细节零损失），输出 `tex_dn_` 接胶片链
- noise σ 自适应：SENSOR_NOISE_PROFILE 按当前感度取最近增益条目（/whiteLevel 归一化）；**X300 不回填**（raw.meta noise=0 证实），引擎回退 0.030；prefs noise_reduction 默认开（设置页「RAW 降噪」行）；raw.render 加 dn/ns/dnMs；shader 校验 11→13 条
- 真机验证（932 开/939 关/946 快速，ISO~570 同链路对照）：**彩噪 1.41→0.74（-48%，达优 ✅）**、亮噪 1.56→0.68（-56%）；**细节 Laplacian 5.18→2.71（-48% 过猛）**——用户观感"降噪明显但清晰度下降"
- 性能：降噪开 640ms vs 关 676ms（dnMs 38.5，P0 mosaic float 让 P1 提速抵消自身开销）；dirMs 波动大（70 vs 264，疑似降频）需多测
- handoff/ 交接文件夹：README（面向新 agent 自包含）+ 6 份快照拷贝；按要求移出 git（gitignore，本地维护），README 已更新至降噪 v1 状态

## Decisions

- [2026-09-21] **降噪只接 RCD 质量档**——bilinear 保持纯净基线（A/B 对照不污染），速度档无降噪
- [2026-09-21] **降噪两段式**：P0 RAW 域压源头（同色 bilateral）+ P4 色度域压彩噪（Y 零损失）——不学 bilinear 式钝化，保 RCD 细节优势
- [2026-09-21] **noiseProfile 回退策略**：HAL 不回填时 ns=0.030（归一化域），raw.meta 记录实测值供核对
- [2026-09-21] **handoff/ 交接文件夹不上 git**（用户要求）：gitignore + 本地维护，README 按"接手 agent 视角"自包含撰写，等用户指令更新
- [2026-09-21] 噪声测量口径：平坦块法（8×8 块、梯度阈值 3.5、均值>40 过滤）——全图去均值残差混入纹理会高估 3–4 倍

## Pitfalls

- [2026-09-21] **降噪强度过猛的量化特征**：细节 Laplacian 降幅 ≈ 降噪幅度（-48%/-48%）= σr/σc 值域权重太松；调参方向 P0 系数 1.6→~1.1、P4 sc 2.4→~1.8 + Y 值域收紧（sc*2.0→~1.2），或 标准/强 两档
- [2026-09-21] SENSOR_NOISE_PROFILE 泛型经 JNI 擦除（元素为平台类型 Pair），Kotlin 需 `as? List<Any?>` + `android.util.Pair<*, *>` 防御性解包，不能直接声明泛型
- [2026-09-21] X300 不回填 SENSOR_NOISE_PROFILE（noise=0 证实）——noiseProfile 自适应降噪必须设计回退估计
- [2026-09-21] 同链路 A/B（开/关）才是降噪评估的干净对照；跨版本/跨场景绝对值不可直接比（ISO/场景混杂）
- [2026-09-21] 自定义 shader 加 sampler 时注意纹理单元重排（P2 dir 1→2、P3 dir/g 1,2→2,3 给 mos 让位），漏绑会静默采错
