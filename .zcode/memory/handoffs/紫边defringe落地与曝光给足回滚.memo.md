# 紫边defringe落地与曝光给足回滚

## Summary

品红定性修正为**逆光边缘紫边渐晕**（上窗口"伪彩感知判据"被真实样片数据否决，14.74%
基准系测量口径污染）；defringe（RawTherapee 同形态）v0.10.134 落地；真机解剖发现用户
所见主体是**低频色度噪声云**（根因 4.8ms 短曝光），方案 A"曝光给足"落地 v0.10.135
当日真机灾难（成片与 DNG 全毁）已紧急回滚，v0.10.136 = 134 行为 + defringe 保留。

## Done

- **离线验证否决上窗口方案**："色度高、亮度平坦"判据反了——品红像素亮度带通是全图
  均值 14 倍；品红 56~66% 贴物体轮廓、平坦区孤立点仅 2~3% ⇒ 定性 = 逆光边缘紫边
- **口径修正**：含负值量转 uint8 回绕产生假边缘，14.74% → 0.65~0.78%（紫边口径），
  三对基准样片（154402/153833/153337，用户恢复）一致
- **defringe 落地（v0.10.134，c5133d9）**：4 pass 半分辨率（down+Lab+a 门 / 11×11
  检测 / 16×16 均值读回 chromave / 全分辨率替换），RT PF_correct_RT 机制复现
  （GPL 不抄码）；离线紫边 ↓63%、红物体 +1%、σ_HP −28%；prefs `defringe` 默认开、
  FilmParams[47]、日志 `df`/`dfCavg`
- **真机解剖（112025 对）**：1px 色度噪点 10.5%→**0.04%**（融合+P0/P4/D-1 有效）；
  用户所见主体 = **>32px 低频色度噪声云**（P90 3 级、品红绿成对、中亮区集中），
  defringe 对低频云结构性无效；根因 = 4.8ms 短曝光（ISO 50 下限锁死 Planner 拉长）
- **方案 A 落地即真机灾难（v0.10.135，511ad73）**：100ms（×10）→ RAW 饱和 4.2%
  （R 通道 24.3 万像素）→ 高光重建品红洪水（hlCnt 50.8 万、hlSum R +11 万）+
  白点失控（hrWhiteEv 8.52、pHi 5.1）→ **成片与 DNG 全毁**
- **紧急回滚**：revert 52870f4，v0.10.136（3c6da7c）= 0.10.134 行为 + defringe 保留

## Decisions

- [2026-10-04] 品红定性修正 = 逆光边缘紫边渐晕；上窗口"伪彩感知色度降噪"方案否决
- [2026-10-04] defringe 保留（对 2-16px 渐晕有效；低频云不归它管）
- [2026-10-04] 方案 A（曝光给足）拍板当日即真机否决：无高光饱和预算的给足 = 毁图；
  "高光交给影调层"仅适用小幅给足（×2~3）；后继任何给足必须有饱和预算约束，待重新拍板
- [2026-10-04] 修正方向三选一待拍板：有界给足（饱和预算反馈）/ D-1 低频扩展 / 暂缓

## Pitfalls

- **含负值量（R-G/B-G/差值）直接转 uint8 进 PIL 模糊 = 回绕假边缘**，占比虚增 12×+
  （本窗口踩三次：recon/hl_check/jpeg_check）；规程：色度分析一律逐通道模糊或 offset
  法，新口径先验量级合理性
- **曝光给足无高光饱和预算**：target 333ms（暗夜语义）+ 砍 hl 上限，大光比场景 =
  RAW 饱和 4.2% + HR 品红洪水 + 白点失控；全局曝光行为改动必须先离线复现真实样片全链
- 判据类方案定案前必须在真实样片跑正/负样本区分度；ROI 定位错 700px 产生"全 0"假象；
  跨图对比先验证构图（seq1 台灯 vs seq2 窗，差点误判对照有效）
- CIELAB = 线性→XYZ（无 sRGB 编码环节，编码步骤放错域全盘错）；rawpy
  gamma=(1,1,1)+16bit 断言不可用（用 gamma 解码近似线性域）
