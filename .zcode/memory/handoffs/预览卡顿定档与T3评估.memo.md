# 预览卡顿定档与T3评估

## Summary

卡顿专项收尾：PC 的 strip 不是「条带 + glFlush」，而是 **LOW 优先级 EGL context + 线程降级 + fence 窗口**；补齐后用户确认预览「好很多」。DFT 按 tile 行拆块 + 在飞限 2，把单 job 从 ~300ms 压到 ~150ms。T3 评估结论：**默认切回空间域（mismatch + fuse）**——两场景 A/B 快 1.8~2.8s、暗部 σ 更低、100% 裁剪无可见差；写新融合的模拟收益 <2 LSB，不做。

## Done

- **0.13.10 卡顿**：still EGL context 以 `EGL_IMG_context_priority` LOW 创建（真机 `eglPriExt=1, eglLow=1`，X300 Mali 支持）；still 线程降 BACKGROUND；DFT 4 次 dispatch 按 tile 行拆 2 块并在飞限 2；P0 条带保留但**去掉 fence**（实测 p0Ms 326→547，16 次同步往返白吃 220ms）。
- **0.13.11 性能**：DFT compute program 惰性缓存（消除冷启动 779ms 尖峰）；对齐金字塔读回改 `GL_RED`（1/2 域 12.5MB→3.1MB，不被支持时回退 RGBA）；still 线程优先级回默认（GPU 段已由 LOW context 让路，CPU 段不该再被抢）。
- **0.13.14 取证**：`copyRaw` 里按哨兵 `files/burst_dump` 导出 4 帧 `.raw + .meta`（帧 1-3 在 processRawBurst 前已 close，只能在此存 buffer）。
- **0.13.15 A/B 开关**：`files/mfnr_spatial` 哨兵 → 强制走空间域（release 包不可 run-as，文件哨兵是唯一无 UI 的切换手段）。
- **0.13.16 默认切换**：`mfnr_dft` 默认 false（空间域），DFT 保留设置页开关；设置页文案同步。
- **真机 A/B 两场景**：明亮 ISO 1163：DFT 6033ms → 空间域 4233ms（−1.8s），暗部 σ 0.88/0.89、高频 −5%；暗光 ISO 662：DFT 8000ms → 空间域 5240ms（−2.76s），暗部 σ **2.08 → 1.71**、高频 −18%，100% 裁剪目视无差。
- **离线证据**：真实 burst（hdrFs 1/1/0.73/2.82 归一化后）跑 DFT 镜像 vs 4×3×3 空间域；合成运动模拟（1/2/4/30px 位移）两条权重路径运动块内差异 0~1.7 LSB，朴素平均 25~278 LSB。
- **调研报告**：`docs/reports/oss-raw-fusion-speed-RESEARCH.md`（开源多帧 RAW 融合全在 CPU，除 PC 无 GPU 实现）、`pc-still-perf-RESEARCH.md`（PC 空域融合/降域/零 readback）。

## Decisions

- [2026-11-12] **默认空间域（`mfnr_dft=false`）**：0.13.15 两场景 A/B 快 1.8~2.8s、暗部噪声更低、无可见细节差；DFT 保留为开关，随时可切。
- [2026-11-12] **不写新融合**：运动模拟显示现有 mismatch 32px 权重 + 64px 膨胀与逐像素 rejection 的差异 0~1.7 LSB（肉眼不可见）；写完整 rejection 要 1~2 周且带新伪影风险。将来若见运动拖影，先做「mismatch 权重 guided upsample」，比新融合便宜一个量级。
- [2026-11-12] **P0 不加 fence 窗口**：P0 整段 300ms、每带 40ms，job 已够碎；fence 只增加同步往返。
- [2026-11-12] **burst_dump 保留**：默认关、哨兵控制、拍照路径只多一次 `File.exists`，T3/融合验证还要用。

## Pitfalls

- [2026-11-12] **⛔ 绝不能用 `pm clear` 清数据**：为绕过 prefs 缓存清了 app 数据，把用户的 M 档/RAW/预设/导入 LUT 全清掉（用户严厉批评）。release 包不能 run-as 时应**让用户点开关**或**加文件哨兵**，不能动用户数据。LUT 原件在 `Download/光子相机/luts/` 可重导。
- [2026-11-12] **真实 burst 是 HDR bracket**：`hdrFs=[1,1,0.73,2.82]`，直接 A/B 会把曝光差当噪声；离线必须先按 hdrFs 归一化。
- [2026-11-12] **离线 σ 指标在明亮场景失效**：帧差仅 3 LSB、纹理 σ 80，σ 被纹理主导；测降噪必须选暗部低梯度块或直接用帧差。
- [2026-11-12] **DFT 拆块有 GPU 代价**：dftGpu 562→951~988ms（job 边界开销），换来预览插队粒度 300→150ms，是卡顿的必要成本。
- [2026-11-12] **热态会造出 2~3s 假差异**：Thermal 2 时 totalMs 7~8s，Thermal 0 冷机 5594ms（与 0.13.9 的 5162 同量级）——性能结论必须冷机取。

## Next

1. **0.13.16 已装、用户已自行恢复配置**；下一步按需挑性能项：P4 链路（`pc3dMs` 600~620ms）、暗光噪声。
2. Spektrafilm 引擎（slot=2）仍待做，优先级在性能之后。
3. T3 只在真实样片出现运动拖影时再做 guided upsample，不主动开新融合。
