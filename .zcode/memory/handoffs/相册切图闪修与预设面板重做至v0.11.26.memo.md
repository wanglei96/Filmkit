# 相册切图闪修与预设面板重做至v0.11.26

## Summary

v0.11.15 后连续六轮真机反馈驱动的收尾：相册侧修完"切图闪一下"（根因是转圈/上一张图闪现，非画质）并把缩放改为两指中心锚点；预设侧从"只读清单+整包更新"重做到"横向预设条 + 一级页只给常用参数 + 完整参数二级页 + 返回键分层"，最后修掉内置预设白点 2.5~2.7 造成的高光死白（`[38]` → 4.0 + 死白约束下重跑拟合）。发布至 **v0.11.26**（versionCode 375）。

## Done

- **相册 PV-2（`3c29d9e`）**：用户"左右滑动一定会显示一下转圈"。根因 = `bitmap` 被两个独立协程分别写（切页 effect 写 null、解码 effect 写新值）⇒ 中间渲染出转圈帧；配套两个真缺陷（被动预载未命中是常态；`viewSize==0` 时 `previewRequestFor` 退化成 (1,1) 解出 1×1 垃圾写进缓存后 `bmp != null` 永久早退）。修法四条：原子替换（`frameAfterPageChange`）、主动预载 page±2、alpha 收进与 zoom/pan 同一道闸（`pageAlphaAt`）、转圈延迟 150ms。
- **相册 PV-3（`86e991f`）**：用户"上一张图还是会闪现"。根因 = `Image` 参数在**组合期**取值，而 effect 重启必然晚于"重组第一次读到新 page" ⇒ 必然存在一帧"新页已选中 + 位图仍是旧页的"（与调度顺序无关，PV-2 只消掉 null 留下旧值）。修法 = 绘制期校验归属（`bitmapBelongsToPage` / `visibleBitmapFor`），归属不符画**该页自己的预载档**而非旧像素。架构师补 M3 源码哨兵（判据存在但调用点绕开 ⇒ 单测盖不到）。
- **相册 PV-4（`7fa2eba`）**：缩放改为两指中心锚点（`zoomAboutCentroid(pan, centroid, center, z1, z2) = pan + (centroid-center-pan)·(1-z2/z1)`）。卡自己发现 `calculateCentroid()` 无指针时返回 NaN 会让**整图消失**，加了守卫。**重要观察**：去掉补偿后既有 `PhotoViewZoomTest` 20 例**仍全绿** ⇒ 旧护栏盖不到锚点性质。
- **预设 PS-3（`a26016a`）**：拍照界面预设"可查看 + 可逐项修改"，参数表从 `EditorScreen.kt` **逐字搬移**到新建 `ParamControls.kt`（−429 行纯删除、零新增），两页共用同一套滑杆。
- **预设 PS-5（`aa7be18`）**：参数区改勾选树（照 PR-2 调研：LrC/Capture One/darktable/RawTherapee 四家一致 —— "包含哪些"用勾选、"调到多少"点开那一行）。
- **预设 PS-6a/6b（`dd1d52b`、`86ece27`）**：图 2 详情卡 + 图 1 完整参数页（分组网格一行 4 格 + 一次一项滑杆 + 重置回预设原值 + LUT 两字段）。
- **预设 PS-7（`0b855ba` 前）**：修透视（面板 `FilmTheme.Panel` 90% alpha ⇒ 取景参数行透出）、常用参数被挤出首屏（干掉整卡滚动）、参数"点不动"（`presetRowTap` 三态无第四态 + 滑杆固定槽）。
- **预设 PS-8（`0b855ba`）**：纵向列表 → 横向 `LazyRow` 预设条（124dp 卡/64dp 高）；一级页删掉全部参数清单（净删 606 行）；返回键分层（`cameraBackTarget`：二级页→快捷菜单→面板，全关才退出 app）。
- **预设 PS-9（`1a03717` 之前）**：间距阶 8/16/24dp + 标题去重；暗角档位 0.20/0.40/0.70 → 0.35/0.65/1.0；颗粒四档 → 强度滑杆（只写 `[26]`）。
- **预设 PS-10（`7715ec9`）**：`[37][38]` 黑白点做成可调（从 `CAMERA_NO_SLIDER_SLOTS` 移除，量程复用 `SettingsScreen` 既有滑杆，pivot = 引擎默认）。
- **白点 R-2/R-3（`b33555b`）**：R-2 实测证明死白起点 ≈ 白点本身（三条 2.60/2.45/2.40 EV，层次预算仅 7.5/3.1/2.0 LSB，而真机高光常到 2.47~3.0 EV）；R-3 把 `[38]` → 4.0 并**在死白起点硬约束下重跑拟合** ⇒ 死白起点三条齐平 **3.55 EV**、预算 15.8~24.4 LSB。
- 发布：`filmkit-0.11.26.apk`（375），全量 `--rerun-tasks` **595 用例 / 0 失败 / 27 tasks 全 executed**。

## Decisions

- **预设交互不自己拍，照开源调研**：架构师前两轮自拟（全参数铺开滑杆、分层）被用户连骂（"丑死/瞎搞/蠢货"）。PR-2 调研后按四家一致做法落地（勾选/点开调值 + 网格 + 分组）。此后每次交互改动都先查成熟实现。
- **预设面板用不透明底**（`PanelSolid`）：半透明会让取景界面的亮色文字（拍摄参数行）透出，与预设内容混叠。
- **一级页不提供全部参数**：只有常用参数 + 「完整参数 >」；完整参数一律进二级页。
- **返回键分层**：二级页 → 快捷菜单 → 面板 → 全关才退出 app（此前 `CameraScreen` **没有任何 BackHandler**，按返回直接退出 app）。
- **内置预设可改、只禁删**（推翻 PS-1 的"内置整体只读"），并配「恢复默认」；改动走覆盖层（`BuiltinOverrides`），出厂 assets 不动 ⇒ 升级时未改过的内置跟着更新。
- **白点选方案 A（不死白优先）**：`[38]` 4.0，代价是亮部变暗（白纸 −15.9~−18.0 LSB）、拟合残差 8~10 → 12.7~17.4。方案 B（回滚，残差小但真机高光糊平）成本极低，等用户验后定。
- **编辑器链路白点 >2.44 EV 无效**如实标注（`wh` 被显示域 clamp 到 1.0）：不灰显、不收窄量程（会砍掉拍照链路实测有效的 6.2 档），只标注。

## Pitfalls

- **"闪一下"要先分清是哪一种**：用户第一次说"闪"我按"清晰度阶跃"修（PV-1），第二次澄清"是屏幕闪烁"才转到转圈，第三次"一定会显示一下转圈"才锁死根因。**同一现象三种机制，必须先让用户描述清楚**。
- **PV-1 报告"同帧完成、不会渲染空帧"是推断，被真机否掉**：`LaunchedEffect` 的协程体是 dispatch 的，不在 apply 阶段同步执行；且 `Image` 参数在组合期取值 ⇒ 必然存在中间帧。
- **单测盖不到"调用点是否真用了判据"**：PV-3 的 M3（调用点整体绕开判据）不红 —— 本项目无 Robolectric/compose-ui-test，只能用**源码哨兵**补。同类：PS-8 用 21 个旧形态符号的反向哨兵防回退。
- **mutation 要注意假绿**：PS-8 一条哨兵 `contains("mutableStateOf<String?>(null)")` 被同文件 `editorId` 命中 ⇒ 断言看似有牙齿实则无效；PS-10 注入时发现"两槽设同值 ⇒ 读错槽照样绿"，改成另一槽设不同哨兵值。
- **并行卡会互相阻塞**：PS-6a 重写 `CameraPresetPanel.kt` 删了勾选树符号，而旧测试仍引用 ⇒ **测试源集整体编译失败，`--tests` 过滤救不了**，两张卡都跑不了测试。约定：删符号前先 grep 全仓，且 `compileDebugUnitTestKotlin` 通过要当硬判据。
- **"只改一个白点数"是错的**：死白起点**不是白点的函数，而是"曲线何时到顶"的函数** —— 只提白点重拟合，理光负片反而更差（2.65 EV），必须在死白起点硬约束下重跑拟合。
- **子代理 token 耗尽会断在收尾**：PS-3 报告写到 §12 才断，代码完整可用（架构师全量复跑 + 独立 mutation 抽检后才提交）。此后派卡一律要求**报告简短、先代码后报告**。

## Next

1. **真机验收 v0.11.26**：白色物体（杯子）高光是否有层次（不再死白）；亮部是否偏暗到不可接受（若太暗 → 白点 4.0 收到 3.5，残差更小但死白起点掉到 ~3.2）。据此在方案 A/B 间定档。
2. **长期方向（待拍板）**：让**预设也走场景自适应白点** —— 引擎 `FilmParams.h:135` 的 `auto_tone`（默认 0）已有"白点高光感知"（v0.10.27 加，修过"釉面/白瓷密集高光一路白上去"），但预设走固定 `[37][38]` 路径 ⇒ 治本需改这条。
3. **真机观感未验项**：横向预设条滑动手感与选中态、一级页 ≈354dp 下取景区占比、颗粒滑杆与暗角四档观感、缩放锚点跟手度（两指异步落下/抬起那一帧质心跳变）。
4. **旧欠账**（T-5/T-7/T-9/T-10 见 `preset-DESIGN.md` §10）：详情页读数口径统一、颗粒标定、LUT 重建（"还原"与"像那么回事"的分界线，未拍板）。
5. **离线执行器接入 PC3D**（旧待办，仍未做）：后链判据改动无法离线定标，多版"离线好看、真机判死"皆源于此。
