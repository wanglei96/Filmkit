# 性能收尾与0.15交接

## Summary
用户确认 0.14.57（854）作为性能收尾版，下一开发版从 0.15.0（855）开始。后续四项：预设标定、边框水印、AI 构图、预览效果。

## Done
- [2026-11-27] 生产代码 `10ce0c3`：可选 Vulkan Hanatos、完整六分量 RAW 协方差紧凑布局、FP64 DIR 平面、按需预热、并行 JPEG/R 底图。报告提交 `aff24ae`；0.14.57 是 main 的性能收尾目标，不把 0.15 版本元数据作为已验收构建。
- [2026-11-27] 真机 Gold 200 / Portra Endura 5.507s、Provia 100F 直扫 5.748s（快门到保存），用户反馈 0.14.57 取景比上版好。受控同 RAW Gold 四对配对中位省 812ms；Provia 不宣称稳定提速。证据见交付报告。
- [2026-11-27] 交付包四原片×两配方×8/10 位共 48 个输出哈希一致；收尾 Release JVM 852 项、850 通过、2 跳过、无失败。连续 FP64 曝光/DIR 和扫描打包候选未过整链门槛，已恢复至 0.14.57 ARM64 库哈希。

## Decisions
- [2026-11-27] 停止性能专项，保留现版成片及取景流畅度，不继续循环试验。0.15 四项只登记，具体范围和顺序待定。
- [2026-11-27] Vulkan 开关按设备支持检测，运行失败回退；没有启用 AHardwareBuffer 共享、全链 Vulkan 或连续 Vulkan 扫描。质量优先，禁止减核、减采样、降精度或复用跨帧统计换速度。

## Pitfalls
- [2026-11-27] 同 RAW 回放、合成取景与实拍是不同口径；不把不同场景实拍差值全归因 Vulkan，也不把 MediaStore 偶发慢帧记为渲染回归。
- [2026-11-26] 常规回归用四张固定同 RAW，见 `facts.md`；灯泡只测高光/品红。清理验保留副本 SHA-256，保留原片和关键证据，不操作手机照片或应用数据。
- [2026-11-27] 预览效果不是性能专项重启；分别验观感与流畅。Spektrafilm 的取景代理不是完整成片，先明确显示口径，不能靠修改成片补预览。
- [2026-11-27] 个别照片相册整图变暗未定因（`docs/reports/spektrafilm-01440-memory-gallery-20261123.md`）；旧高光/彩边、HDR/相纸端点和分发许可待办保留，不宣称已经验收。

## Next
1. 预设标定：梳理 `project.md` 的内置预设和参考，固定输入与显示域，建立参数与观感基线。
2. 边框水印：先确认作用位置、样式、开关及 SDR/HDR 保存口径。
3. AI 构图：先确认交互、输入输出和验收样例，再定实现。
4. 预览效果：以 0.14.57 取景为基线，先比同配方预览与成片的色彩、影调、曝光及构图，单独检查流畅度。
