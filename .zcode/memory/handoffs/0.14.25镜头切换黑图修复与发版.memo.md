# 0.14.25镜头切换黑图修复与发版

## Summary

本窗口完成切镜头黑图与焦段假保持的根因修复、真机回归、提交发布和可审计磁盘清理。
0.14.25(822) 已覆盖安装，`dev`、`main`、tag 与 GitHub Release 全部同步。

## Done

- **黑图根因闭环**：`FrameRenderer.cpp` 的 `ensureRawTex` 删除 `tex_satm_dst_` 后未清空 GL 句柄和尺寸，
  新图像目标复用同名纹理后又被 `passSatMask` 删除。修复为删除即清零句柄/尺寸，`release()` 同步清空
  program、texture、FBO、尺寸和 enabled 状态；未改成像数学。
- **旧库稳定复现**：纹理跟踪记录同一 id 59 先由 `passSatMask`、后由 `makeTex` 创建，再由
  `passSatMask` 删除；旧库第二例黑图，修复库八例通过。旧/新首张完整尺寸 RGBA SHA256 均为
  `e328eedeebb5ef460e477ac85e3c0c7d61b00371247ebd41008ed978e6ea8363`。
- **焦段恢复修复**：`selectOpenLens` 在 enabled pool 内优先 forced、其次 previous、最后最近 24mm；
  同 controller 后台恢复保留实际 lens 和合法 zoom。`CameraScreen` 仅在非 wheel/pinch 手势时同步
  实际等效焦距，`session_ready` 记录实际 camera id/equiv/zoom。
- **真机验收**：主摄、主切长焦、重复长焦、Home 恢复长焦、长焦回主摄五张均正常，RGB 均值
  `54.708/97.008/88.966/99.254/65.326`；恢复时实际 lens 3、等效 `70.25037mm`、zoom 1，
  UI 70mm 选中，实拍视场一致。最终回主摄，手机可正常使用，不再自动拍照。
- **回归**：841 项 App 单测 0 failure、0 error、2 skipped；shader 数值与静态校验、ARM64/x86_64
  Release 构建、864 项完整 JNI JPEG/R 对照、诊断/性能分析检查、`git diff --check` 全部通过。
  过期 `Pv3StaleFrameTest` 只更新测试哨兵，未改相册生产逻辑。

## Decisions

- [2026-11-17] **GL 资源删除必须同时清空句柄和尺寸**：纹理名会被驱动复用，留下悬空状态会导致后续
  pass 删除新目标；资源 owner、release 和重复删除都要按生命周期校验。
- [2026-11-17] **镜头恢复以实际 session 为准**：同 controller 后台恢复保留真实 lens/zoom；手势期间
  不让 UI 同步回写打断交互，不为“假保持”新增冷启动持久化。
- [2026-11-17] **0.14.25 统一收线但不夸大结论**：完整六分量 PC3D、P4/D1 与编码优化随版本发布；
  不声称所有场景稳定 5s 内，也不声称 P4/D1 全面胜过 PC3D，后续质量/性能取舍继续实测。

## Pitfalls

- **每次拍摄前 warmup 会掩盖黑图 bug**：初版测试每例都重建资源，不符合 App 的首次 warmup 后连续
  切镜头；回归必须在同一 renderer 连续跑尺寸变化、强度/旋转与重复镜头。
- **黑底上的数值抖动不是有效图像**：fixture 必须要求 RGB 均值明显大于 10；旧库第二例 mean 0.122
  或完整尺寸 mean 0.499 都明确失败。
- **UI 焦段不变不等于镜头会话没变**：必须读 `camera.session_ready` 的实际 id/equiv/zoom，并用
  照片视场交叉验证，不能只 XML 看选中项。
- **清理不能按目录粗暴删除**：先校验 SHA256、确认手机原片或同内容保留副本，再删重复派生数据；
  free-space 差额受构建和系统缓存影响，不应冒充精确删除量。

## Next

1. 新窗口用 `/recall` 载入本快照；从 `dev@9613b51`、0.14.25(822) 开始，不要重跑已完成发布。
2. 性能专项继续在锁定场景、Thermal 0、固定曝光/ISO 下取 0.14.25 基线；先读
   `release-0.14.25-20261117.md` 与 performance 0.14.20--0.14.23 报告。
3. 任何新的 RAW 重放先确认 fixture 仍在手机或本地；采样前重新取得手机固定、静止场景授权。
4. 旧账保留：高光外观扩展场景、Spektrafilm、理光曲线重标、绿植/绿段和亮部亮度降噪。
5. 后续验收不得 `pm clear`、不得清用户 App 数据或删除手机原片。
