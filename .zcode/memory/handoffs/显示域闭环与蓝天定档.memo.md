# 显示域闭环与蓝天定档

## Summary

把「取景器与成片亮度不一致」从标量估算改回 PC 的同一把尺（显示域鲁棒中灰），
并顺带订正 HDR 高光公式、用官方晴天样片重定理光负片蓝天目标。白块问题未闭环。

## Done

- **HDR 高光公式订正（0.12.231）**：`hdrLin*anchor−1` → `hdrLin−1/anchor`。
  旧式把 scene 差值放大 ≈2.56 倍，高光多给 0.35~0.86 EV，且更早打满 kMax。
- **显示域闭环（0.12.232→242）**：预览与成片都调 `robustMidToneDisplayRgba8()`
  （截尾四分位 + 中心高斯 sigma 0.32，同 PC `MeteringSystem`），成片 `passOutput`
  后量中心 1/2、差多少补到 `exposure_ev`、只重跑 filmic+output 两个 pass。
  真机三张：成片 vs 取景器差 **0.02~0.13 EV**（改前 0.9 EV）。
- **ML-AE 离线验证**：从 PhotonCamera 拉 3 个 MGC tflite（60/61/62 KB），复刻
  64×64×9 输入口径，5 张 DNG 全部跑通（3 模型一套 6 ms）。报告
  `docs/reports/ml-ae-offline-REPORT.md`，脚本 `tools/tuning/ml-ae-offline.py`。
- **理光负片蓝天定档**：抓 grblog 7151 官方原图，晴天深蓝天 h 270.9 / C\* 17.8 /
  L\* 46.8；阴天街景 h 258 / C\* 13.1。蓝段回到 0.12.233 参数（h 303.2、C×0.67）。
- **AGENTS.md 新增「方案选择纪律」**：禁止省事版、禁止半成品、对标实现读完再动手。
- 包 0.12.242（versionCode 693）为当前；回退 0.12.241。

## Decisions

- [2026-11-04] **显示域闭环用两遍渲染**：`tex_scene_` 与曝光无关 ⇒ 只重跑
  filmic+output 两个全分辨率 pass，不重跑马赛克/降噪/融合。
- [2026-11-04] **闭环用 0.7 阻尼 + 最多两轮**：实测闭环增益 1.0~1.76（`ev_shift`
  让白点跟着 exposure_ev 平移），全量步进会过冲（`dispErr` 曾 −0.9）。
- [2026-11-04] **HDR 回标准语义**：中灰及以下 ratio 恒 1，只有 SDR 白点之上延展。
- [2026-11-04] **蓝天目标必须用晴天样片**：阴天散射天空（h 258）不能代表蓝天。
- [2026-11-04] **LUT 里不许做「只作用于某段亮度」的补偿**：钟形窗在连续渐变里
  必然造出一条色相凹陷带（0.12.241 的白块）。

## Pitfalls

- [2026-11-04] **拿阴天街景天空当蓝天目标**：据此把 h 从 271 往青转到 251、C\* 压到
  10.2，用户「天空看不到颜色」。连续两轮朝错误方向改。
- [2026-11-04] **半成品链路能挂两周**：0.12.51 建了显示域统计、0.12.56 拆掉积分
  说「交给 Kotlin 外环」，而外环零调用 ⇒ `aeDispP50` 恒 0，取景器/成片差 0.9 EV。
- [2026-11-04] **用标量顶替参考实现的完整度量**：`g_domain_ratio` 初值 2.0、真实 3.49、
  clamp 上限 4.5 而实测有 6.71 的帧。
- [2026-11-04] **注释里「等价写法」可能是错的**：`hdrLin−1/anchor` 与
  `hdrLin*anchor−1` 差 anchor 倍，我照后者写且注释照抄前者。
- [2026-11-04] **诊断字段跟着开关走会误导**：`last_wmax_` 曾在关自动白点时写 0，
  日志看起来像统计失败（已改无条件记录）。
- [2026-11-04] **ML-AE 输出是曝光补偿量，不是审美判断**：极暗输入它照样给 +7 EV，
  不区分「夜景该暗」与「白天给少了」；触发/上限必须我们定。
- [2026-11-04] **白块（未闭环）**：成片天空 L\*≈190 处有斜率低谷，LUT（细扫 0.35/步
  恒定）与 filmic（斜率单调）均已排除；疑似 RAW 微弱起伏被压缩+降噪抹平。
  待办：预设面板把 LUT strength 调 0 同机位拍一张做隔离。

## Next

1. 白块隔离：LUT strength=0 的一张对照（有=非 LUT，无=LUT×filmic 接口）。
2. 天空「又青又紫」是否接受：官方同样漂 14°（深蓝 271→浅蓝 257），我们 18°。
   要压只能在 filmic 的色相处理做，不能在 display 域 LUT 加窗。
3. 6 题材同场景对照（蓝天+建筑/绿植/红物/人像/阴天街景/室内暖光）。
4. 徕卡黑白暗角 `80/52/−0.24` 仍待处理；理光负片/徕卡黑白是否锁 filmic 仍待定。
