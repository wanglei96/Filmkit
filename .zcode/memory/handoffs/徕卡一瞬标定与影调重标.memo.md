# 徕卡一瞬标定与影调重标

## Summary

徕卡一瞬（M9）从调研走到两阶段落地：一期把 PC 固件配方分支矩阵烘焙为 64³ 纯色彩
display 域 LUT（0.12.87，真机验收集约、无色带）；二期影调重标经三包收敛——双链
minimax 撞墙 14.75 → 单链拍照拟合 0.51（0.12.88）→ 真机"太亮/彩噪"反馈 → 目标
修订为"暗部保 M9、中高段回旧观感"重拟合 3.13（0.12.89）。另查明色温槽 6500K 是
恒等点（不是锁 WB）、AWB 逐张波动 ±5~15 是发黄根源（WB 锁定待立项）、B 方案
（曲线烘进 LUT + filmic 退位）被用户否决。

## Done

- **一期烘焙（0.12.87，`3f9bc41` tag v0.12.87）**：`tools/bake-m9-lut.py` 解码
  LUTS.bin（SHA256 + offset 校验对照 PC `LeicaProfile.kt`）→ `leica_m9_ccd.lut`
  （64³ uint8 786454B，首个 64³ 资产）。**烘焙语义经数据验证**：矩阵 Q13 定点
  （行和=8192=浮点1.0/8，中性恒等）、clamp 2047 只在纯白、分支 R=G 处连续
  （R 行差 [1152,−1147,0] 归零）；1D 曲线输入域=线性值 11-bit 编码
  （table[368]=0.588 与"0.18→0.59"吻合），按定案不烘、影调归 filmic。
  判据：插值 vs 直算 mean 0.13 LSB、max 20 LSB 限于钳制面窄带、灰轴 1.63 LSB
  （行和固有偏差）、端点保黑保白。预设单变量：LUT→leica_m9_ccd、strength 0.31→1.0。
- **一期真机验收通过**（用户目视：浓郁、无色带）：成片 C*P90 中位 33.2 vs M9
  样张库 ≈29；≥240 0.02%；暗部带色 C*P90 34~43。log 确认 64³ 解析 + 预设应用链。
- **发黄定性（三轮，均数据）**：① 标准预设白墙 R−B +0.6/+2.3（中性）；② 徕卡
  两张 + 色温槽白墙 −4~−5.6（偏冷）；③ 20:43 顶灯场景 +9~15（AWB 残留暖偏 ×
  LUT 色度放大 ~2×，暖灰 +25→+45 实测双向放大）。中性物中性 ⇒ 无链路偏色 bug；
  AWB 逐张波动 ±5~15 且无锁定是根源。
- **色温槽语义查明**：`[88] temp_mired` = 相对偏移（基准 6500K、恒等 0，
  EditorExport.kt:495）；UI 滑杆 6500K = 不做补偿，**不是"锁定 WB 到 6500K"**；
  "锁 K/死盯日光"机制不存在（WB 锁定未立项）。
- **引擎槽澄清**：内置预设不带 engine_slot；用户全局强制 sigmoid 时预设的 filmic
  影调槽被旁路（20:43 三张 = sigmoid+LUT，diag tone 1.0）。用户在 UI 给预设自加
  引擎槽（21:11:52 slots 18→19）为正确机制，builtin 资产不动（用户拍板）。
- **影调重标（0.12.88，`26ea5cd`）**：双链 minimax 14.75 撞墙（R-1b 互斥复现）→
  **单链拍照拟合 0.51 LSB**（目标 6 点全中：28.3/72.1/122.6/169.2/205.9/233.4）。
  白点钉 4.0（死白探针 0.28 未达 = R-3 判据与 M9 高光压缩目标冲突，真机 ≥240
  0.02% 裁决不阻塞）。参数 contrast 1.362/black −8.754/toe 近 0。
- **0.12.88 真机反馈**：太亮（p50 46.5→55.8 +9.3、p25 +10.5；avgLuma 62.8→64.0
  几乎不变 ⇒ 分布形状变）、彩噪（暗部色度 σ 1.72→1.76 持平，观感=中间调抬亮 ×
  contrast 1.36 放大）、黄（暖壶 R−B +14.2→+3.9 其实改善，AWB 收敛差异）。
- **0.12.89 二版（`1d3005d` tag v0.12.89）**：目标修订 = 暗部两点保 M9
  （52→28.6/85→71.8）、中高段回 0.12.87 前拍照输出（157.9/191.3/219.5），重拟合
  **3.13 LSB 且死白判据达标**（高光层次 1.56>1.0，冲突消解）。参数 contrast 1.188/
  black −4.879/shoulder 0.0256/0.0132/0.2632/toe 0.227/0.1371/0.7798；
  sat_shadow 1.15→1.0（暗部彩噪）。LUT 保持 1.0。编辑器链 35.4 记账（declared 35.6）。
- 三包均：823 单测绿、出包三验证、清过期包、commit/tag/push；包只留
  0.12.88-M9TONE + 0.12.89-M9TONE2。

## Decisions

- **B 方案否决（用户拍板）**："不能为了预设改引擎"——M9 曲线不烘进 LUT、filmic
  不退位；影调重标只能在现有参数族内做。
- **单链拍照拟合取代双链 minimax**：成片质量优先（项目大前提），拍照链为主判据；
  编辑器链残差记账（declared 35.6）。双链 14.75 是互相拖累的假墙。
- **影调目标 = 暗部 M9 + 中高段旧观感**（真机观感拍板）：M9 样张的 6 点灰阶只在
  暗部两点采纳；中高段用 0.12.87 前拍照输出。
- **白点 4.0 是 R-3 定档值、不是上限**（用户质疑后解除约束）：本轮维持 4.0
  （死白起点 3.55 达标），不是物理限制。
- **LUT 满强度 1.0 保留**（一期已验收的浓郁度）；若彩噪仍不满，下一旋钮 =
  LUT 强度 0.85~0.9（代价 = 浓郁度同步降）。
- **发黄治本 = WB 锁定机制立项**（未动工）：预设侧无解（场景相关色偏会污染
  白天）；短期只能统计折中冷移或用户自调色温滑杆。
- **sat_shadow 回 1.0**：R-3 的暗部饱和增益 1.15 撤销（暗部彩噪真机反馈）。

## Pitfalls

- **recipe-fit `--json` 不是测试读的文件**：`--json` 落原始记录（顶层=预设 id），
  `--export` 才生成 `{generated_by, presets}` 结构（BuiltinPresetCurveTest 读它）。
  跑错模式 → NPE at builtin-curves 加载。
- **拟合必须钉住既有定案**：`--white-ev 4.0` 忘了钉 ⇒ 白点被推到 4.59；
  `--lut-min 1.0` 钉 LUT 强度（默认下界 0.30 是旧 LUT 时代的记账）。
- **"双链撞墙"要拆链验证**：minimax 14.75 看似结构极限，单链拍照即 0.51——
  先确认是哪条链在拖。R-1b 的两链互斥结论在新 LUT 下依旧成立。
- **样张文件名后缀 = LUT 标题**（"徕卡M9CCD"）不是预设名；无后缀 = 无 LUT。
  用户"同场景 A/B"必须用日志核对 apply 时序：21:04 两张看似"标准 vs 徕卡"，
  实际都在切标准之后（两张都是标准）。
- **diag `tone:1.000` = 引擎 1（sigmoid）在工作**：20:43 三张徕卡样张实为
  sigmoid+LUT，预设的 filmic 影调槽被旁路——真机验收口径必须带引擎槽位归因。
- **发黄归因不能拍脑袋**："暖 LED"被用户当场纠正（白光 LED）；用中性区实测
  （白墙/白柜 R−B）+ LUT 格点响应数据定性，别用"光源色温"解释。

## Next

1. **0.12.89 真机验收**（等用户）：中间调亮度是否回到预期、黑位是否保留 M9 紧、
   暗光彩噪是否可接受；三项任一不满 → 目标/参数再迭代。
2. **WB 锁定机制立项**（发黄治本，调研唯一新机制）：预设携带采集行为（锁定 K
   或死盯日光），M9 特征的正解。
3. 彩噪若仍不满：LUT 强度 0.85~0.9 扫描（浓郁度兑换）。
4. 色彩层收尾：分区饱和 + temp/tint 到 C*P90 20+ 量级（调研 §6 顺序）。
5. 质感层：halation[62..65] + 颗粒 + 暗角按 M9 指纹标定。
6. 天空场景 HDR 验收（等天气）：5619 复现则 kHdrCeil 预案（0.12.90 起编号）。
